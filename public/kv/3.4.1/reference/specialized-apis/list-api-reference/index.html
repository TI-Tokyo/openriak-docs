The List API

The list API supports the listing of keys and buckets. The List API is deprecated in Riak 3.4, the AAE Fold API should be used instead, with the fold functions list_buckets , find_keys and find_tombs .

The APIs are unchanged since Riak 2.2.3, so refer to the legacy documentation for information on list keys o list buckets .

The use of list keys or list buckets may have a critical impact on the performance of production clusters. The AAE Fold alternatives are safe to use on production systems as long as two copies of the result-set can be held within available memory on a single node.
