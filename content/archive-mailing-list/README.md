# Archived Mailing List

This content family is generated from the historical HTML scrape of The Mail Archive.

Run `python3 tools/scripts/import-mailing-list.py` from the repository root to rebuild the thread pages, date indexes, inferred category indexes, and title-sorted category routes. The importer reads `riak-docs-fork/external-data/mailing-list/riak-users@lists.basho.com` from the sibling checkout by default; use `--source` to select another scrape.
