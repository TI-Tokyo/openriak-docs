</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg15271" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Sean Cribbs</span><time datetime="2014-11-30T10:35:49-08:00">November 30, 2014 at 10:35 AM</time><span class="mailing-list-message__subject">Re: How to stop riak http server</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">Assuming you&#x27;re using Riak 2.0.x, you can simply comment out any lines in
riak.conf that begin &quot;listener.http.&quot;. For example, the default config says
this:

listener.http.internal = 127.0.0.1:8098

Change it to this:

# listener.http.internal = 127.0.0.1:8098

You could also just delete the line from riak.conf.
