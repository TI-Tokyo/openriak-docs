</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg14825" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Eric Redmond</span><time datetime="2014-08-31T10:49:02-07:00">August 31, 2014 at 10:49 AM</time><span class="mailing-list-message__subject">Re: Can not list search_index after creating it succeed</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">Creating a search schema is non blocking, meaning that it will return ok as it
continues to process and propagate the schema on the backend. Attempting to
bind an index to a custom schema is generally because 1) the schema failed to
create (you can check out the solr.log or error.log for details), 2) you&#x27;re
attempting to use the schema too fast, before it&#x27;s had time to propagate across
the cluster.

In your case, it looks like this first.

Since you added.

&lt;dynamicField name=&quot;*&quot; type=&quot;ignored&quot; /&gt;

You have to define a fieldtype named &quot;ignored&quot;.

&lt;fieldtype name=&quot;ignored&quot; stored=&quot;false&quot; indexed=&quot;false&quot; multiValued=&quot;true&quot;
class=&quot;solr.StrField&quot; /&gt;

Hope that helps,
Eric
