The &quot;Cluster View&quot; screen your viewing in Riak Control displays the
partitions in your riak cluster and the physical node that has claimed each
partition. By default a riak cluster has 64 paritions, you&#x27;ll notice we
start counting at 0.

See: &quot;The Riak Cluster&quot; section on the &quot;what is Riak&quot;[1] page on the wiki
for an explanation of nodes, vnodes and data replication.

The ring view shows the number of partitions and which ip owns them (which by
default = 64) Conversely, the Cluster page will show only the physical nodes.

Check out the Riak Control page on the wiki [1] and the Clustering information
on the wiki [2] for more information on Control and how partitions work,
respectively.
