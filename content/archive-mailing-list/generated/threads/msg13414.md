On Mon, Jan 20, 2014 at 3:49 PM, Bryce Verdier &lt;bryceverd...@gmail.com&gt; wrote:
<blockquote>How does one change the default bucket properties in riak2?
</blockquote>
`n_val` of the default bucket properties can be set with
`riak_core.default_bucket_props.n_val`

<a href="https://github.com/basho/riak_core/blob/develop/priv/riak_core.schema#L7">https://github.com/basho/riak_core/blob/develop/priv/riak_core.schema#L7</a>

If there are other default bucket properties that you need to
override, you can create an `advanced.config` and just add the subset
of the old `app.config` you need.

<blockquote>How does one change the number of simultaneous PB connections?
</blockquote>
`pb_backlog` can be set with `riak_api.pb_backlog`

<a href="https://github.com/basho/riak_api/blob/develop/priv/riak_api.schema#L39">https://github.com/basho/riak_api/blob/develop/priv/riak_api.schema#L39</a>

<blockquote>How does one change the bitcask properties, e.g. expirey_secs?
</blockquote>
`expiry_secs` can be set with `bitcask.expiry_secs`

<a href="https://github.com/basho/bitcask/blob/develop/priv/bitcask.schema#L266">https://github.com/basho/bitcask/blob/develop/priv/bitcask.schema#L266</a>

<blockquote>I&#x27;m sorry if this was already discussed in other emails, I wasn&#x27;t able to
find it.

Thanks in advance!
