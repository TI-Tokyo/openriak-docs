               {riak_kv_mapper,do_map,2},
               {gen_fsm,handle_msg,7},
               {proc_lib,init_p_do_apply,3}]}}

What is wring with my code??

</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg05019" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Kresten Krab Thorup</span><time datetime="2011-10-04T02:24:25-07:00">October 4, 2011 at 2:24 AM</time><span class="mailing-list-message__subject">Re: Erlang Map/Reduce error</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">The error badfun most likely means that the function&#x27;s code is not available
inside Riak.

You need to add {add_paths, &quot;/path/to/your/ebin&quot;} in the riak_kv section in
app.config.  Read more about it here
<a href="http://wiki.basho.com/MapReduce.html#MapReduce-via-the-Erlang-API">http://wiki.basho.com/MapReduce.html#MapReduce-via-the-Erlang-API</a>

For an explanation of why the badfun happens, you can read this blog:
<a href="http://www.javalimit.com/2010/05/passing-funs-to-other-erlang-nodes.html">http://www.javalimit.com/2010/05/passing-funs-to-other-erlang-nodes.html</a>
... which can also give you an idea to how to do it without loading the code
into riak, i.e. something like this may likely work, but will invoke the
interpreter inside riak; which may be too slow for your needs.

Kresten

1&gt; FunStr = &quot;fun(O, undefined, none) -&gt; [riak_object:get_value(O)] end.&quot;.
2&gt; {ok, Tokens, _} = erl_scan:string(FunStr).
3&gt; {ok, [Form]} = erl_parse:parse_exprs(Tokens).
4&gt; Bindings = erl_eval:add_binding(&#x27;B&#x27;, 2, erl_eval:new_bindings()).
5&gt; {value, Fun, _} = erl_eval:expr(Form, Bindings).
6&gt; C:mapred([{&lt;&lt;&quot;buck&quot;&gt;&gt;, &lt;&lt;&quot;key1&quot;&gt;&gt;}, {&lt;&lt;&quot;buck&quot;&gt;&gt;, &lt;&lt;&quot;key2&quot;&gt;&gt;}], [{map, {qfun,
Fun}, none, true}]).

Kresten
