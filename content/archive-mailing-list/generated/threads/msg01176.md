3) Q --- If I want to retrieve only certain number of keys of a
bucket, is there a way I can do it? Something like &#x27;limit&#x27; that I can
add to this URL: GET /riak/test?keys=true&amp;props=True (from kk via
#riak)

    A --- You&#x27;ll need to use a MapReduce job for this or, in certain
cases, a creative use of link walking might accomplish it.

MapReduce ---&gt; <a href="http://wiki.basho.com/display/RIAK/MapReduce">http://wiki.basho.com/display/RIAK/MapReduce</a> ,
<a href="http://wiki.basho.com/display/RIAK/Loading+Data+and+Running+MapReduce+Queries">http://wiki.basho.com/display/RIAK/Loading+Data+and+Running+MapReduce+Queries</a>

Links and Link Walking ---&gt; <a href="http://wiki.basho.com/display/RIAK/Links">http://wiki.basho.com/display/RIAK/Links</a> ,
