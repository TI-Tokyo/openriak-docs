Riak Recap for November 18 - 20
========================

1) The Admaze.ly team open-sourced &quot;resourceful-riak&quot;, a Riak backend
for the Resourceful framework.

* Code here ---&gt; <a href="https://github.com/admazely/resourceful-riak">https://github.com/admazely/resourceful-riak</a>

2) We merged some more contributions to the Python client from Greg
Stein and Soren Hansen. Code here:

*
<a href="https://github.com/basho/riak-python-client/commit/5898f8e66dc4c67b3480324f9fd8aa8e2695cf87">https://github.com/basho/riak-python-client/commit/5898f8e66dc4c67b3480324f9fd8aa8e2695cf87</a>

<a href="https://github.com/basho/riak-python-client/commit/bd74b800c2717601396322acd58b83cbadeed2ad">https://github.com/basho/riak-python-client/commit/bd74b800c2717601396322acd58b83cbadeed2ad</a>
*
<a href="https://github.com/basho/riak-python-client/commit/e9b9412c7a0977c1afb62c00bb3c2a69530adeab">https://github.com/basho/riak-python-client/commit/e9b9412c7a0977c1afb62c00bb3c2a69530adeab</a>

3) Kyle Kingsbury released version 0.1.8 of his Ruby ORM &quot;Risky&quot;.

* Code here ---&gt; <a href="https://github.com/aphyr/risky">https://github.com/aphyr/risky</a>

supporting Riak.

* Code here ---&gt;

have had working with Riak to date.
