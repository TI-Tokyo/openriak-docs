</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg06405" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">charlesugwuh</span><time datetime="2012-01-25T06:51:29-08:00">January 25, 2012 at 6:51 AM</time><span class="mailing-list-message__subject">Re: Cant load data after enabling indexing on bucket with precommit	hook</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">I figured this out.

So I&#x27;m using the  <a href="https://github.com/basho/riak-php-client">https://github.com/basho/riak-php-client</a> PHP Riak Client .
I was using the setProperties method to set the commit hooks for the bucket
to enable search.

However, I was defining the bucket properties like so: &#x27;$prop_arr =
array(&#x27;precommit&#x27; =&gt; array(&#x27;mod&#x27; =&gt; &#x27;riak_search_kv_hook&#x27;, &#x27;fun&#x27; =&gt;
&#x27;precommit&#x27;));&#x27; instead of like so: &#x27;$prop_arr = array(&#x27;precommit&#x27; =&gt;
array(array(&#x27;mod&#x27; =&gt; &#x27;riak_search_kv_hook&#x27;, &#x27;fun&#x27; =&gt; &#x27;precommit&#x27;)));&#x27;.

It&#x27;s a very subtle difference but the first one creates this:
&#x27;{&quot;props&quot;:{&quot;precommit&quot;:{&quot;mod&quot;:&quot;riak_search_kv_hook&quot;,&quot;fun&quot;:&quot;precommit&quot;}}}&#x27;
while the second creates this
&#x27;{&quot;props&quot;:{&quot;precommit&quot;:[{&quot;mod&quot;:&quot;riak_search_kv_hook&quot;,&quot;fun&quot;:&quot;precommit&quot;}]}}&#x27;.
The difference is the square bracket and this threw the whole thing out of
whack when it wasn&#x27;t present.

So now everything is working ok.
