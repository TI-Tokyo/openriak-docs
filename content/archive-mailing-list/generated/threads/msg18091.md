Version 1.6.3 of the Riak Spark Connector has been released, and is now
available through both GitHub
&lt;<a href="https://github.com/basho/spark-riak-connector/releases/tag/v1.6.3">https://github.com/basho/spark-riak-connector/releases/tag/v1.6.3</a>&gt; and Spark
Packages &lt;<a href="https://spark-packages.org/package/basho/spark-riak-connector">https://spark-packages.org/package/basho/spark-riak-connector</a>&gt;.
I&#x27;d like to thank the team, especially Sergey Galkin
&lt;<a href="https://github.com/srgg">https://github.com/srgg</a>&gt;, for all their hard work on this release.

This release fixes some issues, and enhances some features:

   - Enhancement - Data locality support for Coverage Plan Based
   Partitioning #230
   &lt;<a href="https://github.com/basho/spark-riak-connector/pull/230">https://github.com/basho/spark-riak-connector/pull/230</a>&gt;
   - Enhancement - Improve Coverage Plan Based Partitioning: smart split
   calculation and more accurate coverage entry distribution across the
   partitions #231 &lt;<a href="https://github.com/basho/spark-riak-connector/pull/231">https://github.com/basho/spark-riak-connector/pull/231</a>&gt;
   - Critical Fix - Python serialization for empty JSON objects #226
   &lt;<a href="https://github.com/basho/spark-riak-connector/pull/226">https://github.com/basho/spark-riak-connector/pull/226</a>&gt;
   - Fix - Remove double filtering for DataFrames #228
   &lt;<a href="https://github.com/basho/spark-riak-connector/pull/228">https://github.com/basho/spark-riak-connector/pull/228</a>&gt;

As always, issues and PRs are welcome via the project&#x27;s GitHub page
&lt;<a href="https://github.com/basho/spark-riak-connector">https://github.com/basho/spark-riak-connector</a>&gt;.
