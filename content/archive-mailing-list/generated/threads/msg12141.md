Riak Recap for August 1-27
====================

Riak CS 1.4.0 was released, with OpenStack integration.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012997.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012997.html</a>
- <a href="https://github.com/basho/riak_cs/blob/1.4.0/RELEASE-NOTES.org">https://github.com/basho/riak_cs/blob/1.4.0/RELEASE-NOTES.org</a>

Riak 1.4.1 was released.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012891.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012891.html</a>

The Basho-supported Riak Ruby client 1.4.0 was released.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013066.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013066.html</a>

Dave Martorana wrote a great post on why Flyclops is going with Riak for
persistence to back their games, which was followed by an overview of building
Riak for OmniOS.
- <a href="http://tech.flyclops.com/taking-the-riak-plunge-356">http://tech.flyclops.com/taking-the-riak-plunge-356</a>
- <a href="http://tech.flyclops.com/building-riak-on-omnios-360">http://tech.flyclops.com/building-riak-on-omnios-360</a>

Riak is being used by the UK&#x27;s National Health Service as part of their Spine
re-architecture. Forrester mentioned this in a piece recently.
-
<a href="http://blogs.forrester.com/james_staten/13-07-30-to_get_national_healthcare_right_requires_adaptive_intelligence">http://blogs.forrester.com/james_staten/13-07-30-to_get_national_healthcare_right_requires_adaptive_intelligence</a>

Basho engineer Takahiko Sato posted a Riak concepts slide deck on slideshare
(Japanese).
- <a href="http://www.slideshare.net/takahikosato/riak-24796781">http://www.slideshare.net/takahikosato/riak-24796781</a>

Ryan Zezeski announced Yokozuna 0.8.0, the next generation search tool for Riak
that leverages Solr.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012887.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/012887.html</a>
- <a href="https://github.com/basho/yokozuna/blob/master/docs/RELEASE_NOTES.md#080">https://github.com/basho/yokozuna/blob/master/docs/RELEASE_NOTES.md#080</a>

mrb and the small team working on the Riak Go Client are looking for feedback
before they officially make it 1.0.
- <a href="https://twitter.com/mrb_bk/status/364878043719802880">https://twitter.com/mrb_bk/status/364878043719802880</a>

In what is becoming a common deployment pattern, Customer.io moved into
production with Riak and Go.
- <a href="http://customer.io/blog/Segment-customer-data-faster.html">http://customer.io/blog/Segment-customer-data-faster.html</a>
- <a href="https://twitter.com/jrallison/status/365560974251540481">https://twitter.com/jrallison/status/365560974251540481</a>

The team at Janrain wrote a blog post about why they are using Riak in
production and their move to take over development of the Riak Haskell client.
-
<a href="http://janrain.com/blog/janrain-is-now-leading-development-of-the-haskell-riak-client/">http://janrain.com/blog/janrain-is-now-leading-development-of-the-haskell-riak-client/</a>

CorrugatedIron co-author Jeremiah Peschka wrote a post called &quot;Querying a
Key/Value Database – Learning with Riak&quot; for the Brent Ozar blog.
-
<a href="http://www.brentozar.com/archive/2013/08/querying-a-keyvalue-database-learning-with-riak">http://www.brentozar.com/archive/2013/08/querying-a-keyvalue-database-learning-with-riak</a>

Jeremiah presented at Seattle Riak on &quot;Riak in a .NET World&quot;, video online.
- <a href="http://compositecode.com/2013/08/20/riak-in-a-net-world/">http://compositecode.com/2013/08/20/riak-in-a-net-world/</a>

Jeremiah also announced the release of CorrugatedIron 1.4.1.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013074.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013074.html</a>

Adron Hall started an open source project to build a Windows 8 Riak Interface
and blogged about it.
- <a href="http://compositecode.com/2013/08/20/riak-in-a-net-world/">http://compositecode.com/2013/08/20/riak-in-a-net-world/</a>

Adron posted a piece on the Client Round Robin Anti-Pattern.
-
<a href="http://compositecode.com/2013/08/21/riak-development-guidance-the-client-round-robin-anti-pattern/">http://compositecode.com/2013/08/21/riak-development-guidance-the-client-round-robin-anti-pattern/</a>

Nathan LaFreniere&#x27;s riakproto library just hit 1.4.1.
- <a href="https://npmjs.org/package/riakproto">https://npmjs.org/package/riakproto</a>

Gavin M. Roy wrote a Riak plugin for New Relic in Python.
-
<a href="https://github.com/MeetMe/newrelic-plugin-agent/blob/master/newrelic_plugin_agent/plugins/riak.py">https://github.com/MeetMe/newrelic-plugin-agent/blob/master/newrelic_plugin_agent/plugins/riak.py</a>
