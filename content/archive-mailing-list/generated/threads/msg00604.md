Riak Recap for 6/14

1) @kevsmith pushed out the 0.11 version of the Riak Java Client

Get it here ---&gt;
<a href="https://oss.sonatype.org/content/repositories/releases/com/basho/riak/riak-client/0.11.0/">https://oss.sonatype.org/content/repositories/releases/com/basho/riak/riak-client/0.11.0/</a>

2) The organizers at Red Dirt Ruby published a video of Sean Cribb&#x27;s
Riak Workshop from last month. This one is long but well worth it.

Grab some hot cocoa, set aside a few hours, and click here ---&gt;
<a href="http://reddirtrubyconf.com/video">http://reddirtrubyconf.com/video</a>

missed.

More details here ---&gt;
<a href="http://en.oreilly.com/velocity2010/public/schedule/detail/15572">http://en.oreilly.com/velocity2010/public/schedule/detail/15572</a>

Tweet here ---&gt; <a href="http://twitter.com/dysinger/status/16198029348">http://twitter.com/dysinger/status/16198029348</a>
