Riak Recap for August 28 - September 5
====================
Riak 1.4.2 was released.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013183.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013183.html</a>

Basho announced a new development process for its repositories on GitHub.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013148.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013148.html</a>

Dan &amp; Drew Kerrigan of Basho discuss client-side CRDTs and term-based inverted
indexes, including a demonstration Zombie Index application.
- <a href="http://basho.com/index-for-fun-and-for-profit/">http://basho.com/index-for-fun-and-for-profit/</a>
- <a href="http://basho.com/indexing-the-zombie-apocalypse-with-riak/">http://basho.com/indexing-the-zombie-apocalypse-with-riak/</a>
- <a href="http://zombies.samples.basho.com/">http://zombies.samples.basho.com/</a>

Jonathan Ellis of Datastax wrote a blog post discussing the lack of vector
clocks in Cassandra and talked extensively about Riak&#x27;s default behaviors,
resulting in a long and educational discussion on Hacker News.
- <a href="http://www.datastax.com/dev/blog/why-cassandra-doesnt-need-vector-clocks">http://www.datastax.com/dev/blog/why-cassandra-doesnt-need-vector-clocks</a>
- <a href="https://news.ycombinator.com/item?id=6329619">https://news.ycombinator.com/item?id=6329619</a>

Customer.io migrated from MongoDB to Riak and discussed the dramatic speed
improvements they achieved.
-
<a href="http://basho.com/customer-io-gains-6x-speed-improvement-by-moving-from-mongodb-to-riak/">http://basho.com/customer-io-gains-6x-speed-improvement-by-moving-from-mongodb-to-riak/</a>
- <a href="http://customer.io/blog/Segment-customer-data-faster.html">http://customer.io/blog/Segment-customer-data-faster.html</a>

Flywheel, a mobile taxi hailing platform, selected Riak for its operational
simplicity.
-
<a href="http://basho.com/mobile-taxi-platform-flywheel-uses-riak-to-power-their-application/">http://basho.com/mobile-taxi-platform-flywheel-uses-riak-to-power-their-application/</a>

Joachim Haagen Skeie open sourced a Riak data browser written in Ember.js and
Netty.
- <a href="https://github.com/joachimhs/Embriak">https://github.com/joachimhs/Embriak</a>

John Vincent (Lusis) released an Omnibus project for Riak.
- <a href="https://github.com/lusis/omnibus-riak">https://github.com/lusis/omnibus-riak</a>

Bryce Kerley asked for feedback on link walking via the Ruby library.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013187.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-August/013187.html</a>
