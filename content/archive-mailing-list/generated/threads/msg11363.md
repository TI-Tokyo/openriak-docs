Riak Recap for June 20 - 30
====================

The Tier 3 crew wrote some docs on how to use their new object storage
service (that runs on Riak CS).
-
<a href="http://help.tier3.com/entries/21649725-Using-Object-Storage-via-REST-API-AWS-SDK">http://help.tier3.com/entries/21649725-Using-Object-Storage-via-REST-API-AWS-SDK</a>

Basho Hacker Andrew Thompson wrote a blog post about package management.
- <a href="http://vagabond.github.io/2013/06/21/z_packagers-dont-know-best/">http://vagabond.github.io/2013/06/21/z_packagers-dont-know-best/</a>

He also wrote a follow up:
- <a href="http://vagabond.github.io/2013/06/21/zz_packaging-and-the-tide-of-history/">http://vagabond.github.io/2013/06/21/zz_packaging-and-the-tide-of-history/</a>

Aphyr wrote a piece for InfoQ about his Jepsen framework and how to break
databases.
- <a href="http://www.infoq.com/articles/jepsen">http://www.infoq.com/articles/jepsen</a>

Brian Dunavant wrote a blog post about running Riak on SSDs and how that
impacted various components of their production deployment.
-
<a href="http://www.phishie.com/wordpress/2013/06/eventually-consistant-performance/">http://www.phishie.com/wordpress/2013/06/eventually-consistant-performance/</a>

The team at Trifork wrote a blog called &quot;EFFICIENTLY STORING YOUR DOMAIN
MODEL IN RIAK.&quot;
-
<a href="http://blog.trifork.com/2013/06/20/efficiently-storing-your-domain-model-in-riak/">http://blog.trifork.com/2013/06/20/efficiently-storing-your-domain-model-in-riak/</a>

Basho Hacker Eric Redmond&#x27;s Railsberry talk &quot;Distributed patterns you
should know&quot; is now online.
- <a href="https://vimeo.com/68757697">https://vimeo.com/68757697</a>

He also gave a variation of this talk at Ancient City Ruby called
&quot;Distributed Patterns in Ruby.&quot;
- <a href="http://www.youtube.com/watch?v=Adu_dbcnUHA&amp;feature=youtu.be">http://www.youtube.com/watch?v=Adu_dbcnUHA&amp;feature=youtu.be</a>

Basho Hacker C.S. Meiklejohn wrote a blog post about something he&#x27;s been
working on called  &quot;Riak PG&quot; -  distributed process groups for Erlang
(built on riak_core).
-
<a href="http://christophermeiklejohn.com/erlang/riak/crdt/2013/06/24/introducing-riak-pg-distributed-process-groups-for-erlang.html">http://christophermeiklejohn.com/erlang/riak/crdt/2013/06/24/introducing-riak-pg-distributed-process-groups-for-erlang.html</a>

Daniel Kvasnička wrote and released a Riak client written in Racket.
- <a href="https://github.com/dkvasnicka/racket-riak">https://github.com/dkvasnicka/racket-riak</a>

Sean Cribbs is giving a talk at All Your Base Conference this October in
Oxford called &quot;Practical Eventually-Consistent Web Apps on Riak.&quot;
- <a href="http://lanyrd.com/2013/all-your-base/sckfzk/">http://lanyrd.com/2013/all-your-base/sckfzk/</a>

Basho TE Joel Jacobson and ardent Riak user Age Mooji will be presenting on
all things Riak at the NoSQL Netherlands Meetup on July 24th in Amsterdam.
- <a href="http://www.meetup.com/nosql-nl/events/127354632/">http://www.meetup.com/nosql-nl/events/127354632/</a>
