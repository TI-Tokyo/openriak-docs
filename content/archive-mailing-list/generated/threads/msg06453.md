It looks like you have a screwed up ring. You have two nodes joining and no
valid nodes, meaning the one owning the original ring is gone (not even
just down, but nonexistent). You probably started a node, changed its node
name in vm.args and then restarted it. Because the ring has already been
written, it thinks the new node name owns 0 partitions, while the one that
it was before, owns them all.

To fix both of these problems, you need to stop all nodes, delete the ring
files (on Linux, /var/lib/riak/ring/*), start them back up, and rejoin them.
