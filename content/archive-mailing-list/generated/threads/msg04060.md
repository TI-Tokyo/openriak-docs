Riak Recap for July 20 - 24
====================

1) OJ Reeves (@thecolonial) and Jeremiah Peschka (@peschkaj) released
a .NET client for Riak yesterday called &quot;CorrugatedIron&quot;. In short,
this library is awesome.

* Project site ---&gt; <a href="http://corrugatediron.org/">http://corrugatediron.org/</a>
* Repo on GitHub ---&gt; <a href="https://github.com/DistributedNonsense/CorrugatedIron">https://github.com/DistributedNonsense/CorrugatedIron</a>
* Introductory Blog Post from OJ ---&gt;
<a href="http://buffered.io/posts/introducing-corrugatediron/">http://buffered.io/posts/introducing-corrugatediron/</a>
* Introductory Blog Post from Jeremiah ---&gt;
<a href="http://www.brentozar.com/archive/2011/07/just-one-more-thing-introducing-corrugatediron/">http://www.brentozar.com/archive/2011/07/just-one-more-thing-introducing-corrugatediron/</a>

Special thanks are due OJ, Jeremiah, and several others who worked on
making version 0.1 possible! Rumor has it that they are already fast
at work on version 0.2 and are on the look out for contributors...

2) The videos for the WindyCityDB conference held in June in Chicago
are online. Susan Potter gave a great talk on Link Walking in Riak and
you should watch it.

* Watch here ---&gt; <a href="http://windycitydb.org/videos2011/">http://windycitydb.org/videos2011/</a>

3) @Cy6erBr4in released a link shortener built with Erlang, Riak, and
Mochiweb.

* Link shortener ---&gt; <a href="http://aes.li/">http://aes.li/</a>
* Code on GitHub ---&gt; <a href="https://github.com/2garryn/esli">https://github.com/2garryn/esli</a>

4) Some jobs:

* Extole in San Francisco is looking for a Ruby Developer with Riak
experience. --&gt; <a href="http://bit.ly/pD4aLY">http://bit.ly/pD4aLY</a>
* Opening for a Java Developer with Riak and Mongo experience in
Middlebury, VT ---&gt;  <a href="http://bit.ly/puJayu">http://bit.ly/puJayu</a>
