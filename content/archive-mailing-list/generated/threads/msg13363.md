Riak Recap for December 18 - January 7
====================

Basho unveiled our first infographic late last year
- <a href="http://basho.com/infographic-down-with-downtime/">http://basho.com/infographic-down-with-downtime/</a>

Jeremy Hill from Basho&#x27;s UK office wrote a piece on government IT&#x27;s changing
views of the cloud
-
<a href="http://www.theinformationdaily.com/2013/12/31/a-cloud-future-the-public-sectors-new-mentality-to-data">http://www.theinformationdaily.com/2013/12/31/a-cloud-future-the-public-sectors-new-mentality-to-data</a>

John Daily&#x27;s post on Riak development anti-patterns was published today
- <a href="http://basho.com/riak-development-anti-patterns/">http://basho.com/riak-development-anti-patterns/</a>

Imran Hossain Shaon tackled using Riak CS as a storage backend for Eucalyptus
4.0
-
<a href="http://mdshaonimran.wordpress.com/2014/01/01/eucalyptus-object-storage-gateway-with-riak-cs/">http://mdshaonimran.wordpress.com/2014/01/01/eucalyptus-object-storage-gateway-with-riak-cs/</a>

Srivatsa Katta created a command-line tool to interface with Riak
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-December/014339.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-December/014339.html</a>
- <a href="https://github.com/katta/riakcli">https://github.com/katta/riakcli</a>

Pedro Larroy is improving C++ and Python 3 client support
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-December/014298.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-December/014298.html</a>
- <a href="https://github.com/larroy/riak_python3">https://github.com/larroy/riak_python3</a>

Basho engineer and author Eric Redmond guest-starred in a Puppet Labs Podcast
-
<a href="http://puppetlabs.com/podcasts/eric-redmond-design-patterns-distributed-systems">http://puppetlabs.com/podcasts/eric-redmond-design-patterns-distributed-systems</a>

Noah Isaacson released a new version of riak-streaming-node
- <a href="https://npmjs.org/package/riaks">https://npmjs.org/package/riaks</a>

Bryce Verdier took a close look at Riak and Haskell and blogged about it
-
<a href="http://scrollingtext.org/connecting-riak-node-using-haskell-and-viewing-riak-buckets">http://scrollingtext.org/connecting-riak-node-using-haskell-and-viewing-riak-buckets</a>

Basho&#x27;s Drew Kerrigan created a client-side counter type in Ruby with
idempotent writes
- <a href="http://rubygems.org/gems/riak-ruby-ledger">http://rubygems.org/gems/riak-ruby-ledger</a>

Brian Roach unveiled a preview of Basho&#x27;s completely rewritten Java client for
2.0
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2014-January/014374.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2014-January/014374.html</a>

- <a href="http://www.meetup.com/Seattle-Riak/events/157134312/">http://www.meetup.com/Seattle-Riak/events/157134312/</a>
