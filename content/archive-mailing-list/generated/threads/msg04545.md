curl -v -X PUT -d &#x27;{&quot;prop&quot;:&quot;val&quot;}&#x27; -H &quot;Content-Type: application/json&quot;
<a href="http://riak/store/jdTestBucket/key2?w=1">http://riak/store/jdTestBucket/key2?w=1</a>
curl -v -X PUT -d &#x27;{&quot;prop&quot;:&quot;val&quot;}&#x27; -H &quot;Content-Type: application/json&quot;
<a href="http://riak/store/jdTestBucket/key3?w=1">http://riak/store/jdTestBucket/key3?w=1</a>
curl -v -X PUT -d &#x27;{&quot;prop&quot;:&quot;val&quot;}&#x27; -H &quot;Content-Type: application/json&quot;
<a href="http://riak/store/jdTestBucket/key4?w=1">http://riak/store/jdTestBucket/key4?w=1</a>

We shut down one node.

We delete the keys:
curl -v -X DELETE <a href="http://riak/store/jdTestBucket/key1?w=1">http://riak/store/jdTestBucket/key1?w=1</a>
curl -v -X DELETE <a href="http://riak/store/jdTestBucket/key2?w=1">http://riak/store/jdTestBucket/key2?w=1</a>
curl -v -X DELETE <a href="http://riak/store/jdTestBucket/key3?w=1">http://riak/store/jdTestBucket/key3?w=1</a>
curl -v -X DELETE <a href="http://riak/store/jdTestBucket/key4?w=1">http://riak/store/jdTestBucket/key4?w=1</a>

We list the keys :
curl -i <a href="http://riak/store/jdTestBucket?keys=true\&amp;props=false">http://riak/store/jdTestBucket?keys=true\&amp;props=false</a>

All keys are listed.

Is it normal?
