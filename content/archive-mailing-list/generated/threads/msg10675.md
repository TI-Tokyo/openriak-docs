a customer of mine is running Riak on EC2 (and also using DynamoDB, but for a
totally different use case). I&#x27;m not sure if the 2B keys will be a problem, we
are a bit below that amount. It also highly depends on your desired backend,
throughput and latency requirements if you want to run Riak on EC2.

We&#x27;ve struggled quite some time with bad 99th read percentile. When we updated
to 1.3 and applied an additional patch ([0]), the situation improved. The main
issue is that the IO performance of EC2&#x27;s ephemeral instance storage is quite
unpredictable. We started and stopped a lot of instances in order to get ones,
that have a better IO performance (IO performance appears to be quite steady
over instance lifetime). If you can afford to run your cluster on SSD-backed
instances, you won&#x27;t have a problem though :)

I have no exact details for a cost comparison, but this also depends on your
requirements and workload. Riak is pretty easy to run and has features,
DynamoDB does not offer (e.g. we needed key expiration). On the other hand,
DynamoDB is pretty fast and very steady performance wise. But since you pay for
throughput it can get quite expensive very quickly.
