You should have at least 5 servers, and they should have at least 4GB RAM each. The minimums are for different reasons.

The minimum RAM is clear: keeping things like keys resident reduces the chances of disk swap, which can destroy any database.

The minimum 5 nodes is because the major reason for using Riak is high availability. If you don&#x27;t have a good distribution of objects across several physical machines, you are less able to deal with any particular one going down. If you only have two servers, you really can&#x27;t survive a single outage. Any less than 4 makes the odds that a value is replicated multiple times on the same machine quite high, so we recommend 5 since you can at least handle 1 downed node.

Eric
