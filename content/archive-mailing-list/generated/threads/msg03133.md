Riak Recap for April 20 - 21
=====================

1) Jon Brisbin wrote a piece for the Springsource blog (that
originally appeared on his personal blog) called &quot;Eventing Data With
Riak and RabbitMQ.&quot; As you can probably guess, this one talks a lot
about the work he&#x27;s been doing getting Riak and RabbitMQ to play nice
together and its potential uses.

* Read here ---&gt;
<a href="http://blog.springsource.com/2011/04/21/eventing-data-with-rabbitmq-and-riak/">http://blog.springsource.com/2011/04/21/eventing-data-with-rabbitmq-and-riak/</a>

2) Version 0.15 of the Perl client developed and used by Franck Cuny,
Robin Edwards, and Linkfluence team was just released.

* Details here ---&gt; <a href="http://search.cpan.org/~rge/Net-Riak-0.15/">http://search.cpan.org/~rge/Net-Riak-0.15/</a>

3) Some more evidence that Erlang Factory London is going to be
downright amazing: Kresten Krab Thorup will be giving a talk called
&quot;Bringing Riak to the Mobile Platform.&quot; Riak Mobile is a component
that can be embedded into your iOS or Android application to make it a
full Riak replication-aware peer...

* Details here ---&gt;
<a href="http://erlang-factory.com/conference/London2011/speakers/KrestenKrabThorup">http://erlang-factory.com/conference/London2011/speakers/KrestenKrabThorup</a>

4) JB Barth wrote up a great intro blog post to using Riak and Rekon.

* Read here ---&gt; <a href="http://jbbarth.com/archives/2011/4/21/a_first_sight_at_riak/">http://jbbarth.com/archives/2011/4/21/a_first_sight_at_riak/</a>

5) Mikhail Sobolev fixed up a few links related to the Python Client.

* Commit details here ---&gt; <a href="https://github.com/basho/riak-python-client/pull/23">https://github.com/basho/riak-python-client/pull/23</a>

6) For anyone headed to Velocity in June, Justin Sheehy&#x27;s talk
overview was just posted.

* All the details here ---&gt;
<a href="http://velocityconf.com/velocity2011/public/schedule/detail/18143">http://velocityconf.com/velocity2011/public/schedule/detail/18143</a>

7) A few job opportunities:

* Senior Software Engineer in Santa Clara, CA ---&gt; <a href="http://bit.ly/eZaiXu">http://bit.ly/eZaiXu</a>
* Data Engineer at Ubermedia ---&gt;
<a href="http://www.ventureloop.com/ventureloop/jobdetail.php?jobid=64080">http://www.ventureloop.com/ventureloop/jobdetail.php?jobid=64080</a>

8) Scott Gonyea did some reworking of some ObjC/ObjC++ Riak Protobuf
code he published a while ago.

* Start here ---&gt; <a href="http://twitter.com/#!/acts_as/status/60934187900870656">http://twitter.com/#!/acts_as/status/60934187900870656</a>

9) Q --- Can a Riak M/R job modify a stored object? (from alextj via #riak)

    A --- This is not currently possible.

10) Q --- Are there any plans for the PBC interface to allow a put
with no key specified? (from rob_ via #riak)

      A --- This has just been added (thanks, Andrew!) and will be
available in the next release. See:
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2011-April/003820.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2011-April/003820.html</a>
