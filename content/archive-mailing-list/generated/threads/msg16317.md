I just pushed the blue button and released Riak Java Client 2.0.2.
Get it here: <a href="http://repo1.maven.org/maven2/com/basho/riak/riak-client/2.0.2/">http://repo1.maven.org/maven2/com/basho/riak/riak-client/2.0.2/</a>
It should be synced to Maven Central within the hour. Just update your pom
dependency to 2.0.2.

Special thanks to Justin Plock, Cesar Alvernaz, Zack Manning, and Cosmin
Marginean for their bug reports and pull requests.

Features:

Option to temporarily queue commands when maxConnections is reached -
<a href="https://github.com/basho/riak-java-client/issues/510">https://github.com/basho/riak-java-client/issues/510</a>
Made mocking easier with K/V commands -
<a href="https://github.com/basho/riak-java-client/pull/528">https://github.com/basho/riak-java-client/pull/528</a>
Improved JavaDocs for Search and MapReduce -
<a href="https://github.com/basho/riak-java-client/pull/524">https://github.com/basho/riak-java-client/pull/524</a>
Added Reset Bucket Properties Command -
<a href="https://github.com/basho/riak-java-client/pull/522">https://github.com/basho/riak-java-client/pull/522</a>
Upgraded Animal Sniffer Maven Plugin -
<a href="https://github.com/basho/riak-java-client/pull/514">https://github.com/basho/riak-java-client/pull/514</a>

Bugfixes:

Fixed Java 6 Runtime Compatibility -
<a href="https://github.com/basho/riak-java-client/pull/530">https://github.com/basho/riak-java-client/pull/530</a>
Partially fixed missing No UnknownHostException, added logging -
<a href="https://github.com/basho/riak-java-client/pull/529">https://github.com/basho/riak-java-client/pull/529</a>
Fixed Java 8 Build Support - <a href="https://github.com/basho/riak-java-client/pull/517">https://github.com/basho/riak-java-client/pull/517</a>
Removed dependency on Sun Tools jar -
<a href="https://github.com/basho/riak-java-client/pull/517">https://github.com/basho/riak-java-client/pull/517</a>
Fixed an inconsistency of visibility at secondary index query.response.get
entries - <a href="https://github.com/basho/riak-java-client/pull/515">https://github.com/basho/riak-java-client/pull/515</a>
Fixed an inconsistency in StringBinIndex.named()returning type -
<a href="https://github.com/basho/riak-java-client/pull/511">https://github.com/basho/riak-java-client/pull/511</a>

Cheers,
Alex Moore
