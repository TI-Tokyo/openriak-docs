Riak Recap for November 15 - 24
========================

1) nlf&#x27;s &quot;simple-riak&quot; hit 0.1.3 a few days back.

* Code here ---&gt; <a href="https://npmjs.org/package/simpleriak">https://npmjs.org/package/simpleriak</a>

2) Suvash Thapaliya wrote a blog post about using Vagrant and Riak.

* Read here ---&gt;
<a href="http://suvashthapaliya.com/blog/2012/11/riak-multi-node-cluster-setup-for-development-environment-with-vagrant/">http://suvashthapaliya.com/blog/2012/11/riak-multi-node-cluster-setup-for-development-environment-with-vagrant/</a>

3) RiakOn, &quot;hosted Riak that rocks&quot;, was just announced.

* Site here ---&gt; <a href="http://riakon.com/">http://riakon.com/</a>
* Blog post from the team about the service ---&gt;
<a href="http://riakon.com/blog#2012_11_10">http://riakon.com/blog#2012_11_10</a>

4) Logstash has experimental Riak support.

* Details here ---&gt; <a href="http://logstash.net/docs/1.1.5/outputs/riak">http://logstash.net/docs/1.1.5/outputs/riak</a>

5) I just stumbled onto a few blogs from deepakmdass that should be
worthwhile to some of you.

* Hiera-HTTP and Riak ---&gt;
<a href="http://beingasysadmin.wordpress.com/2012/11/24/hiera-http-and-riak/">http://beingasysadmin.wordpress.com/2012/11/24/hiera-http-and-riak/</a>
* Logstash and Riak ---&gt;
<a href="http://beingasysadmin.wordpress.com/2012/10/25/using-riak-with-logstash/">http://beingasysadmin.wordpress.com/2012/10/25/using-riak-with-logstash/</a>

6) Gideon de Kok just released Raiku, &quot;a non-blocking - Akka IO driven
- Riak client for Scala with a cute DSL&quot;. This looks quite useful.

* Code here ---&gt; <a href="https://github.com/gideondk/Raiku">https://github.com/gideondk/Raiku</a>

7) CarrotCornCat wrote some code to make Riak usable with the
Sprockets library.

* Code here ---&gt; <a href="https://github.com/CarrotCornCat/sprockets-cache-riak">https://github.com/CarrotCornCat/sprockets-cache-riak</a>
