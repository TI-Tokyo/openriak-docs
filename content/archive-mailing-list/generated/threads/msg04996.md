are not enabled in your Riak installation. You can disable them in the
test suite by doing:

$ SKIP_SEARCH=1 SKIP_LUWAK=1 python setup.py test

You also seem to be running into a problem with leftover keys in one
of the test buckets. That problem is fixed by pull request #67, which
has not been merged :-( ... if you grab that fix, then a couple of
your errors will go away.

I see some additional failures based on extra siblings... I don&#x27;t know
what is happening there.

and the python client has not been updated appropriately yet. In the
meantime, you can add the option:
{delete_mode, immediate} to the riak_kv section of app.config of Riak. This
should allow all of the tests to pass. You can read more about the changes
in the release notes here
<a href="https://github.com/basho/riak/blob/master/RELEASE-NOTES.org">https://github.com/basho/riak/blob/master/RELEASE-NOTES.org</a> under the Delete
Changes heading.

Hope this helps.
