We are overjoyed to announce the final release of Riak 2.0.0.

The documentation page &lt;<a href="http://docs.basho.com/riak/latest/">http://docs.basho.com/riak/latest/</a>&gt; has been
completely redone and updated for 2.0, so please see that for the most
complete information on 2.0. A full listing of the new features in 2.0,
along with links to all the relevant docs, can be found in Intro to 2.0
&lt;<a href="http://docs.basho.com/riak/latest/intro-v20/">http://docs.basho.com/riak/latest/intro-v20/</a>&gt;, while a guide to upgrading
to version 2.0 can be found in our 2.0 upgrade guide
&lt;<a href="http://docs.basho.com/riak/latest/upgrade-v20/">http://docs.basho.com/riak/latest/upgrade-v20/</a>&gt;.

Downloads can also be found on the documentation page
&lt;<a href="http://docs.basho.com/riak/latest/downloads/">http://docs.basho.com/riak/latest/downloads/</a>&gt;, and Apt/Yum repositories
can be found on our packagecloud.io page
&lt;<a href="https://packagecloud.io/basho/riak">https://packagecloud.io/basho/riak</a>&gt;.

The complete release notes for 2.0.0 can be found on GitHub
&lt;<a href="https://github.com/basho/riak/blob/riak-2.0.0/RELEASE-NOTES.md">https://github.com/basho/riak/blob/riak-2.0.0/RELEASE-NOTES.md</a>&gt;.

There are roughly 700 people in our THANKS file, and about 30 tags were
made for 2.0 from the first “pre” to now. We appreciate both the patience
and the feedback of all of Riak’s users through this long release cycle.

<blockquote>From the entire Basho team, thanks!
