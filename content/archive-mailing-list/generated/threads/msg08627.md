Hi,

It is the Java client which to be honest, doesn&#x27;t handle well one
node going down, so, for example, in my company we use HA proxy for
that, here is a starting configuration: <a href="https://gist.github.com/1507077">https://gist.github.com/1507077</a>

Once we switched to HA proxy we just use a simple client without
cluster config, so the Java client doesn&#x27;t know anything about the load
balancing going on. It works well, I can upgrade and restart servers
without our Java application be complaining.

Regards,

Guido.
