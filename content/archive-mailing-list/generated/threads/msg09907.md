Riak Recap for January 15 - 28
=======================

1) Basho is sponsoring the ErlangDC event that&#x27;s happening February
9th.  You should go.

* Details and tickets here ---&gt; <a href="http://erlangdc.com/">http://erlangdc.com/</a>

2) myfinder released some new Perl code for testing Riak.

* Code here ---&gt; <a href="https://github.com/myfinder/p5-test-riak">https://github.com/myfinder/p5-test-riak</a>

looking for feedback on which query method is faster for his use case.

* Read here ---&gt;
<a href="http://www.cranialpulse.com/2013/01/riak-whats-faster-2i-or-key-filters.html">http://www.cranialpulse.com/2013/01/riak-whats-faster-2i-or-key-filters.html</a>

4) The team at Klarna just released some Riak-flavored code.

<a href="https://github.com/klarna/krc">https://github.com/klarna/krc</a>
