Riak Recap for November 18 - December 3
===============================

We announced version 1.4.3 of Riak CS.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-November/014099.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-November/014099.html</a>

The team at Element84 wrote a blog post about spinning up a Riak cluster
with Vagrant.
- <a href="http://www.element84.com/dry-up-your-vagrant-files.html">http://www.element84.com/dry-up-your-vagrant-files.html</a>

Hashnuke published a blog about using Riak Search 2.0. He also tweeted a
script for running Riak Search on Digital Ocean VMs.
- <a href="http://akash.im/2013/11/28/riak20-yokozuna-preview-elixir-erlang.html">http://akash.im/2013/11/28/riak20-yokozuna-preview-elixir-erlang.html</a>
- <a href="https://twitter.com/HashNuke/status/407445595234631680">https://twitter.com/HashNuke/status/407445595234631680</a>

There&#x27;s some Riak (and Webmachine) hacking happening this Saturday at
ErlangDC.
- <a href="http://www.eventbrite.com/e/erlang-dc-r13b-tickets-7565878747?ref=estw">http://www.eventbrite.com/e/erlang-dc-r13b-tickets-7565878747?ref=estw</a>

Wampum released a new node.js client for Riak called &quot;Riakor.&quot;
- <a href="https://github.com/wampum/riaktor">https://github.com/wampum/riaktor</a>

More from the Node.js community: David Keijser released &quot;riak-genesis&quot;, a
tool to seed a riak database with data defined in a javascript DSL.
- <a href="https://npmjs.org/package/riak-genesis">https://npmjs.org/package/riak-genesis</a>

MvM wrote up some details on a new branch of LevelDB (now in master) that
addresses some delete/compaction issues.
- <a href="https://github.com/basho/leveldb/wiki/Mv-aggressive-delete">https://github.com/basho/leveldb/wiki/Mv-aggressive-delete</a>

Neil Soman put together a blog post that discusses the “Scalable Walrus”
component of Eucalyptus (backed by Riak CS).
-
<a href="http://neilsoman.blogspot.com/2013/11/introducing-scalable-walrus-tech-preview.html">http://neilsoman.blogspot.com/2013/11/introducing-scalable-walrus-tech-preview.html</a>

Tom posted a slide deck from a recent talk he and Cmeik gave at Erlang
Factory Lite in Toronto.
- <a href="https://speakerdeck.com/tsantero/choose-your-own-consistency">https://speakerdeck.com/tsantero/choose-your-own-consistency</a>

Information Week ran a piece on The Weather Channel&#x27;s usage of Riak.
-
<a href="http://www.informationweek.com/big-data/software-platforms/big-data-reshapes-weather-channel-predictions/">http://www.informationweek.com/big-data/software-platforms/big-data-reshapes-weather-channel-predictions/</a>

Basho CTO Justin Sheehy did an interview with Cloudpro about Basho, Riak,
and Riak CS.
- <a href="http://www.cloudpro.co.uk/paas/3579/qa-justin-sheehy-cto-basho/">http://www.cloudpro.co.uk/paas/3579/qa-justin-sheehy-cto-basho/</a>

Hector and John wrote a blog post about the current state of Riak and Cloud
Foundry.
- <a href="http://basho.com/leveraging-riak-with-cloud-foundry/">http://basho.com/leveraging-riak-with-cloud-foundry/</a>

Basho Hacker Kota Uenishi posted a slide deck from a recent talk he gave
about the new consistency work coming in 2.0. (This one is in Japanese.)
-
<a href="https://speakerdeck.com/kuenishi/a-new-concept-of-consistency-in-distributed-database-and-implementation-in-riak">https://speakerdeck.com/kuenishi/a-new-concept-of-consistency-in-distributed-database-and-implementation-in-riak</a>

<a href="http://www.meetup.com/Chicago-Riak-Meetup/events/151516252/">http://www.meetup.com/Chicago-Riak-Meetup/events/151516252/</a>
- Basho will be at Open Source 2013 happening in Tokyo on December 13th:
<a href="http://www.ospn.jp/osc2013.enterprise/">http://www.ospn.jp/osc2013.enterprise/</a>
