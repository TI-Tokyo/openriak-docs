Riak Recap for May 04 - 05
====================

1) Basho Hacker Rusty Klophaus will be giving a &quot;Getting Started with
Riak&quot; talk at the Arlington/DC Erlang User Group on May 17.

* Details and registration info here ---&gt;
<a href="http://www.meetup.com/erlang/events/17550721/">http://www.meetup.com/erlang/events/17550721/</a>

2) Runar Jordan (@runarj) just posted a blog called &quot;Why Riak.&quot;

* Read here ---&gt; <a href="http://blog.epigent.com/2011/05/why-riak.html">http://blog.epigent.com/2011/05/why-riak.html</a>

Thanks, Runar!

3) Verion 0.4.0rc2 of riak-js was just released, complete with new
code, bug fixes, and updated docs.

* All the details here ---&gt;
<a href="http://twitter.com/#!/riakjs/statuses/66259374556979200">http://twitter.com/#!/riakjs/statuses/66259374556979200</a>

Also, @frank06 et al are actively looking for contributors on this
project, so if you want to get involved, shoot Francisco a message.

4) Sean Cribbs gave a Riak-js talk at NodeConf yesterday in Portland.

* Slides, code, and login credentials for a the sample app he used
during the talk are here ---&gt;
<a href="http://twitter.com/#!/seancribbs/statuses/66289362836520961">http://twitter.com/#!/seancribbs/statuses/66289362836520961</a>

5) Eric Moritz released a new chunk of code yesterday called
&quot;riak-streaming&quot;. This one is &quot;an experimental project to attempt to
reproduce Hadoop Streaming with Riak&quot; and is definitely worth a look.

Code is here on GitHub ---&gt; <a href="https://github.com/ericmoritz/riak-streaming">https://github.com/ericmoritz/riak-streaming</a>

Thanks, Eric!

6) Alvaro Videla (@old_sound) just released an app called
&quot;Rabbitmq-chat&quot;. Though it doesn&#x27;t use Riak, it is inspired by Sean
Cribbs&#x27; &quot;YakRiak&quot;, so I thought I would include it. I also happen to
know that Alvaro isn&#x27;t the only Rabbit-MQ fan on this mailing list.

* Code here ---&gt; <a href="https://github.com/videlalvaro/rabbitmq-chat">https://github.com/videlalvaro/rabbitmq-chat</a>

7) One Job for today:

* Nerve.com in NYC is looking for a &quot;Creative Web Developer&quot; with Riak
experience. ---&gt;
<a href="http://careers.stackoverflow.com/jobs/11482/nerve-com-is-seeking-a-creative-web-developer-nerve-com">http://careers.stackoverflow.com/jobs/11482/nerve-com-is-seeking-a-creative-web-developer-nerve-com</a>
