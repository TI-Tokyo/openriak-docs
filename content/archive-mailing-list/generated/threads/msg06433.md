We are pleased to announce the release of the Riak Java client 1.0.3.
This is a bug fix release. Please see the
CHANGELOG&lt;<a href="https://github.com/basho/riak-java-client/blob/1.0.3/CHANGELOG">https://github.com/basho/riak-java-client/blob/1.0.3/CHANGELOG</a>&gt;
 for full list of changes in Riak Java client 1.0.3.

The 1.0.3 Java client is available from Maven Central. Add the dependency
to your pom.xml:

&lt;dependency&gt;
  &lt;groupId&gt;com.basho.riak&lt;/groupId&gt;
  &lt;artifactId&gt;riak-client&lt;/artifactId&gt;
  &lt;version&gt;1.0.3&lt;/version&gt;
  &lt;type&gt;pom&lt;/type&gt;
&lt;/dependency&gt;

*You can also download the client .jar (and dependencies) from github.
*&lt;<a href="https://github.com/basho/riak-java-client/downloads">https://github.com/basho/riak-java-client/downloads</a>&gt;

If you prefer your client in source form, the source code can be cloned
from our GitHub repo &lt;<a href="https://github.com/basho/riak-java-client">https://github.com/basho/riak-java-client</a>&gt; and 1.0.3
can be fetched by checking out the
riak-1.0.3&lt;<a href="https://github.com/basho/riak-java-client/tree/1.0.3">https://github.com/basho/riak-java-client/tree/1.0.3</a>&gt;
 tag.

As always, thanks for being the best community anywhere!
-Basho
