Riak Recap for May 28 - 31
====================

1) Patrick Durusau posted a few observations about Riak Core on his blog.

* Read here ---&gt; <a href="http://tm.durusau.net/?p=11050">http://tm.durusau.net/?p=11050</a>

2) We merged some code from rappazzo into the Java client that added a
getLinks() method to the Protocol Buffers interface.

* Details here ---&gt; <a href="https://github.com/basho/riak-java-client/pull/25">https://github.com/basho/riak-java-client/pull/25</a>

Thanks, rappazzo!

3) Jon Langevin released a PHP client for Riak (based on the official
Riak Python client) that is tailor made for the Yii Framework.

* Repo on BitBucket ---&gt; <a href="https://bitbucket.org/intel352/riiak">https://bitbucket.org/intel352/riiak</a>
* More details on the Yii Framework integration ---&gt;
<a href="http://www.yiiframework.com/extension/riiak/">http://www.yiiframework.com/extension/riiak/</a>

Thanks, Jon!

4) Basho Developer Advocate Grant Scofield is giving an &quot;Intro to
Riak&quot; talk at the Dallas Big Data Meetup on June 9th.

* Details and registration here ---&gt;
<a href="http://www.dfwbigdata.org/events/17758631/?a=socialmedia&amp;eventId=17758631&amp;action=detail">http://www.dfwbigdata.org/events/17758631/?a=socialmedia&amp;eventId=17758631&amp;action=detail</a>

5) Mathias Meyer just posted the slides he used for the talk he
delivered earlier today at RailWayCon.

* Check them out here ---&gt; <a href="http://nosql-railswaycon-2011.heroku.com/#1">http://nosql-railswaycon-2011.heroku.com/#1</a>

<a href="http://jobs.github.com/positions/4ff16efc-8c80-11e0-9d4e-7ebd55a85777">http://jobs.github.com/positions/4ff16efc-8c80-11e0-9d4e-7ebd55a85777</a>
