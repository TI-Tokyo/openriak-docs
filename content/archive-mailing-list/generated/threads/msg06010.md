Because Protocol Buffers (or gzipped-JSON for that matter) is a binary
format, it&#x27;s unlikely that it will conform with the UTF-8 charset, which is
currently required to send the data over into the Javascript VM. Our
version of Spidermonkey doesn&#x27;t yet have support for Buffer or any other
means of working directly with binary data, so it must be UTF-8 (since we
convert the riak_object record into a JSON form before invoking).
