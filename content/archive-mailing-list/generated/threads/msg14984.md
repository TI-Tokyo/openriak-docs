Feature:

* Instrumentation: if the `instrumentable` gem is loaded, the client exposes
  several event hooks to `ActiveSupport::Notifications`. Read the README for
  more information, and if you&#x27;d like other events to be instrumented, please
  file GitHub issues. Instrumentation was developed by Ryan Daigle.
* Use Beefcake 1.0 for Protocol Buffers. This Beefcake release fixes a memory
  usage issue with JRuby, and has fixed and simplified character encoding
support.

Bugfix:

* URI escaping now uses the CGI escaper. Thanks to Sean McKibben for
  reporting this bug.

The gem is available at: <a href="https://rubygems.org/gems/riak-client/versions/1.4.5">https://rubygems.org/gems/riak-client/versions/1.4.5</a>
