<blockquote>Hi All,

Imagine that I store &quot;some_item&quot; with key &quot;some_key&quot; into a &quot;products&quot; bucket
with a category &quot;whatever&quot; and a price &quot;300&quot;.
I save it using cURL like this:

$data = &#x27;some_item&#x27;;
$key = &#x27;some_key&#x27;;
$bucket = &#x27;products&#x27;;
curl_setopt($curl, CURLOPT_HTTPHEADER, array(&quot;x-riak-index-price_int:
300&quot;, &quot;x-riak-index-categroy_bin: whatever&quot;));
curl_setopt($curl, CURLOPT_URL,
&quot;<a href="http://{$riakserver}:8098/riak/{$bucket}/{$key}">http://{$riakserver}:8098/riak/{$bucket}/{$key}</a>&quot;;);
$method = &#x27;PUT&#x27;;
[...]

It works great and &quot;GET
<a href="http://{$riakserver}:8098/buckets/products/index/category_bin/whatever">http://{$riakserver}:8098/buckets/products/index/category_bin/whatever</a>&quot;; give
the correct data:

{&quot;keys&quot;: [&quot;some_key&quot;]}

Now my question is... if i want to UPDATE the &quot;price&quot; from 300 to 400 but at
this moment i don&#x27;t know the &quot;category&quot;... how do i retrieve which indexes
are set for a key? so I can update &quot;price&quot; and don&#x27;t lose &quot;category&quot;.

If I do &quot;GET <a href="http://{$riakserver}:8098/riak/products/some_key">http://{$riakserver}:8098/riak/products/some_key</a>&quot;; I just get
&quot;some_item&quot; that is the data stored in the object, but I&#x27;m unable to see its
indexes.
</blockquote>
I don&#x27;t know if there&#x27;s a better way, but you can always store the secondary
index items in the value for that key. Use JSON or something to aggregate
multiple items for the value, then looking up the key gives you the price in
addition to &quot;some_item&quot;.

-Nate
