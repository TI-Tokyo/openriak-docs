Everyone at Basho is extremely happy to announce the public availability of
Riak 2.0.0 RC. As a release candidate, we do not recommend using it in
production, but it should be considered feature and API complete for Riak
2.0 final. We reserve the right to make changes for any data-loss or severe
performance issues found post-RC, but these will not affect the API.

This is our most ambitious release, with major new features throughout the
product. With that in mind, please take plenty of time to read through the
Release Notes. There are some important considerations regarding upgrades,
known issues, and packaging. The Release Notes are still a work-in-progress
and will be continually updated as we march towards 2.0 final. We have made
a lot of progress on our docs site &lt;<a href="http://docs.basho.com">http://docs.basho.com</a>&gt; for 2.0, but
still have work to do before final release. We appreciate your patience.

   -

   *Release Notes*: <a href="https://github.com/basho/riak/blob/2.0/RELEASE-NOTES.md">https://github.com/basho/riak/blob/2.0/RELEASE-NOTES.md</a>
    -

   *Downloads*: <a href="http://docs.basho.com/riak/2.0.0/downloads/">http://docs.basho.com/riak/2.0.0/downloads/</a>
   Note: There will be minor tweaks to the download site to show the labels
   for SuSE Enterprise Linux and Ubuntu 14.04 packages
    -

   *APT/YUM Repos* (see release-notes re: this change):
   <a href="https://packagecloud.io/basho/riak/install">https://packagecloud.io/basho/riak/install</a> Note: If you are downloading
   the files directly, use our docs site. For apt/yum repo install, use
   packagecloud.

Thanks to everyone in our community,
-Team Basho
