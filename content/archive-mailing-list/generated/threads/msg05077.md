The Basho Team has been hard at work on some new documentation and
revisions for the new release. Instead of burying these in a Recap, we
thought they warranted their own email.

And we&#x27;ll be working on more, so stay tuned. Be sure to file issues or
pull requests against the wiki repo (a) if you&#x27;ve got something to
contribute.

Mark

a - <a href="https://github.com/basho/riak_wiki">https://github.com/basho/riak_wiki</a>
----

1 - Backends - We&#x27;ve updated the existing Bitcask and Innostore pages,
and have added in-depth documentation for the other supported backend
options:

* LevelDB - <a href="http://wiki.basho.com/LevelDB.html">http://wiki.basho.com/LevelDB.html</a>
* Memory Backend ---&gt; <a href="http://wiki.basho.com/Memory.html">http://wiki.basho.com/Memory.html</a>
* Multi Backend ---&gt; <a href="http://wiki.basho.com/Multi.html">http://wiki.basho.com/Multi.html</a>
* Bitcask ---&gt; <a href="http://wiki.basho.com/Bitcask.html">http://wiki.basho.com/Bitcask.html</a>
* Innostore ---&gt; <a href="http://wiki.basho.com/Innostore.html">http://wiki.basho.com/Innostore.html</a>

2 - Indexing and MapReduce

* We&#x27;ve added a lengthy section on Secondary Indexing ---&gt;
<a href="http://wiki.basho.com/Secondary-Indexes.html">http://wiki.basho.com/Secondary-Indexes.html</a>
* The MapReduce page has been updated to reflect new 1.0&#x27;s updates
---&gt; <a href="http://wiki.basho.com/MapReduce.html">http://wiki.basho.com/MapReduce.html</a>

3 - Protocol Buffers API

* The PB API page has been updated and reorganized ---&gt;
<a href="http://wiki.basho.com/PBC-API.html">http://wiki.basho.com/PBC-API.html</a>

4 - Configuration Files

* The Configuration Files page, which covers app.config, vm.args, and
Rebar Overlays, has been revised ---&gt;
<a href="http://wiki.basho.com/Configuration-Files.html">http://wiki.basho.com/Configuration-Files.html</a>
