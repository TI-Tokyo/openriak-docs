New versions of s3cmd uses AWS v4 authentication [1] but Riak CS
does not support it yet [2].
Tentatively, please add following one line to your .s3cfg file:
signature_v2 = True

[1] <a href="https://github.com/s3tools/s3cmd/issues/402">https://github.com/s3tools/s3cmd/issues/402</a>
[2] <a href="https://github.com/basho/riak_cs/issues/897">https://github.com/basho/riak_cs/issues/897</a>

Thanks,
Shino
