Riak Recap for Jan. 14 - 16

1) seancribbs and ossarah had a very brief chat in #riak that started
with &quot;Is there some way, in a map phase, to fetch the object that a
link refers to?&quot;

* Gist here ---&gt; <a href="https://gist.github.com/783629">https://gist.github.com/783629</a>

2) Piotr Nosek has started work on another C Driver for Riak.

* Code on GitHub here ---&gt; <a href="https://github.com/fenek/riak-c-driver">https://github.com/fenek/riak-c-driver</a>

* Added to the wiki here -
<a href="http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html#Client-Libraries-and-Frameworks">http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html#Client-Libraries-and-Frameworks</a>

Thanks, Piotr, for both the code and the wiki updating.

3) There is all sorts of good stuff happening with Luwak and MapReduce.

* Basho Hacker Bryan Fink put together something called &quot;luwak_mr&quot;
which will be a much-appreciated piece of code for anyone who is
trying to run MapReduce jobs over data in Luwak. Repo here ---&gt;
<a href="https://github.com/beerriot/luwak_mr">https://github.com/beerriot/luwak_mr</a>

* He also added a function to Riak Function Contrib for doing
MapReduce over your Luwak data. Function here ---&gt;
<a href="http://contrib.basho.com/luwak_mr.html">http://contrib.basho.com/luwak_mr.html</a>

*For those of you who aren&#x27;t familiar with Luwak, see:
<a href="https://github.com/basho/luwak">https://github.com/basho/luwak</a> and <a href="http://wiki.basho.com/Luwak.html">http://wiki.basho.com/Luwak.html</a>

4) Q --- Does riak support ttl expiration of objects? (from
heckacopter via #riak)

    A --- Yes. See &quot;riak_kv_cache_backend&quot; towards the bottom of
<a href="http://wiki.basho.com/Configuration-Files.html#app.config">http://wiki.basho.com/Configuration-Files.html#app.config</a>

5) Q --- Is it possible to implement transitive closures by link
walking? (from cirwin via #riak)

    A --- Hard to give a definite &quot;no&quot; without knowing exactly what
you&#x27;re trying to do. However, if you&#x27;re trying to compute reachability
between arbitrary objects in constant time using link walking, then
you&#x27;ll probably want a more specialized graph database. Links weren&#x27;t
made to handle these type of algorithms.

6) We have a new bot in #riak. Sean Cribbs wrote and released bashobot
- <a href="https://github.com/basho/bashobot/">https://github.com/basho/bashobot/</a> - and it&#x27;s now up and running in
#riak. Hop into the #riak IRC room on irc.freenode.net and type
&quot;!help&quot; to see it in action or check out the repo&#x27;s README for a
complete list of commands.

7) Justin Sheehy answered a question on Quora about the nature of
buckets in Riak.

Read here ---&gt;
<a href="http://www.quora.com/Riak/How-resource-intensive-is-bucket-in-Riak">http://www.quora.com/Riak/How-resource-intensive-is-bucket-in-Riak</a>
