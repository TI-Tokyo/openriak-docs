Example:

add first :

curl -X PUT -H &quot;content-type:text/plain&quot; \

  <a href="http://localhost:8098/riak/hb/first">http://localhost:8098/riak/hb/first</a> --data &quot;hello&quot;

curl -X PUT -H &quot;content-type: text/plain&quot; \
  -H &quot;Link:&lt;/riak/hb/fourth&gt;; riaktag=\&quot;foo\&quot;&quot; \
  <a href="http://localhost:8098/riak/hb/second">http://localhost:8098/riak/hb/second</a> --data &quot;the second&quot;

curl <a href="http://localhost:8098/riak/hb/first/_,_,_">http://localhost:8098/riak/hb/first/_,_,_</a>

curl <a href="http://localhost:8098/riak/hb/first/_,_">http://localhost:8098/riak/hb/first/_,_</a>,

/riak/some_bucket/some_key/&lt;bucket&gt;,&lt;riaktag&gt;,0|1

What i am missing here ? Some miss-configuration ?

What i changed in app.config was :

{default_bucket_props, [
    {n_val,1},
    {allow_mult,false},
    {last_write_wins,false},
    {precommit, []},
    {postcommit, []},
    {chash_keyfun, {riak_core_util, chash_std_keyfun}},
    {linkfun, {modfun, riak_kv_wm_link_walker, mapreduce_linkfun}}
    ]}

but this are the defaults except n_val imo.
