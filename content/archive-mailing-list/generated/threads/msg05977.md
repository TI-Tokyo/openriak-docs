Riak Recap for December 14 - 15
========================

1) Version 1.0.0.M4 of the Riak GORM plugin is now available. (h/t to
Jon Brisbin for making this happen!)

* Details and code here ---&gt;
<a href="http://twitter.com/grailsplugins/statuses/147341274427559936">http://twitter.com/grailsplugins/statuses/147341274427559936</a>

2) Mathias Meyer wrote another great blog post about Riak. This one is
on storing timelines.

* Read here
---&gt;<a href="http://www.paperplanes.de/2011/12/15/storing-timelines-in-riak.html">http://www.paperplanes.de/2011/12/15/storing-timelines-in-riak.html</a>

3) Andy Gross posted some code and slides from the talk he gave this
week on Erlang and DTrace. (Say goodbye to your weekend.)

* Slides ---&gt; <a href="http://argv0.com/talks/dtrace-erlang/">http://argv0.com/talks/dtrace-erlang/</a>
* Example D scripts for Erlang, Riak-1.0.2+DTrace binaries for OSX,
and Erlang template for Instruments.app ---&gt;
<a href="https://github.com/argv0/dtrace-erlang-bashochat-12142011">https://github.com/argv0/dtrace-erlang-bashochat-12142011</a>

4) For anyone thinking about going to Erlang Factory this March in San
Francisco, Basho DAs Dan Reverri and Ian Plosker will be giving a
three day class all about Riak.

* You&#x27;ll want to go to this ---&gt;
<a href="http://www.erlang-factory.com/conference/SFBay2012/university/RiakTraining">http://www.erlang-factory.com/conference/SFBay2012/university/RiakTraining</a>

5) We fixed up some inaccuracies with the PBC API docs on the wiki.

* Here&#x27;s the commit for anyone who is interested ---&gt;
<a href="https://github.com/basho/riak_wiki/pull/226">https://github.com/basho/riak_wiki/pull/226</a>

6) Shuhao Wu&#x27;s RiakKit project made it onto PyPI

* Code here ---&gt; <a href="http://pypi.python.org/pypi/riakkit/0.1a">http://pypi.python.org/pypi/riakkit/0.1a</a>
