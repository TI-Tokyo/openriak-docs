There have been several issues people have ran into with Riak 2.0 pre&#x27;s and
beta tags due to incompatibilities in different versions of Erlang.  For
2.0 we are building against R16B02, with our own patches put on top of it.
 We are planning on documenting this on the docs page, but that page is not
updated yet.

So, if you&#x27;d like to build 2.0 from source, here is the Erlang you should
build from:

<a href="http://s3.amazonaws.com/downloads.basho.com/erlang/otp_src_R16B02-basho4.tar.gz">http://s3.amazonaws.com/downloads.basho.com/erlang/otp_src_R16B02-basho4.tar.gz</a>

If you&#x27;d like to see our patches, you can see what&#x27;s changed here:

<a href="https://github.com/basho/otp/compare/erlang:maint...OTP_R16B02_basho4">https://github.com/basho/otp/compare/erlang:maint...OTP_R16B02_basho4</a>

Thanks,
Jared
