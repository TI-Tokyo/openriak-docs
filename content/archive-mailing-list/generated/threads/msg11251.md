Riak Recap for May 29 - June 11
------------------------------------------------

Josh Bush wrote up a post about how to get a Riak test cluster up and
running.
- <a href="http://freshbrewedcode.com/joshbush/2013/05/28/riak-dev-cluster-ubuntu/">http://freshbrewedcode.com/joshbush/2013/05/28/riak-dev-cluster-ubuntu/</a>

Julien Genestoux at Superfeedr wrote a blog post about their Riak usage.
- blog.superfeedr.com/google-reader-api-riak/

Will Laurance published another Riak-flavored library. This one is called &quot;
riakvm&quot; and is CLI for building Riak instances.
- <a href="https://github.com/wlaurance/riakvm">https://github.com/wlaurance/riakvm</a>

Tom &quot;Norman Wilson&quot; Santero posted his slide deck from the Atlanta Riak
Meetup.
- <a href="https://speakerdeck.com/tsantero/operating-and-tuning-riak">https://speakerdeck.com/tsantero/operating-and-tuning-riak</a>

Basho Hacker Bryce Kerley managed to get Riak running on the Samsung ARM7
Chromebook.
- <a href="http://blog.brycekerley.net/post/51819560503/riak-on-samsung-arm7-">http://blog.brycekerley.net/post/51819560503/riak-on-samsung-arm7-</a>
chromebook

Byrce also added multi-get to the Riak Ruby Client
- <a href="https://twitter.com/seancribbs/status/344541378560274433">https://twitter.com/seancribbs/status/344541378560274433</a>

Troy Melhase announced Zukai, an ODM for Riak and Node.js.
- <a href="https://github.com/natural/zukai">https://github.com/natural/zukai</a>

Theo Bot released Catalyst::Model::Riak 0.07
- <a href="http://search.cpan.org/~nltbo/Catalyst-Model-Riak/lib/Catalyst/Model/Riak">http://search.cpan.org/~nltbo/Catalyst-Model-Riak/lib/Catalyst/Model/Riak</a>
.pm

John Liao wrote a blog post about using MapReduce with CorrugatedIron.
- <a href="http://jyliao.blogspot.com/2013/06/riak-mapreduce-with-f.html">http://jyliao.blogspot.com/2013/06/riak-mapreduce-with-f.html</a>

Pedro Teixeira and the CrowdProcess team released a new protocol buffers
client for Node.js.
- <a href="https://github.com/CrowdProcess/riak-pb">https://github.com/CrowdProcess/riak-pb</a>

Basho Hacker Eric Redmond was on the Tea Hour podcast talking about
Riakand other, lesser-known databases.
- <a href="http://teahour.fm/2013/06/03/databases-with-eric-redmond.html">http://teahour.fm/2013/06/03/databases-with-eric-redmond.html</a>

Bryce also added multi-get to the Riak Ruby Client
- <a href="https://twitter.com/seancribbs/status/344541378560274433">https://twitter.com/seancribbs/status/344541378560274433</a>

Basho Hacker Ryan Zezeski posted slides from his &quot;Yokozuna, Scaling Solrwith
Riak&quot; talk at Berlin Buzzwords.
- <a href="https://speakerdeck.com/rzezeski/yokozuna-scaling-solr-with-riak">https://speakerdeck.com/rzezeski/yokozuna-scaling-solr-with-riak</a>

Basho Hacker John Burwell is giving a talk on Riak CS and Cloudstack at the
next Silicon Valley Riak Meetup. This one is happening on June 26th.
- <a href="http://www.meetup.com/Silicon-Valley-Riak/events/124134742/">http://www.meetup.com/Silicon-Valley-Riak/events/124134742/</a>

We just announced a Riak Meetup in Baltimore. The tentative date for this

- <a href="http://www.meetup.com/Baltimore-Riak-Meetup/">http://www.meetup.com/Baltimore-Riak-Meetup/</a>
