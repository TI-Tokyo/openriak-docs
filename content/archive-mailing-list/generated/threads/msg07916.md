Riak Recap for June 29 - July 11
========================

1) Basho Hacker Russell Brown wrote a blog post about the new stats code
that will be in Riak 1.2.

* Read here ---&gt;
<a href="http://basho.com/blog/technical/2012/07/02/folsom-backed-stats-riak-1-2/">http://basho.com/blog/technical/2012/07/02/folsom-backed-stats-riak-1-2/</a>

eventually target Riak.

* Code here ---&gt; <a href="https://github.com/bkerley/hanover">https://github.com/bkerley/hanover</a>

5) Lots of great stuff coming via the team at Boundary:

* Ray Jenkins wrote a blog post about how they use Scala with Riak ---&gt;
<a href="http://blog.boundary.com/2012/07/09/reusable-patterns-for-riak-in-scala/">http://blog.boundary.com/2012/07/09/reusable-patterns-for-riak-in-scala/</a>

known) ---&gt; <a href="https://github.com/rjenkins/riak-scala-dao">https://github.com/rjenkins/riak-scala-dao</a>
* AND they announced a new round of funding. Congrats to the team! ---&gt;
<a href="http://blog.boundary.com/2012/07/10/big-day-for-boundary-15m-in-new-funding/">http://blog.boundary.com/2012/07/10/big-day-for-boundary-15m-in-new-funding/</a>

blog post about how (and why) to use it.

* Read here --&gt;
<a href="http://blog.gogrid.com/2012/07/09/create-a-basho-riak-cluster-on-gogrid/">http://blog.gogrid.com/2012/07/09/create-a-basho-riak-cluster-on-gogrid/</a>

Webmachine, and ErlyDTL blog series. This one did not disappoint.

* Read here ---&gt;
<a href="http://buffered.io/posts/webmachine-erlydtl-and-riak-part-5/">http://buffered.io/posts/webmachine-erlydtl-and-riak-part-5/</a>

<a href="http://www.infoq.com/presentations/Knockbox-an-Eventual-Consistency-Toolkit">http://www.infoq.com/presentations/Knockbox-an-Eventual-Consistency-Toolkit</a>
