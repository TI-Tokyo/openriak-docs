I&#x27;m happy to announce the 0.9.0 release of riak-js, the Riak client for
Node.js. It&#x27;s a complete rewrite in plain old JavaScript, bringing some new
functionality along the way. You can read all about the fresh release over on
the Basho blog [1].

riak-js now has a new home [2] and fully updated documentation [3].

Let me know if you run into any issues or have any questions!

npm install riak-js@0.9.0 and off you go!

Happy JavaScripting!

Cheers, Mathias
