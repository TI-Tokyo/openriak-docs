We have an updated release candidate for Riak 1.3.0 (RC2).

It is available for download here:
<a href="http://docs.basho.com/riak/1.3.0rc2/downloads/">http://docs.basho.com/riak/1.3.0rc2/downloads/</a>

The items changed for RC2 are below and are reflected in the release notes:
<a href="https://github.com/basho/riak/blob/1.3/RELEASE-NOTES.md">https://github.com/basho/riak/blob/1.3/RELEASE-NOTES.md</a>

   -  Permissions not checked on $PIPE_DIR in riak script:
   <a href="https://github.com/basho/riak/issues/192">https://github.com/basho/riak/issues/192</a>
   -  convert LRUCache from LRU to simple fifo:
   <a href="https://github.com/basho/leveldb/pull/71">https://github.com/basho/leveldb/pull/71</a>
   -  Take node liveness into account during contant hash choice for reduce
   phase:  <a href="https://github.com/basho/riak_kv/issues/476">https://github.com/basho/riak_kv/issues/476</a> - Thanks Gunin
   Alexander
   -  Improve interaction between AAE and K/V deletion:
   <a href="https://github.com/basho/riak_kv/pull/478">https://github.com/basho/riak_kv/pull/478</a>

Thanks for the continued support,
-Basho
