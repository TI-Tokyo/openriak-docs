It should be noted however that this is not ideal usage of Riak; There&#x27;s a
reason that examples of this type of behavior are not easy to find. If /
when postcommit hooks fail, you will get almost no notice that such a
failure occurred because the PUT to the bucket which has the commit hook
will return a success to the client whether or not the commit hook succeeds.
