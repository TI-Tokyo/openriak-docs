users.

using &quot;Bucket Policies&quot; to automatically set public access.

<a href="https://gist.github.com/alexmoore/5909408">https://gist.github.com/alexmoore/5909408</a>, and then you could apply the policy
using s3cmd: s3cmd -c .s3cfg setpolicy public-access-bucket-policy.json
