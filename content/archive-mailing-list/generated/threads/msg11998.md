On behalf of Basho, I&#x27;m excited to announce that Riak CS 1.4.0 is now official. Riak CS is Basho&#x27;s open source cloud storage software.

The biggest feature additions are support for the Swift API and Keystone authentication, which enables CS to be a drop-in storage replacement for OpenStack deployments. We also fixed numerous bugs, including query string authentication for multi-part uploads and better connection handing of transient Riak failures.

* The full release notes can be found here: <a href="http://git.io/xlL8uw">http://git.io/xlL8uw</a>

The Riak CS docs have been updated accordingly:

* The 1.4.0 packages are here: <a href="http://docs.basho.com/riakcs/latest/riakcs-downloads/">http://docs.basho.com/riakcs/latest/riakcs-downloads/</a>
* Full documentation is here: <a href="http://docs.basho.com/riakcs/latest/">http://docs.basho.com/riakcs/latest/</a>
* Rolling upgrade docs are here: <a href="http://docs.basho.com/riakcs/latest/cookbooks/Rolling-Upgrades-For-Riak-CS/">http://docs.basho.com/riakcs/latest/cookbooks/Rolling-Upgrades-For-Riak-CS/</a>

In addition to the release notes, we have a full overview of the release on the Basho Blog. We&#x27;re also doing a webcast on August 23rd for anyone is interested in attending.

* Blog post: <a href="http://basho.com/riak-cs-1-4-is-now-available/">http://basho.com/riak-cs-1-4-is-now-available/</a>
* Webcast details and registration: <a href="http://info.basho.com/RiakCS1.4_Aug23.html">http://info.basho.com/RiakCS1.4_Aug23.html</a>

Let us know if you have any questions, comments, or issues. Thanks to everyone who made this release possible with their usage, bug reports, and contributions. As usual, we couldn&#x27;t have shipped this without you. And be sure to grab your ticket for RICON West - ricon.io/west.html - to hack on Riak and Riak CS alongside the Basho team and community this October in San Francisco.

Best,

Seth and the Basho Team
