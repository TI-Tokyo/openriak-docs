Most git servers use port 9418. If you are able to open that port on
your firewall it should work. Alternatively if you look for files in the riak
directory and its subdirectories called &#x27;rebar.config&#x27; and edit those and
change the git urls to be &quot;<a href="http://">http://</a>...&quot;; instead of &quot;git://...&quot; then it should
use port 80 to clone the needed repos instead of 9418. Hopefully one of those
will get you up and running. Cheers.

Kelly
</div></div></details></li><li class="mailing-list-reply"><details id="msg07341" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Jared Morrow</span><time datetime="2012-04-27T21:17:38-07:00">April 27, 2012 at 9:17 PM</time><span class="mailing-list-message__subject">Re: Issue with Riak Install from Source under SUSE SLES 11 SP11	Version S390</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">Claude,

The issue is not in the rebar.config file for eleveldb, but in a file that
fetches the original C++ source for leveldb.   To fix your issue, simply unpack
the riak source as you already did then:

$ cd deps/eleveldb

And then make the following changes to &#x27;c_src/build_deps.sh&#x27;:

--- c_src/build_deps.sh.orig    2012-04-27 22:06:31.000000000 -0600
+++ c_src/build_deps.sh 2012-04-27 22:07:49.000000000 -0600
@@ -37,7 +37,7 @@
         export LD_LIBRARY_PATH=&quot;$BASEDIR/system/lib:$LD_LIBRARY_PATH&quot;

         if [ ! -d leveldb ]; then
-            git clone git://github.com/basho/leveldb
+            git clone <a href="http://github.com/basho/leveldb">http://github.com/basho/leveldb</a>
             (cd leveldb &amp;&amp; git checkout $LEVELDB_VSN)
         fi

Then return to the top-level source directory for Riak and run &#x27;make&#x27; and
things should be better.

-Jared
