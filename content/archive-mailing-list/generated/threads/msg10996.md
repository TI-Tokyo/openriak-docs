Riak Recap for April 27 - April 30
=======================

We posted some details about how Ingo and the team at Qeep are using Riak to
power message storage for their the fast-growing social network.
- <a href="http://basho.com/riak-at-qeep-the-global-social-network/">http://basho.com/riak-at-qeep-the-global-social-network/</a>

Library of Erlang utility functions for Riak MapReduce. Contains useful
functions for getting the size of the object stored, performing read-repair,
and executing deletes
- <a href="https://github.com/whitenode/riak_mapreduce_utils">https://github.com/whitenode/riak_mapreduce_utils</a>

Sean Cribbs posted his &quot;Data Structures in Riak&quot; slides from NoSQL Matters
Cologne. There&#x27;s also some sample code.
- <a href="https://twitter.com/seancribbs/status/327797359444623360">https://twitter.com/seancribbs/status/327797359444623360</a>

A Clojure web service prototype of the Epochal Time Model leveraging Riak and
Zookeeper
- <a href="https://github.com/gerardc/remi">https://github.com/gerardc/remi</a>

Numan released python code called Sunspear which is purpose-built for activity
streams backed by Riak
- <a href="https://pypi.python.org/pypi/sunspear/0.1.2">https://pypi.python.org/pypi/sunspear/0.1.2</a>
