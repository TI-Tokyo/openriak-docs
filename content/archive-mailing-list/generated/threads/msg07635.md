Riak Recap for May 21 - June 6
=======================

1) Tom Santero gave talk at GOTO Copenhagen a few weeks back called Riak in
the Cloud.

* Slides here ---&gt; <a href="http://www.slideshare.net/tsantero/riak-in-the-cloud">http://www.slideshare.net/tsantero/riak-in-the-cloud</a>

2) hexreel released bottle-riak, a plugin that integrates Riak with Bottle
applications.

* Code here ---&gt; <a href="https://github.com/hexreel/bottle-riak">https://github.com/hexreel/bottle-riak</a>

3) The team at QBranch put together a short blog post about how and why
they are using Riak.

* Blog post ---&gt; <a href="http://blog.frli.se/2012/05/riak-at-qbranch.html">http://blog.frli.se/2012/05/riak-at-qbranch.html</a>
* We also added them to the production users page ---&gt;
<a href="http://basho.com/company/production-users#user-qbranch">http://basho.com/company/production-users#user-qbranch</a> (You, too, could be
on this page....)

4) Basho is sponsoring a round (or three) of drinks at Puppet Camp in
Boston on June 22nd.

* Details here ---&gt; <a href="http://puppetcampboston.eventbrite.com/">http://puppetcampboston.eventbrite.com/</a>

5) Thiago Avelino gave a presentation on Riak Search and released his
slides.

* Check them out here ---&gt;
<a href="http://www.slideshare.net/avelinoo/nosql-for-search-riak">http://www.slideshare.net/avelinoo/nosql-for-search-riak</a>

6) Just before heading on holiday, Mathias Meyer gave a great talk at NoSQL
Matters called Designing for Concurrency with Riak.

* Slides here ---&gt;
<a href="https://speakerdeck.com/u/roidrage/p/designing-for-concurrency-with-riak">https://speakerdeck.com/u/roidrage/p/designing-for-concurrency-with-riak</a>

7) Nam Nguyen wrote a blog post about his first week working with Riak.

* Read here ---&gt;
<a href="http://techualization.blogspot.com/2012/05/one-week-with-riak.html">http://techualization.blogspot.com/2012/05/one-week-with-riak.html</a>

8) Michael Bernstein released a whole bunch of Go and Riak code.

* riakpbc: a Riak PBC client for GO ---&gt; <a href="https://github.com/mrb/riakpbc">https://github.com/mrb/riakpbc</a>
* shoebox: a sample Riak application written in Go ---&gt;
<a href="https://github.com/mrb/shoebox">https://github.com/mrb/shoebox</a>

9) Matt Ranney and the Voxer crew will be talking about using Riak in
Production at the Next SF Riak Meetup.

* Details and registration here ---&gt;
<a href="http://www.meetup.com/San-Francisco-Riak-Meetup/events/68028502/">http://www.meetup.com/San-Francisco-Riak-Meetup/events/68028502/</a>

10) Sean Cribbs gave a talk at Berlin Buzzwords on eventually consistent
data structures and how they might work in Riak.

* Slides here ---&gt;
<a href="http://berlinbuzzwords.de/sites/berlinbuzzwords.de/files/slides/Eventually-Consistent%20Data%20Structures%20(bbuzz12).pdf">http://berlinbuzzwords.de/sites/berlinbuzzwords.de/files/slides/Eventually-Consistent%20Data%20Structures%20(bbuzz12).pdf</a>

11) More new code: Andrea Luzzardi released a statsd plugin for Riak Python
clients.

* Code here ---&gt; <a href="https://github.com/aluzzardi/riak-statsd-python">https://github.com/aluzzardi/riak-statsd-python</a>

12) Ulf Norell and John Hughes (with the help of Scott Lystig Fritchie, Jon
Meredith, and Dave Smith) gave at talk at the recent Erlang User Conference
about testing Riak (and eventual consistency) with QuickCheck.

* Slides here ---&gt;
<a href="http://www.erlang-factory.com/upload/presentations/593/ThePropertiesofRiak.pdf">http://www.erlang-factory.com/upload/presentations/593/ThePropertiesofRiak.pdf</a>

13) George Reese wrote a piece for O&#x27;Reilly about using Riak with Dasein
Persist.

* Read here ---&gt;
<a href="http://broadcast.oreilly.com/2012/05/object-nosql-mapping-for-riak-with-dasein-persist.html">http://broadcast.oreilly.com/2012/05/object-nosql-mapping-for-riak-with-dasein-persist.html</a>

14) Andy Gross&#x27; Riak Use Cases slides from GOTO Amsterdam are online.

* Check them out here ---&gt;
<a href="http://gotocon.com/dl/goto-amsterdam-2012/slides/AndyGross_RiakUseCasesDissectingTheSolutionsToHardProblems.pdf">http://gotocon.com/dl/goto-amsterdam-2012/slides/AndyGross_RiakUseCasesDissectingTheSolutionsToHardProblems.pdf</a>

15) Ilya Bogunov gave a talk on Riak and the video made it online.

* Watch here ---&gt; <a href="https://vimeo.com/42619422">https://vimeo.com/42619422</a>

16) Colin Alston moved over the Twisted Python code he and a few others at
Praekelt are working on to a GitHub repo called riakasaurus.

* Code here ---&gt;  <a href="https://github.com/calston/riakasaurus">https://github.com/calston/riakasaurus</a>
* I also did some snooping on Colin&#x27;s blog and it turns out he was hiding a
few posts about Riak ---&gt; <a href="http://imcol.in/?s=riak+">http://imcol.in/?s=riak+</a>

17) The team at Rakuten released a slide deck about a storage system they
wrote called LeoFS that uses Bitcask.

* Slides here ---&gt;
<a href="http://www.slideshare.net/rakutentech/rakuten-leofs-distributed-file-system">http://www.slideshare.net/rakutentech/rakuten-leofs-distributed-file-system</a>

18) Carlo Scarioni wrote a blog post about using Java to talk to Riak,
MongoDB, Cassandra, Redis and CouchDB.

* Read here ---&gt;
<a href="http://cscarioni.blogspot.co.uk/2012/06/i-had-requirement-in-my-current-job-to.html">http://cscarioni.blogspot.co.uk/2012/06/i-had-requirement-in-my-current-job-to.html</a>
