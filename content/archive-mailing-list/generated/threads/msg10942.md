Riak Recap for April 3 - April 19
=======================

Michael Klishin slipped under the wire for this Recap by announcing
Welle 1.5.0, a Clojure client for Riak
- <a href="http://blog.clojurewerkz.org/blog/2013/04/19/welle-1-dot-5-0-is-released/">http://blog.clojurewerkz.org/blog/2013/04/19/welle-1-dot-5-0-is-released/</a>

Mike McNeil has released a Riak adapter for Sails.js
- <a href="https://npmjs.org/package/sails-riak">https://npmjs.org/package/sails-riak</a>

OJ Reeves and Jeremiah Peschka have released CorrugatedIron 1.3
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-April/011720.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-April/011720.html</a>

The video of Ines Sombra&#x27;s &quot;Riak In The Cloud&quot; talk from Big Nerd Ranch is now
online.
- <a href="https://vimeo.com/63331718">https://vimeo.com/63331718</a>

There will be some Riak and Erlang content at the upcoming Vancouver Polyglot
un-Conference.
- <a href="http://polyglotconf.com/tutorials/">http://polyglotconf.com/tutorials/</a>

cliak is a minimal Command Line Interface (CLI) written in Node for
performing CRUD operations on Riak
- <a href="https://bitbucket.org/csolar/cliak">https://bitbucket.org/csolar/cliak</a>

Andy Gross&#x27; &quot;Riak and Dynamo, Five Years Later&quot; talk from QCon London is now
online.
- <a href="http://www.infoq.com/presentations/riak-dynamo">http://www.infoq.com/presentations/riak-dynamo</a>

Ilja Iwas released a Riak Browser app for OS X
- <a href="https://github.com/iljaiwas/RiakBrowser">https://github.com/iljaiwas/RiakBrowser</a>

Heinz Gies has written a blog post about tests in Riak test
-
<a href="http://blog.licenser.net/blog/2013/04/09/writing-your-first-riak-test-test-yes-i-know-there-are-two-tests-there/">http://blog.licenser.net/blog/2013/04/09/writing-your-first-riak-test-test-yes-i-know-there-are-two-tests-there/</a>

New Basho blog entry: Riak and Syslog
- <a href="http://basho.com/syslog-and-riak-1-3/">http://basho.com/syslog-and-riak-1-3/</a>

Peter Bailis and Ali Ghodsi reference Russell Brown, Sean Cribbs and
riak_dt in a paper on eventual consistency
- <a href="http://queue.acm.org/detail.cfm?id=2462076">http://queue.acm.org/detail.cfm?id=2462076</a>

James Martin contributed a Riak Module to Ansible
- <a href="https://github.com/ansible/ansible/pull/2627">https://github.com/ansible/ansible/pull/2627</a>
