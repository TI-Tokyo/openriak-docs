This looks like a known and since-resolved bug that was in 1.2.0. Riak
Search could get into a state where transfers would never finish and
bad things would happen. See the following:

<a href="http://docs.basho.com/riak/latest/references/Riak-Search---Settings/">http://docs.basho.com/riak/latest/references/Riak-Search---Settings/</a>
<a href="https://github.com/basho/merge_index/pull/24">https://github.com/basho/merge_index/pull/24</a>

Sorry for the lateness. In the event that you&#x27;re still running Riak
and haven&#x27;t upgraded, this is fixed in 1.2.1.
