The Basho wiki states that:
The $key index field is a special field that is implicitly indexed on all
objects when Secondary Indexes is enabled. The value of this field is the
object&#x27;s key, so this field allows an application to perform range queries
across the keys in a bucket.

What is the REST API to use this special field? And what would be the the
corresponding read URI?

I&#x27;ve included a command-line example below that uses the special $key
field.

Note that on the command line, the dollar sign ($) must be escaped with a
backslash, otherwise the shell thinks you are referencing a variable. You
won&#x27;t need to escape the dollar sign using the client libraries.

Best,
Rusty

## Load some data...

curl -v -X PUT -d &#x27;data1&#x27; -H &quot;x-riak-index-field1_bin: val1&quot; \
<a href="http://127.0.0.1:8098/riak/bucket1/key1">http://127.0.0.1:8098/riak/bucket1/key1</a>

curl -v -X PUT -d &#x27;data2&#x27; -H &quot;x-riak-index-field1_bin: val2&quot; \
<a href="http://127.0.0.1:8098/riak/bucket1/key2">http://127.0.0.1:8098/riak/bucket1/key2</a>

curl -v -X PUT -d &#x27;data3&#x27; -H &quot;x-riak-index-field1_bin: val3&quot; \
<a href="http://127.0.0.1:8098/riak/bucket1/key3">http://127.0.0.1:8098/riak/bucket1/key3</a>

curl -v -X PUT -d &#x27;data4&#x27; -H &quot;x-riak-index-field1_bin: val4&quot; \
<a href="http://127.0.0.1:8098/riak/bucket1/key4">http://127.0.0.1:8098/riak/bucket1/key4</a>

curl -v -X PUT -d &#x27;data5&#x27; -H &quot;x-riak-index-field1_bin: val5&quot; \
<a href="http://127.0.0.1:8098/riak/bucket1/key5">http://127.0.0.1:8098/riak/bucket1/key5</a>

## Run a REST-based query. In a web browser, you can just open
<a href="http://localhost:8098/buckets/bucket1/index/$key/key2/key4">http://localhost:8098/buckets/bucket1/index/$key/key2/key4</a>

curl <a href="http://localhost:8098/buckets/bucket1/index/\$key/key2/key4">http://localhost:8098/buckets/bucket1/index/\$key/key2/key4</a>

## Run a M/R-based query...

curl -X POST \
-H &quot;content-type: application/json&quot; \
-d @- \
<a href="http://localhost:8098/mapred">http://localhost:8098/mapred</a> \
&lt;&lt;EOF
{
   &quot;inputs&quot;:{
       &quot;bucket&quot;:&quot;bucket1&quot;,
       &quot;index&quot;:&quot;\$key&quot;,
       &quot;start&quot;:&quot;key2&quot;,
       &quot;end&quot;:&quot;key4&quot;
   },
   &quot;query&quot;:[
      {
         &quot;reduce&quot;:{
            &quot;language&quot;:&quot;erlang&quot;,
            &quot;module&quot;:&quot;riak_kv_mapreduce&quot;,
            &quot;function&quot;:&quot;reduce_identity&quot;,
            &quot;keep&quot;:true
         }
      }
   ]
}
EOF
