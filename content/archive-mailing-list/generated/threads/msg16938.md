We include/shade that jar in the final riak-client jar so we stopped
shipping it separately.
You&#x27;ll want to clone riak_pb, and build this tag to install it locally for
dev:  <a href="https://github.com/basho/riak_pb/tree/java-2.1.1.0">https://github.com/basho/riak_pb/tree/java-2.1.1.0</a>

You&#x27;ll need protocol buffers 2.5.0
&lt;<a href="https://github.com/google/protobuf/releases/tag/v2.5.0">https://github.com/google/protobuf/releases/tag/v2.5.0</a>&gt; to build, and you
should be able to build/install the riak_pb lib with `mvn install`.  If you
use homebrew you can use this &lt;<a href="http://stackoverflow.com/a/23760535">http://stackoverflow.com/a/23760535</a>&gt; procedure
to install the older protobuf lib (just swap protobuf241 for protobuf250).

Thanks,
