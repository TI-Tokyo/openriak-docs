I created lager backend for Ybot -
<a href="https://github.com/0xAX/lager_ybot_backend">https://github.com/0xAX/lager_ybot_backend</a>. Ybot is chatrobot (
<a href="https://github.com/0xAX/Ybot">https://github.com/0xAX/Ybot</a>).

Now you can receive your lager error messages in real time in your chat
rooms.

Now it&#x27;s supports:

  * IRC

  * XMPP

  * 37signals campfire chat.

  * Google talk.

  * HipChat.

More info at lager_ybot_backend README -
<a href="https://github.com/0xAX/lager_ybot_backend">https://github.com/0xAX/lager_ybot_backend</a> and Ybot&#x27;s README -
<a href="https://github.com/0xAX/Ybot">https://github.com/0xAX/Ybot</a>
