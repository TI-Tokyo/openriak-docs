I am researching self-hosted alternatives to S3, and found Riak CS.
Setup was OK, and I currently can access the server fine with s3cmd

Unfortunately I cannot make it work with AWS SDK PHP version 3, since it
uses signature version 4.

I have done lots of trial and error, using PHP
define(&#x27;AWS_KEY&#x27;, &#x27;xxx&#x27;);
define(&#x27;AWS_SECRET_KEY&#x27;, &#x27;xxx&#x27;);
$client = new S3Client([
    &#x27;credentials&#x27; =&gt; [
        &#x27;key&#x27;    =&gt; AWS_KEY,
        &#x27;secret&#x27; =&gt; AWS_SECRET_KEY
    ],
    &#x27;region&#x27; =&gt; &#x27;local&#x27;,
    &#x27;version&#x27; =&gt; &#x27;2006-03-01&#x27;,
    &#x27;endpoint&#x27; =&gt; &#x27;172.xx.x.xx:8080&#x27;,
//    &#x27;signature_version&#x27; =&gt; &#x27;v4&#x27;
]);

signature_version can only be v4 or anonymous.

What is the expectation with v4 requests?

I did find the option, auth_v4_enabled:

[

%%    {auth_v4_enabled, true}
  ]}
].

but it ends up in error 500

Do I need more configuration, or is it not ready.

Going back to developers it seems they use something called Flyssystem,
which has v2 and v3 adapters
<a href="http://flysystem.thephpleague.com/adapter/aws-s3-v2/">http://flysystem.thephpleague.com/adapter/aws-s3-v2/</a>

So I have solved my problem for now, by using the flysystem v2 adapter,
with something like:
use Aws\S3\S3Client;
use League\Flysystem\AwsS3v2\AwsS3Adapter;
use League\Flysystem\Filesystem;

$client = S3Client::factory([
    &#x27;key&#x27;    =&gt; AWS_KEY,
    &#x27;secret&#x27; =&gt; AWS_SECRET_KEY,
    &#x27;region&#x27; =&gt; &#x27;local&#x27;,
    &#x27;endpoint&#x27; =&gt; &#x27;<a href="http://s3.amazonaws.com:8080&#x27;">http://s3.amazonaws.com:8080&#x27;</a>,
]);

- and also catching the s3.amazonaws.com DNS with DNSmasq and sending
requests to the Riak CS.

I will of course look into the proxy parts too, and refine this with a
better named endpoint.

Thank you for input, Riak CS proved to be easier to get up than expected.
