We have built and uploaded Riak 1.2.0 release candidate 3 for your use,
testing, and abuse.

You can download RC3 from our downloads page:
<a href="http://basho.com/resources/downloads/">http://basho.com/resources/downloads/</a>

The changes for RC3 can be found in the release notes:
<a href="https://github.com/basho/riak/blob/1.2/RELEASE-NOTES.md">https://github.com/basho/riak/blob/1.2/RELEASE-NOTES.md</a>

The new bugs fixed in RC3 are:

* [riak_core - Restructure supervision tree so that folsom is an included
app](<a href="https://github.com/basho/riak_core/pull/217">https://github.com/basho/riak_core/pull/217</a>)

* [riak_core - Ring mgr crash creates confused cluster](
<a href="https://github.com/basho/riak_core/issues/166">https://github.com/basho/riak_core/issues/166</a>)

* [riak_core - Make the ring manager responsible for loading the ring](
<a href="https://github.com/basho/riak_core/pull/214">https://github.com/basho/riak_core/pull/214</a>)

* [riak_core - Fix capability system race condition](
<a href="https://github.com/basho/riak_core/pull/216">https://github.com/basho/riak_core/pull/216</a>)

* [riak_kv - Changed semantics of backend:drop - backend must close all
handles](<a href="https://github.com/basho/riak_kv/pull/373">https://github.com/basho/riak_kv/pull/373</a>)

* [riak_kv - Call eleveldb:close on vnode stop for eleveldb backend](
<a href="https://github.com/basho/riak_kv/pull/372">https://github.com/basho/riak_kv/pull/372</a>)

Known issues
* [riak_kv - Call eleveldb:close on vnode stop for eleveldb backend](
<a href="https://github.com/basho/riak_kv/pull/372">https://github.com/basho/riak_kv/pull/372</a>)

Thanks once again from the whole team!

-Jared (by proxy, Ed.)
