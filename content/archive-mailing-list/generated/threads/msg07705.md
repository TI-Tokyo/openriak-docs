protobuf for Riak. It can be found here: <a href="https://github.com/tpjg/goriakpbc">https://github.com/tpjg/goriakpbc</a>

I realize there are other efforts (like github.com/mrb/riakpbc) and was
actually hoping Airbrake would open source their client
(<a href="http://blog.airbrake.io/status/planned-airbrake-migration-love-go-love-riak/">http://blog.airbrake.io/status/planned-airbrake-migration-love-go-love-riak/</a>)
but can&#x27;t wait for that.

I have started a library that takes inspiration from the Ruby client library
(<a href="https://github.com/basho/riak-ruby-client">https://github.com/basho/riak-ruby-client</a>) and plan to implement only those
functions that I need to port a part of my Ruby on Rails application to Go. So
far simple get and store operations as well as setting some bucket properties
are implemented.

Kind regards,
