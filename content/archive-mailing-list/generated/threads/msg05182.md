Riak Recap for October 12 - 16
=======================

1) Clipboard.com, heavy Riak/Search users and contributors, rolled
their service out of stealth mode last week. Congratulations to the
team!

* Details here ---&gt; <a href="http://blog.clipboard.com/2011/10/13/Hello-World">http://blog.clipboard.com/2011/10/13/Hello-World</a>

2) Alvaro Videla (@old_sound) released a RabbitMQ plugin that uses
Bitcask as a storage backend. Thanks, Alvaro!

* Code and details here ---&gt;
<a href="https://twitter.com/old_sound/status/124152414914875392">https://twitter.com/old_sound/status/124152414914875392</a>

3) Ben Murphy is tinkering with counters in Riak. Very cool stuff.
Thanks for releasing, Ben!

* Code here ---&gt; <a href="https://github.com/benmmurphy/ecnty">https://github.com/benmmurphy/ecnty</a>

4) The video of the &quot;Scaling at ShowYou&quot; talk that John Muellerleile
(@jrecursive) gave a few weeks back at Boundary HQ is now online.

* Watch here ---&gt; <a href="http://blog.boundary.com/2011/10/11/Boundary-Tech-Talk-1.html">http://blog.boundary.com/2011/10/11/Boundary-Tech-Talk-1.html</a>

5) We merged a contribution from Chris Umbel to the Java Client. Thanks, Chris!

* Details here ---&gt; <a href="https://github.com/basho/riak-java-client/pull/66">https://github.com/basho/riak-java-client/pull/66</a>

6) Yosuke Hara gave a Riak presentation at a Python Hack-a-thon over
the weekend. Thanks, Yosuke!

* Slides here on his blog ---&gt;
<a href="http://yosuke-perspective.blogspot.com/2011/10/python-hack-thon-introduce-to-riak.html">http://yosuke-perspective.blogspot.com/2011/10/python-hack-thon-introduce-to-riak.html</a>

7) It looks like Jon Brisbin had a busy, productive weekend with Riak
and RabbitMQ... Thanks, Jon!

* His Riak/RabbitMQ Post-commit hook is now updated to 1.0. Details
here ---&gt; <a href="http://twitter.com/#!/j_brisbin/status/125942119151058945">http://twitter.com/#!/j_brisbin/status/125942119151058945</a>
* He also updated his custom Rabbit/Riak exchange ---&gt;
<a href="http://twitter.com/#!/j_brisbin/status/125955392890089473">http://twitter.com/#!/j_brisbin/status/125955392890089473</a>
* And, if you&#x27;re going to be in Chicago for Spring 2GX 2011 at the end
of this month, you can see Jon talk all about this code and how he&#x27;s
using it ---&gt;
<a href="http://www.springone2gx.com/conference/chicago/2011/10/speakers/jon_brisbin">http://www.springone2gx.com/conference/chicago/2011/10/speakers/jon_brisbin</a>
* This would also be a great time to point out the Riak and RabbitMQ
section on the wiki
---&gt;<a href="http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html#Riak-and-RabbitMQ">http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html#Riak-and-RabbitMQ</a>
