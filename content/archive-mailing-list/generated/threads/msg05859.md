Riak Recap for December 2 - 4
=======================

1) Jon Dickinson wrote a short blog post with his impressions of the
NoSQL Roadshow event that happened in London last week.

* Read here ---&gt;
<a href="http://www.denormalised.com/roundup/an_afternoon_with_riak_2011_11_29.html">http://www.denormalised.com/roundup/an_afternoon_with_riak_2011_11_29.html</a>

2) David O&#x27;Dell posted some code on his blog that to create a
compressed back up of a riak cluster.

* Read here ---&gt;
<a href="http://dodizzle.com/riak-cluster-backup-script-with-compression-r">http://dodizzle.com/riak-cluster-backup-script-with-compression-r</a>

3) Basho Hacker Reid Draper added some new bits to his knockbox code.

* Details here ---&gt;
<a href="https://twitter.com/#!/reiddraper/statuses/143459415687831552">https://twitter.com/#!/reiddraper/statuses/143459415687831552</a>

4) The team at CircuitHub just released some new Riak-themed code.

* MassiveGit: Git Object Model on top of Riak ---&gt;
<a href="https://github.com/circuithub/massive-git">https://github.com/circuithub/massive-git</a>
* Riak-entity: a tiny library on top of riak-js to work with Riak in
OO style ---&gt; <a href="https://github.com/circuithub/riak-entity">https://github.com/circuithub/riak-entity</a>

5) superissac started working on a node.js port of bitcask.

* Short blog post (in Chinese) with links to code ---&gt;
<a href="http://superisaac.iteye.com/blog/1291313">http://superisaac.iteye.com/blog/1291313</a>
