I&#x27;ve just installed the riak ubuntu package using the instructions
here:

<a href="http://docs.basho.com/riak/latest/tutorials/installation/Installing-on-Debian-and-Ubuntu/#Installing-From-Apt-Get">http://docs.basho.com/riak/latest/tutorials/installation/Installing-on-Debian-and-Ubuntu/#Installing-From-Apt-Get</a>

And the resulting /usr/lib/riak has an erts-5.9.1 directory, but the init
script installed in /etc/init.d/riak has a critical var defined as:

ERTS_PATH=/usr/lib/riak/erts-5.9.1/bin

The result is that none of the init script&#x27;s &quot;stop&quot; and &quot;restart&quot;
operations fail since start-stop-daemon is looking for the wrong process
path.

Is this a known bug?  I haven&#x27;t had much luck searching for issues, as I&#x27;m
not sure which of the many, many repos on <a href="https://github.com/basho/">https://github.com/basho/</a> might
be relevant to this corner of the riak project.

By the way, the README on <a href="https://github.com/basho/riak">https://github.com/basho/riak</a> has a &quot;how to
report bugs&quot; section that sends you to the defunct bugzilla database which
sends you back to github.
