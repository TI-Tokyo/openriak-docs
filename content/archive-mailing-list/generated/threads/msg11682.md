Today&#x27;s recap is coming to you from across the street of Eastern State

First and foremost, we&#x27;re excited to share the new Riak docs reorg and redesign.
- <a href="http://docs.basho.com">http://docs.basho.com</a>

Jeremiah Peschka announced CorrugatedIron 1.4 with support for Riak 1.4.
- <a href="http://www.brentozar.com/archive/2013/07/corrugatediron-1-4/">http://www.brentozar.com/archive/2013/07/corrugatediron-1-4/</a>

Gideon de Kok announced Raiku 0.6 with support for Riak 1.4.
- <a href="http://gideondk.nl/blog/2013/7/20/release-raiku-060">http://gideondk.nl/blog/2013/7/20/release-raiku-060</a>

Age Mooji released the version 0.8.1 of his Riak Scala Client and
wrote up a quick blog post about it.
- <a href="http://scalapenos.com/2013/07/10/riak-scala-client-0.8.1.html">http://scalapenos.com/2013/07/10/riak-scala-client-0.8.1.html</a>

Not sure where to start with Riak&#x27;s new CRDT support? Basho hacker Sam
Elliot created a cookbook for you.
- <a href="https://github.com/basho/riak_crdt_cookbook">https://github.com/basho/riak_crdt_cookbook</a>

Davey Shafik has been doing some work to get the Riak PHP Client docs in order.
- <a href="https://github.com/basho/riak-php-client/pull/53">https://github.com/basho/riak-php-client/pull/53</a>
- <a href="http://dshafik.github.io/riak-php-client/">http://dshafik.github.io/riak-php-client/</a>

Basho Hacker Kota Uenishi gave a talk at Rubykaigi about using Riak
with Fluentd.
- <a href="https://vimeo.com/69128202">https://vimeo.com/69128202</a>

Antoine Michaud of Xebia.fr gave a talk about Riak.
- <a href="https://vimeo.com/70120771">https://vimeo.com/70120771</a>

The Engineering Team at Gilt Groupe have been testing Riak. They wrote
a blog post about the recent set of benchmarks and performance tests
they ran against Riak&#x27;s Multi-Datacenter replication.
- <a href="http://tech.gilt.com/post/55529520304/riak-passes-the-stress-test">http://tech.gilt.com/post/55529520304/riak-passes-the-stress-test</a>

@rev4t from the Internet Initiative Japan gave a talk on Yokozuna at
the latest Tokyo Riak Meetup.
- <a href="https://www.youtube.com/watch?v=VTrR9CfxOJQ">https://www.youtube.com/watch?v=VTrR9CfxOJQ</a>

Basho Hacker Steve Vinoski gave a talk at Erlang Factory called,
&quot;Addressing Network Congestion in Riak Clusters.&quot;
-
<a href="http://www.erlang-factory.com/conference/ErlangUserConference2013/speakers/SteveVinoski">http://www.erlang-factory.com/conference/ErlangUserConference2013/speakers/SteveVinoski</a>

Digital Ocean posted a guide on how to create a Riak cluster in their cloud.
-
<a href="https://www.digitalocean.com/community/articles/how-to-create-a-riak-cluster-on-an-ubuntu-vps">https://www.digitalocean.com/community/articles/how-to-create-a-riak-cluster-on-an-ubuntu-vps</a>

Joshua Bussdieker created an alternative Puppet module for installing
and configuring Riak.
- <a href="https://forge.puppetlabs.com/jbussdieker/riak">https://forge.puppetlabs.com/jbussdieker/riak</a>
