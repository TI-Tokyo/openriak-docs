Riak Recap for Nov. 24 - 28

1) Anyone heading to Scale Camp in London in a few weeks?
(<a href="http://www.scalecamp.org.uk/">http://www.scalecamp.org.uk/</a>) Sadly, no one from Basho will be there,
but there might be a Riak enthusiast or two in attendance. Let the
list know if you&#x27;ll be there.

2) @udk1 (Russell Smith) put together a PHP script that simplifies
deleting all the keys from a bucket.

Check it out here ---&gt;
<a href="http://blog.ukd1.co.uk/post/1729691991/deleting-all-the-keys-in-a-riak-bucket">http://blog.ukd1.co.uk/post/1729691991/deleting-all-the-keys-in-a-riak-bucket</a>

3) Ripple Update: Sean Cribbs pushed a HTTP backend that uses Excon.
It appears to be quite fast.

Commit here ---&gt;
<a href="https://github.com/seancribbs/ripple/commit/0e1a7be5886d832b3bd01d446676d82b1641857c">https://github.com/seancribbs/ripple/commit/0e1a7be5886d832b3bd01d446676d82b1641857c</a>

Link to benchmarks here ---&gt;
<a href="http://twitter.com/seancribbs/status/9110924686262273">http://twitter.com/seancribbs/status/9110924686262273</a>

Boulder. The new date and time is Tuesday, December 7, 2010, 7-9:00pm.

Details and registration info here ---&gt; <a href="http://planca.st/IHx">http://planca.st/IHx</a>

a Riak Field Storage module.

Details here ---&gt; <a href="http://drupal.org/project/riak_field_storage">http://drupal.org/project/riak_field_storage</a>

Original Announcement here ---&gt;
<a href="http://twitter.com/peschkaj/status/8872266557292544">http://twitter.com/peschkaj/status/8872266557292544</a>

7)  Q --- Any idea when 0.14 is going to be released?  (from danoyoung
via #riak)

     A --- 0.14 is slated for a December release.

8) quentusrex, benblack, timanglade and a few others had a lengthy
chat in #riak that started with &quot;Anyone know if there is a simple way
to pull
documents(about 3 million documents) from a couchdb server into a  new
riak cluster? &quot;

Gist here ---&gt; <a href="https://gist.github.com/720780">https://gist.github.com/720780</a>

9) Is there a way to sync the data in a precommit hook into another
database? (from chx via #riak)

Yes. You can write a pre-commit that would do that. @argv0 gave a demo
a while back on using a post-commit hook and RabbitMQ to pump data
into SQLite from Riak. It&#x27;s not exactly what you&#x27;re looking for but
might be a good place to start ---&gt;
<a href="http://bitbucket.org/argv0/riak_rabbit">http://bitbucket.org/argv0/riak_rabbit</a>
