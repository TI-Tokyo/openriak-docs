Riak Recap for May 26 - April 2
=======================

The crew at CopperEgg released a monitoring plugin for Riak.
- <a href="https://github.com/CopperEgg/metrics-plugins/tree/master/riak">https://github.com/CopperEgg/metrics-plugins/tree/master/riak</a>

Adron Hall is speaking at HTML 5 Dev Conf on &quot;Data &amp; Applications
Across the Void :: Distributing Systems&quot;.
- <a href="http://www.html5devconf.com/sessions.html">http://www.html5devconf.com/sessions.html</a>

Eric Redmond is speaking at Ancient City Ruby in St. Augustine,
Florida, the oldest city in America!
- <a href="http://www.ancientcityruby.com/">http://www.ancientcityruby.com/</a>

Jeremiah Peschka and the team at Brent Ozar posted a video on storing
session state. Riak and CorrugatedIron are featured prominently.
- <a href="http://www.brentozar.com/archive/2013/03/saving-session-state-video/">http://www.brentozar.com/archive/2013/03/saving-session-state-video/</a>

John Newman is speaking at PDX Web &amp; Design on April 11th in Portland, Oregon.
- <a href="http://www.meetup.com/pdxweb/events/111325372/">http://www.meetup.com/pdxweb/events/111325372/</a>

Basho is sponsoring the Write The Docs Conference in Portland, Oregon.
- <a href="http://conf.writethedocs.com">http://conf.writethedocs.com</a>

Evan Miller has a framework on GitHub called BossDB that he&#x27;s billing
as &quot;a sharded, caching, pooling, evented ORM for Erlang.&quot; There&#x27;s Riak
support.
- <a href="https://github.com/evanmiller/boss_db">https://github.com/evanmiller/boss_db</a>

David Collier of Engine Yard released some slides about Riak and
CouchDB and Data Mining.
-
<a href="https://speakerdeck.com/davidcoallier/the-artful-business-of-data-mining-distributed-schema-less-document-based-databases">https://speakerdeck.com/davidcoallier/the-artful-business-of-data-mining-distributed-schema-less-document-based-databases</a>

The team at Temetra gave a great talk at the London Meetup a few
months back about how they are storing meter in Riak. The video is now
online.
- <a href="http://basho.com/riak-at-temetra/">http://basho.com/riak-at-temetra/</a>

Sebastian Cohen wrote a great blog about upgrading to Riak 1.3 and the
Bitcask performance increase that came with it.
-
<a href="http://tisba.de/2013/04/02/why-you-should-consider-updating-and-patching-your-riak/">http://tisba.de/2013/04/02/why-you-should-consider-updating-and-patching-your-riak/</a>

Heinz Gies wrote a blog about building Riak Core apps with the help of
riak_test.
-
<a href="http://blog.licenser.net/blog/2013/03/31/getting-started-with-riak-test-and-riak-core/">http://blog.licenser.net/blog/2013/03/31/getting-started-with-riak-test-and-riak-core/</a>

Ines Sombra has been pitching Riak all over the East coast for the
last few weeks. Her slide deck from the &quot;Riak in the Cloud&quot; talk she
gave at the Big Nerd Ranch is online (and are well worth your time).
- <a href="https://speakerdeck.com/randommood/riak-at-engine-yard-given-at-big-nerd-ranch">https://speakerdeck.com/randommood/riak-at-engine-yard-given-at-big-nerd-ranch</a>

Andy Gross gave a talk last night at the Silicon Valley Cloud
Computing Meetup all about Riak and Riak CS. Check these out when you
get the chance.
-
<a href="https://speakerdeck.com/argv0/building-reliable-cloud-storage-services-with-riak">https://speakerdeck.com/argv0/building-reliable-cloud-storage-services-with-riak</a>

Joe Armstrong, one of the creators of Erlang, has started a blog
series promoting the language
- <a href="http://joearms.github.com/2013/03/27/promoting-erlang.html">http://joearms.github.com/2013/03/27/promoting-erlang.html</a>
- <a href="http://joearms.github.com/2013/03/28/solving-the-wrong-problem.html">http://joearms.github.com/2013/03/28/solving-the-wrong-problem.html</a>

- Q &amp; A
<a href="http://www.quora.com/Riak/How-do-I-query-a-Riak-list?__snids__=110482528&amp;__nsrc__=4">http://www.quora.com/Riak/How-do-I-query-a-Riak-list?__snids__=110482528&amp;__nsrc__=4</a>
