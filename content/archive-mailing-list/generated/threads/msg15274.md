Hi Taufan,

The link that Sean provided has information on how to create the bucket type.
Taken from the included link:

        riak-admin bucket-type create maps &#x27;{&quot;props&quot;:{&quot;datatype&quot;:&quot;map&quot;}}&#x27;

        riak-admin bucket-type create sets &#x27;{&quot;props&quot;:{&quot;datatype&quot;:&quot;set&quot;}}&#x27;

        riak-admin bucket-type create counters
&#x27;{&quot;props&quot;:{&quot;datatype&quot;:&quot;counter&quot;}}&#x27;

I’ve also got a small riak_test example which uses the Erlang client to create
the bucket type and operate over a key.  This might provide a good starting
place to work from.

For example:

Creating a search index:
<a href="https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L33">https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L33</a>

Updating/creating a map with a register in it:
<a href="https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L50">https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L50</a>

Executing this with the client:
<a href="https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L56">https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L56</a>

Performing a search query with the client:
<a href="https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L66">https://github.com/basho/riak_test/blob/master/tests/yz_crdt.erl#L66</a>
