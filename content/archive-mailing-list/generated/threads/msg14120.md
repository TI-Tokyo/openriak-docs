<blockquote>1. Does it support wildcards in a middle or start?  *abc, a*bc,
</blockquote>
Riak Search 2.0 (Yokozuna) is based on Apache Solr. Any queries
supported by Solr&#x27;s distributed search are supported by Search
2.0 over HTTP. The PB API has not been altered for Search 2.0 (with
the exception of presort) so if you want to use features like facets
you&#x27;ll have to use HTTP for now.

<a href="https://cwiki.apache.org/confluence/display/solr/Apache+Solr+Reference+Guide">https://cwiki.apache.org/confluence/display/solr/Apache+Solr+Reference+Guide</a>

For wildcard searches in particular see the following section:

<a href="https://cwiki.apache.org/confluence/display/solr/The+Standard+Query+Parser#TheStandardQueryParser-SpecifyingTermsfortheStandardQueryParser">https://cwiki.apache.org/confluence/display/solr/The+Standard+Query+Parser#TheStandardQueryParser-SpecifyingTermsfortheStandardQueryParser</a>

<blockquote>2. Does presort supports any field instead of  key or score?
</blockquote>
There is no presort option for Search 2.0. Presort is a work around
for sorting issues in the current Search [1,2]. Solr sorts
properly. Although, depending on the fields sorted, the results can
become inconsistent for the same query over time because of a bug in
Search 2.0 [3].

<blockquote>I&#x27;m not found this in 2.0 docs.
</blockquote>
These are the Riak Search 2.0.0beta1 docs.

<a href="http://docs.basho.com/riak/2.0.0beta1/dev/using/search/">http://docs.basho.com/riak/2.0.0beta1/dev/using/search/</a>
