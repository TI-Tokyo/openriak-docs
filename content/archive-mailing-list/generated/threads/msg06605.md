Göran and I worked on a Riak client for Pharo Smalltalk named Phriak.
You can download the code at <a href="http://www.squeaksource.com/Phriak">http://www.squeaksource.com/Phriak</a>
Today I released the version 0.3.

Riak is a screamingly cool NoSQL database that scales like crazy. It&#x27;s a
distributed, data agnostic db (see <a href="http://wiki.basho.com/Riak.html">http://wiki.basho.com/Riak.html</a>).

There&#x27;s a Metacello package ConfigurationOfPhriak for simple loading.

As of today, Phriak supports (through the HTTP API):
- Bucket properties
- Objects metadata
- Links and link walking
- Secondary indexing
- Map/Reduce
- VClock and Siblings resolution

Cheers,
Nico
