Yes, a secondary index is the most reasonable way to accomplish this.
Here&#x27;s an example using the Python client:

now = time.gmtime()
myobj.add_index(&#x27;modified_int&#x27;, now)
myobj.store()

bucket.get_index(&#x27;modified_int&#x27;, now-3600, now+3600)

Hope that helps.
