Riak Recap for July 6 - 7
==================

1) Bryan O&#x27;Sullivan&#x27;s Haskell Client just hit version 0.6.

* Details here ---&gt; <a href="http://twitter.com/#!/Hackage/status/88761152116490242">http://twitter.com/#!/Hackage/status/88761152116490242</a>

2)  This one is somewhat far out on the calendar but it&#x27;s worth
relaying: newly-minted Basho Architect Steve Vinoksi will be talking
at GOTO Amsterdam in October.

* Details here ---&gt; <a href="http://gotocon.com/amsterdam-2011/speaker/Steve+Vinoski">http://gotocon.com/amsterdam-2011/speaker/Steve+Vinoski</a>

3) Luca Spiller released &quot;Riak Console,&quot; an interactive command line
interface to Riak. This one looks pretty useful

* On GitHub here ---&gt; <a href="https://github.com/lucaspiller/riak-console">https://github.com/lucaspiller/riak-console</a>

Thanks, Luca!

4) Next week at BashoWest we will be having a Ripple Hackathon, and
we&#x27;re opening up the office to Bay Area Ruby Hackers. You should be
here.

* Details here on the Basho Blog ---&gt;
<a href="http://blog.basho.com/2011/07/07/Ripple-Hackathon-Happening-Next-Week-at-Basho-West/">http://blog.basho.com/2011/07/07/Ripple-Hackathon-Happening-Next-Week-at-Basho-West/</a>

5) Alexander Mikhalev (@alex_mikhalev) wrote a blog post about
securing a Riak cluster using n2n VPN. This one is definitely worth
the read. (NOTE: The typical recommended configuration is behind a
firewall where the cluster is not exposed to the outside world.)

* Read here ---&gt;
<a href="http://sci-blog.com/2011/07/secure-riak-installation-using-n2n-vpn/">http://sci-blog.com/2011/07/secure-riak-installation-using-n2n-vpn/</a>

Thanks, Alexander!

6) One job to pass along.

* Scopely in L.A. is hiring Node.js developers with Riak experience.
Details here ---&gt; <a href="http://jobs.nodejs.org/a/jbb/job-details/523690">http://jobs.nodejs.org/a/jbb/job-details/523690</a>
