Wendy had a great question about Solr integration (aka Riak Search) with
mult-valued fields [1]

backend [2]

[3] (thank you for that!)

crypto [4]
Shino gives Roman the command to run Riak KV in the foreground as a hidden
process [5]
Antonio gets a helping hand from MVM regarding leveldb deletion of files
[6], which leads to further questions. Antonio also shares that the task
completed and the command he used [7]
Luke has further questions for Gregg as they test their first 5 node
application and get errors [8]
MVM was kind enough to help Wes with an older thread on leveldb [9]
