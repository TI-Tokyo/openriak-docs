Riak Recap for February 24 - 26
========================

1) The team at Temetra wrote up a short blog post about how and why
they are using Riak in production.

* Read here ---&gt;  <a href="http://www.temetra.com/2012/02/riak-cluster-deployed">http://www.temetra.com/2012/02/riak-cluster-deployed</a>

2) Sreejith Kesavan wrote a blog post about doing multi-index queries
with the Python client.

* Read here ---&gt; <a href="http://foobarnbaz.com/2012/02/25/multi-index-queries-in-riak/">http://foobarnbaz.com/2012/02/25/multi-index-queries-in-riak/</a>

3) Pavlo Baron (I think) wrote up a short post about using Pre-Commit hooks.

* Read here ---&gt;
<a href="http://startup-tech.tumblr.com/post/15300179505/riak-precommit-hooks">http://startup-tech.tumblr.com/post/15300179505/riak-precommit-hooks</a>

4) Basho Hacker Sean Cribbs was on the Extroverted Developer Podcast
talking about all things Basho, Riak and development.

* Listen here ---&gt;
<a href="http://extroverteddeveloper.com/blog/2012/2/27/extroverted-developer-7-sean-cribbs.html">http://extroverteddeveloper.com/blog/2012/2/27/extroverted-developer-7-sean-cribbs.html</a>

5) Basho put up another Billboard. This one is to congratulate Bump on
passing 80MM users. If you&#x27;re driving up the 101 just south of San
Francisco, you might see it. (Also, congrats to the Bump team for the
release of 3.0!)

* Billboard pic here ---&gt;
<a href="https://twitter.com/#!/bpatrick001/status/174202724324343808/photo/1">https://twitter.com/#!/bpatrick001/status/174202724324343808/photo/1</a>

6) We are doing a free Webinar on Wednesday all about what&#x27;s new in Riak 1.1.

* Details and RSVP here ---&gt; <a href="http://basho.com/contact/webinar-registration">http://basho.com/contact/webinar-registration</a>

7) Jon Bribin released a Groovy DSL for doing HTTP testing that (as
far as I can tell) he&#x27;s using for Riak development.

* Code here ---&gt; <a href="https://github.com/jbrisbin/rest-builder">https://github.com/jbrisbin/rest-builder</a>

8) Basho team member Casey Rosenthal is going to be at the PDX Erlang
Meetup tomorrow night. I heard a rumor he has some Riak swag. Don&#x27;t be
scared to attend and ask him hard questions.

* Details here ---&gt; <a href="http://calagator.org/events/1250461948">http://calagator.org/events/1250461948</a>
