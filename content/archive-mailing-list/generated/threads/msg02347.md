For example:

git checkout -- rebar.config &amp;&amp; sed -Ei &#x27;&#x27; -e &#x27;s:&quot;git:&quot;https:&#x27; -e
&#x27;s:(//.*)&quot;,:\1.git&quot;,:&#x27; rebar.config

NOTE: I&#x27;m using BSD sed here, on Fedora you might have to replace -E with -r
