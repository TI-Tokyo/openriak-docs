The Go client for Riak is out of beta, so Go get it!

To install it in your go project, just run `go get
github.com/basho/riak-go-client` &lt;<a href="http://github.com/basho/riak-go-client%60">http://github.com/basho/riak-go-client%60</a>&gt;.

You can find more information on the project page
(<a href="https://github.com/basho/riak-go-client">https://github.com/basho/riak-go-client</a>
&lt;<a href="https://github.com/basho/riak-go-client">https://github.com/basho/riak-go-client</a>&gt;), and in the API docs
(<a href="https://godoc.org/github.com/basho/riak-go-client">https://godoc.org/github.com/basho/riak-go-client</a>
&lt;<a href="https://godoc.org/github.com/basho/riak-go-client">https://godoc.org/github.com/basho/riak-go-client</a>&gt;).

Special thanks to Luke Bakkan &amp; Chris Mancini for their work on the client,
Timo Gatsonides for his inspiring work on goriakpbc, and Sergio Arteaga for
submitting GitHub issues.

Thanks,
Alex
