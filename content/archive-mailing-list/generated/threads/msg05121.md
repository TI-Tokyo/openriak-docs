Your pre-commit hook needs to be a named erlang or Javascript function[1]. You
define your function in a js file, put the js file on your Riak server(s)
somewhere and set the app.config riak_kv env parameter &#x27;js_source_dir&#x27;[2] to
the directory that contains the file. We recommend that you namespace your
functions.  You can then define a pre-commit hook like:

{&quot;props&quot;: {&quot;precommit&quot;: [{&quot;name&quot;: &quot;YourNameSpace.yourFun&quot;}]}}

[1] <a href="http://wiki.basho.com/Commit-Hooks.html#Configuration">http://wiki.basho.com/Commit-Hooks.html#Configuration</a>
[2] <a href="http://wiki.basho.com/Configuration-Files.html#js_source_dir">http://wiki.basho.com/Configuration-Files.html#js_source_dir</a>
