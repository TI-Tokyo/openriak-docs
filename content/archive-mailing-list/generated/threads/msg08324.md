I&#x27;m  using ver. 1.2.0 too. It happens only on bucket with indexing enabled.
I think it depends on the Analyzer factory.
My index schema was:
...
        {dynamic_field, [
            {name, &quot;*&quot;},
            {type, string},
            {analyzer_factory, {erlang, text_analyzers,  *
whitespace_analyzer_factory*}}
        ]}
...

Since I&#x27;ve changed the default factory from
whitespace_analyzer_factory to standard_analyzer_factory
it seems to work.
My current index schema is:
...
        {dynamic_field, [
            {name, &quot;*&quot;},
            {type, string},
            {analyzer_factory, {erlang, text_analyzers, *
standard_analyzer_factory*}}
        ]}
...

It looks like the whitespace_analyzer_factory has some differences compare
to standard_analyzer_factory.

Thanks
Vladimir
