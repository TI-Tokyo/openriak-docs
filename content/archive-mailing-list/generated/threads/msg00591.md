Static arguments can be passed to MapReduce queries using the &quot;arg&quot;
property. Here is an example query that runs over all the keys in the bucket
&quot;bucket&quot;:
{
    &quot;inputs&quot;: &quot;bucket&quot;,
    &quot;query&quot;: [
        {
            &quot;map&quot;: {
                &quot;language&quot;: &quot;javascript&quot;,
                &quot;source&quot;: &quot;function(value, keyData, arg) { return [arg]; }&quot;,
                &quot;keep&quot;: true,
                &quot;arg&quot;: &quot;static data&quot;
            }
        }
    ]
}
