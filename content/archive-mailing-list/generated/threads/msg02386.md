</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg02389" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Jeremiah Peschka</span><time datetime="2011-02-19T07:43:29-08:00">February 19, 2011 at 7:43 AM</time><span class="mailing-list-message__subject">Re: Alternative to Luwak??</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">The problem you&#x27;re running into is that Luwak will only store the information
about a file that you tell it. Unless you make the luwak_file aware of the
file&#x27;s metadata in the filesystem (through luwak_file:set_attribute), you&#x27;re
simply telling luwak to store the binary data that is read from disk.

How file metadata is handled varies from filesystem to filesystem. On some UNIX
filesystems, file metadata is stored in inodes. Inodes are pointers to the
actual file on disk, but they also contain the file metadata.
