Riak Recap for Jan. 26 - 27

1) Sean Cribbs contributed some session store code to riak-js.

* On GitHub here ---&gt; <a href="https://github.com/frank06/riak-js/pull/36">https://github.com/frank06/riak-js/pull/36</a>

2) Bryan Fink wrote a post for the Basho Blog called &quot;Fixing the
Count.&quot; This is a follow up to his post from last week about using
Map/Reduce to calculate Batting Averages.

Read here ---&gt; <a href="http://blog.basho.com/2011/01/26/fixing-the-count/">http://blog.basho.com/2011/01/26/fixing-the-count/</a>

3) In the last recap I mentioned that John Nunemaker wrote something
called &quot;adapter-riak.&quot; Turns out it was part of a larger project
called &quot;ToyStore.&quot;

For more details see:

*
<a href="http://railstips.org/blog/archives/2011/01/27/data-modeling-in-performant-systems/">http://railstips.org/blog/archives/2011/01/27/data-modeling-in-performant-systems/</a>
* <a href="http://thechangelog.com/post/2960631110/toystore-orm-for-key-value-data-stores">http://thechangelog.com/post/2960631110/toystore-orm-for-key-value-data-stores</a>

4)  Kresten Krab Thorup (@drkrab) wrote a great blog post called
&quot;About Version Vectors (a.k.a. Vector Clocks)&quot; that might be of use to
those of you who are trying to wrap your head around how versioning
and vector clocks work.

Read here ---&gt; <a href="http://www.javalimit.com/2011/01/understanding-vector-clocks.html">http://www.javalimit.com/2011/01/understanding-vector-clocks.html</a>

5) Bryan O&#x27;Sullivan released the Haskell Client for Riak at which he
had been hinting for the last week.

* Code here ---&gt; <a href="http://hackage.haskell.org/package/riak-0.1.0.0">http://hackage.haskell.org/package/riak-0.1.0.0</a>

He also wrote up a blog post about the client and some other open
source technologies that he and the MailRank team are hacking on.

* Read here ---&gt;
<a href="http://engineering.mailrank.com/introducing-some-open-source-technologies">http://engineering.mailrank.com/introducing-some-open-source-technologies</a>

6) The latest &quot;Minute with Riak&quot; episode is out. This one features
Rusty Klophaus talking about Property Based Testing and how we use
Erlang QuickCheck to test Riak.

Listen here ---&gt; <a href="http://riak.minutewith.com/pages/20110128">http://riak.minutewith.com/pages/20110128</a>

7) David J. Göhrig wrote a blog post called &quot;Riak, haproxy, and client
side applications.&quot; This talks a bit about what it took him to switch
&quot;a django app to running a riaksearch cluster fronted by haproxy.&quot;

Read here ---&gt; <a href="http://blog.dloh.org/2011/01/riak-haproxy-and-client-side.html">http://blog.dloh.org/2011/01/riak-haproxy-and-client-side.html</a>
