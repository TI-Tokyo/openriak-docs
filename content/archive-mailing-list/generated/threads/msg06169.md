When running map &amp; reduce functions, I’ve noticed a strange behavior like
adding ‘not_found’ records to the input of the reduce. Is there a way to

</blockquote>
Yes. If you&#x27;re using the erlang map function
riak_kv_mapreduce:map_object_value, you can pass an arg of &#x27;filter_notfound&#x27; to
filter out the not_found keys. If using js, you can have a look at this entry
in our knowledge base
(<a href="https://help.basho.com/entries/326412-how-do-i-filter-out-not-found-from-map-reduce-results">https://help.basho.com/entries/326412-how-do-i-filter-out-not-found-from-map-reduce-results</a>)
 which shows how to use a reduce phase to filter out not_founds.
