<blockquote>Hi,

I am looking for a way to insert an object and have the key

one will be created for me, but how do I do that with the erlang

</blockquote>You have to generate a key. The generator that&#x27;s used when doing a
POST on a bucket is riak_core_util:unique_id_62() which you could
reuse if you like.

<blockquote>Also, are there any restrictions on the keys (like length, only ascii, etc.)?

</blockquote>My understanding is that though there isn&#x27;t a specific limit, in
practice you&#x27;ll want to restrict your keys to something URL safe so
the HTTP interface can be used. Also if you&#x27;re using the Innostore
backend, a maximum length of 255 bytes applies.
