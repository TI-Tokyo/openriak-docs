Riak Recap for April 13 -14
====================

1) jtuple released two repos yesterday: &quot;riak_zab&quot; and &quot;riak_zab_example&quot;

* riak_zab is an extension for riak_core that provides totally ordered
atomic broadcast capabilities. Check it out here ---&gt;
<a href="https://github.com/jtuple/riak_zab">https://github.com/jtuple/riak_zab</a>
* riak_zab_example is the sister repo to riak_zab

Thanks, jtuple!

Related to this code, Alex Popescu (@al3xandru) wrote up a blog post
exploring some of the potential implications for riak_zab + riak
_core.

* Read here ---&gt;
<a href="http://nosql.mypopescu.com/post/4633402570/riak-zab-zookeepers-zab-protocol-for-riak">http://nosql.mypopescu.com/post/4633402570/riak-zab-zookeepers-zab-protocol-for-riak</a>

2) For anyone who is going (or considering going) to Erlang Factory in
London, there is a preso from Arun Suresh at Yahoo! that you&#x27;re going
to want to put on your calendar.

* Details here ---&gt;
<a href="http://www.erlang-factory.com/conference/London2011/speakers/ArunSuresh">http://www.erlang-factory.com/conference/London2011/speakers/ArunSuresh</a>

3) Sean Cribbs released a sample app called &quot;riak_id&quot;. From the GitHub
repo: &quot;riak_id is a very simple application that serves both to
duplicate functionality from Twitter’s “Snowflake” and to teach, via a
very simple example, how to build a riak_core application.&quot;

* In other words, go take a look ---&gt; <a href="https://github.com/seancribbs/riak_id">https://github.com/seancribbs/riak_id</a>

4) Kresten Kreb released some great code that enables you to build
&quot;simple secondary indexes in Riak based on Riak&#x27;s link mode.&quot;

* On GitHub here ---&gt; <a href="https://github.com/krestenkrab/riak_link_index">https://github.com/krestenkrab/riak_link_index</a>

Thanks, Kresten!

5) If anyone sees aphyr (Kyle Kingsbury) in #riak, be sure to
congratulate him on the very successful launch of Riak (and
MySQL)-backed showyou.com.

Congrats, Kyle!

6) Andy Gross contributed a nice chunk of code to Ryan Zezeski&#x27;s
&quot;rebar_riak_core&quot; repo .

* Details here ---&gt; <a href="http://twitter.com/#!/argv0/statuses/58682543221907457">http://twitter.com/#!/argv0/statuses/58682543221907457</a>

7) @frank06 et al have just added &quot;very rudimentary support for
keys=stream&quot; to riak-js.

* Details here ---&gt; <a href="http://twitter.com/riakjs/statuses/58993765980962816">http://twitter.com/riakjs/statuses/58993765980962816</a>

8) We posted the follow up to the Riak + Operations Webinar that
happened yesterday.

* Video and slides on the Basho Blog ---&gt;
<a href="http://blog.basho.com/2011/04/15/follow-up-to-riak-operations-webinar/">http://blog.basho.com/2011/04/15/follow-up-to-riak-operations-webinar/</a>

[note: this one is definitely worth your time]
