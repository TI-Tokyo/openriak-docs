Partition distribution is determined by the claim algorithm. In this case
it more evenly distributes partitions in a &quot;from scratch&quot; scenario vs.
adding nodes. There has been work to improve the algorithm that you can
find here: <a href="https://github.com/basho/riak_core/pull/183">https://github.com/basho/riak_core/pull/183</a>
