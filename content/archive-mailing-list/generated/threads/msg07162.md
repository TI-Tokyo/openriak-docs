data; could that be the case?

You need to specify the charset when importing 8-bit text.  It looks like your
xml is utf-8 encoded, so it should be imported using something like this:

curl -H &#x27;Content-Type: text/html;charset=UTF-8&#x27; -X PUT @datafile.xml
<a href="http://host:port/riak/bucket/key">http://host:port/riak/bucket/key</a>

The various language clients have different ways of specifying the charset for
a value; so if you imported the xml using some other method you need to find
out where to specify it.

Perhaps to verify, you can check the result of a curl -v (verbose, print the
headers) for one of your values.  If it does not come back with a charset=XXX
in the Content-Type header, then this is your problem.

Kresten
