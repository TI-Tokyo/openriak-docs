Riak Recap for January 4 - 5
=====================

1) Bip Thelin&#x27;s &quot;Zerolog&quot; project is now using Riak instead of Mnesia.

* More here ---&gt; <a href="https://twitter.com/#!/bipthelin/status/154890873744797697">https://twitter.com/#!/bipthelin/status/154890873744797697</a>

2) Basho Developer Scott Lystig Fritchie wrote an extensive blog post
about TCP Incast and how it can affect Erlang applications.

* This is well worth the read ---&gt;
<a href="http://www.snookles.com/slf-blog/2012/01/05/tcp-incast-what-is-it/">http://www.snookles.com/slf-blog/2012/01/05/tcp-incast-what-is-it/</a>

3) Related to #2: Voxer is using Riak to do billions of operations per
day. (You should all be using Voxer on your smart phones if you&#x27;re not
already. Go download it.)

* Details here ---&gt; <a href="http://www.marketwire.com/press-release/-1603652.htm">http://www.marketwire.com/press-release/-1603652.htm</a>

4) UnityPark has some docs up on their site on how to use Riak with
their game development environment.

* Getting started ---&gt;
<a href="http://developer.unitypark3d.com/ugamedb/manual/getting-started.html">http://developer.unitypark3d.com/ugamedb/manual/getting-started.html</a>
* Riak on VMware ---&gt;
<a href="http://developer.unitypark3d.com/ugamedb/manual/riak-on-vmware.html">http://developer.unitypark3d.com/ugamedb/manual/riak-on-vmware.html</a>

5) The ever-active Kresten Krab Thorup released a Fractal B-Tree
written in Erlang.

* Code here ---&gt; <a href="https://github.com/krestenkrab/fractal_btree">https://github.com/krestenkrab/fractal_btree</a>
