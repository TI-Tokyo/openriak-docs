</blockquote></div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg15172" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">John Daily</span><time datetime="2014-11-14T10:46:34-08:00">November 14, 2014 at 10:46 AM</time><span class="mailing-list-message__subject">Re: Is it possible to start with One node and increase later</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">The n_val represents the number of copies of the data, regardless of the number
of servers in the cluster. If you have n_val=3 and only 1 server, 3 copies of
each piece of data will be on that server (and performance will be generally
abysmal because every read and write request will effectively require 3
separate databases against the same disk I/O).

Riak is designed for extremely high availability, and simply isn’t designed to
run on 1 or 2 servers. Anything less than 5 is not recommended.

-John
