<blockquote>2.) What internal mechanisms are in Riak to do parallelizations of
large matrices?

</blockquote>Riak&#x27;s map reduce functionality allows parallel processing of map and reduce
functions over a given set of data but nothing specific to large matrices.

<blockquote>3.) How does Riak handle multiple cores in complex and data I/O
intensive algorithms?

</blockquote>The Erlang VM manages the spread of work over multiple cores on any single
node. Riak distributes work across a cluster via map reduce.
