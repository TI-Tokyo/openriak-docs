October 18 - October 28
==================

1) Callixte put together some instructions on running Riak on SmartOS.

* Try it out here ---&gt;
<a href="http://callixte.wordpress.com/2012/10/19/riak-on-smartos-outside-joyent-sdc/">http://callixte.wordpress.com/2012/10/19/riak-on-smartos-outside-joyent-sdc/</a>

module for modeling Riak docs and then providing common operations.

* Code here ---&gt; <a href="https://bitbucket.org/danostrowski/riakdocs">https://bitbucket.org/danostrowski/riakdocs</a>

* Getting your hands on Riak CS ---&gt;
<a href="http://basho.com/blog/technical/2012/10/18/try-riak-cs/">http://basho.com/blog/technical/2012/10/18/try-riak-cs/</a>

4) Nathan Lafreniere released protobuf.js, a pure javascript protocol
buffer encoding implementation, written specifically for Riak.

* Details and code here ---&gt; <a href="https://npmjs.org/package/protobuf.js">https://npmjs.org/package/protobuf.js</a>
* He&#x27;s also working on a client that wraps this encoding called
riakpbc ---&gt; <a href="https://github.com/nathan-lafreniere/riakpbc">https://github.com/nathan-lafreniere/riakpbc</a>

* Details here ---&gt; <a href="http://www.meetup.com/riak-manchester/">http://www.meetup.com/riak-manchester/</a>
