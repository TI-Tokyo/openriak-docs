To be clear, for production deployments we recommend using no fewer
than 5 nodes:

<a href="http://docs.basho.com/riak/latest/references/appendices/Cluster-Capacity-Planning/#Number-of-Nodes">http://docs.basho.com/riak/latest/references/appendices/Cluster-Capacity-Planning/#Number-of-Nodes</a>

<blockquote>When doing a backup ...
1. Do i need to remove the node from the load balancer?
</blockquote>
The process for backing up the LevelDB backend can be found here:

<a href="http://docs.basho.com/riak/latest/cookbooks/Backups/#LevelDB-Backups">http://docs.basho.com/riak/latest/cookbooks/Backups/#LevelDB-Backups</a>

<blockquote>2. How do i backup riak using nodejs? Can i run a cron or do i have to do
this manually?
</blockquote>
As the LevelDB backup link above mentions, running this in a cron job
is a good approach. You&#x27;re best bet is to use a tool like rsync for
the data directory backups – although, if you&#x27;re using a file system
with snapshot capabilities, that may be easier.
