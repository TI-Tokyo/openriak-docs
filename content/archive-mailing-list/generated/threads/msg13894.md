</div></div></details></li></ol></div></details></li></ol></div></details></li><li class="mailing-list-reply"><details id="msg13914" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Ryan Zezeski</span><time datetime="2014-03-24T18:51:07-07:00">March 24, 2014 at 6:51 PM</time><span class="mailing-list-message__subject">Re: updating the default bucket-type to support Solr indexing?</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">Actually, a bucket type is not required. To associate an index with a
bucket you simply set the `search_index` property. Bucket types provide a
method for many buckets to inherit the same properties. Setting the
search_index property on the bucket type is a way to index multiple buckets
under one index without setting the property on each bucket. Otherwise, I
would suggest setting the property at the bucket level and not the type
level.

The specific problem Paul ran into is that he tried to change properties
for the default type which is a special type that cannot be altered.
