Riak Recap for August 16 - 26
======================

1) Dave Parfitt got a little crazy and started tinkering with a Riak
OCaml client.

* Code here ---&gt; <a href="https://github.com/metadave/riak-ocaml-client">https://github.com/metadave/riak-ocaml-client</a>

2) Dave also spent some time hacking prelimary Riak support into YCSB.

* Still very beta ---&gt; <a href="https://github.com/metadave/YCSB/tree/master/riak">https://github.com/metadave/YCSB/tree/master/riak</a>

3) The crew at Puppet Labs is offering a bounty for a Riak module.
We&#x27;re also throwing in a RICON ticket for the eventual winner.

* Details here ---&gt;
<a href="http://puppetlabs.com/blog/puppet-module-bounty-logstash-riak-and-graphite/">http://puppetlabs.com/blog/puppet-module-bounty-logstash-riak-and-graphite/</a>

4) Sebastian Cohnen wrote a blog post on how to go about upgrading
from 0.14 to 1.2

* Read here ---&gt;  <a href="http://tisba.de/2012/08/20/migrating-riak-from-0-14-2-to-1-2/">http://tisba.de/2012/08/20/migrating-riak-from-0-14-2-to-1-2/</a>

5) There&#x27;s a new SF Riak Meetup on the calendar. This one is happening
on September 5th and will feature Andy Gross and Shanley Kane going
in-depth on Riak 1.2.

* Details here ---&gt;
<a href="http://www.meetup.com/San-Francisco-Riak-Meetup/events/78766672/">http://www.meetup.com/San-Francisco-Riak-Meetup/events/78766672/</a>

6) We announced a Riak Meetup in London happening this Wednesday.
(I&#x27;ll be on hand for this one.)

* Register here ---&gt; <a href="http://www.meetup.com/riak-london/events/79190462/">http://www.meetup.com/riak-london/events/79190462/</a>

7) AND there will be a Riak Meetup in Leeds on September 19th.

* Details here ---&gt; <a href="http://www.meetup.com/Leeds-Riak/events/78269232/">http://www.meetup.com/Leeds-Riak/events/78269232/</a>

8) Tom Santero gave a talk at the NYC Devops Meetup all about Riak and
how Basho does DevOps.

* Slides here (including a picture of our CEO shelling out cash for
RAM) ---&gt; <a href="https://speakerdeck.com/u/tsantero/p/devops-at-basho">https://speakerdeck.com/u/tsantero/p/devops-at-basho</a>

9) Tom has been busy. He gave a talk called &quot;The Persistence of Data&quot;
a few days before that at another NYC Meetup.

* Slides here ---&gt; <a href="https://speakerdeck.com/u/tsantero/p/the-persistence-of-data">https://speakerdeck.com/u/tsantero/p/the-persistence-of-data</a>

10) We added Nimbuzz to the production users page:

* Details here ---&gt; <a href="http://basho.com/company/production-users/#user-nimbuzz">http://basho.com/company/production-users/#user-nimbuzz</a>

11) Casey Rosenthal has some experimental code on GitHub that uses
Ripple to for calculating rolling averages.

* Check it out here ---&gt; <a href="https://github.com/clr/riak-rolling-average">https://github.com/clr/riak-rolling-average</a>

12) Riak-shim just hit 0.12.

* Latest here ---&gt;  <a href="https://twitter.com/rubygems/status/237731085201584128">https://twitter.com/rubygems/status/237731085201584128</a>

13) OJ Reeves releases version 0.2.3.0 of CorrugatedIron, the .NET
Client that he, Jeremiah Peschka, and a few others hack on. Keep an
eye on this code...

* Details here ---&gt; <a href="http://www.nuget.org/packages/CorrugatedIron">http://www.nuget.org/packages/CorrugatedIron</a>

14) John Glick spent some time channeling Larry Wall and released a
bit of experimental code that lets you work with Riak&#x27;s configs from
the command line.

* Code here ---&gt;   <a href="https://github.com/glickbot/riak-conf">https://github.com/glickbot/riak-conf</a>

15) Rodrigo De Castro wrote his fourth piece on Riak for DZone. This
one updates a few examples from &quot;Seven Databases in Seven Weeks&quot; to
run against Riak 1.2.

* Read here ---&gt; <a href="http://java.dzone.com/articles/riak-updated-examples-seven">http://java.dzone.com/articles/riak-updated-examples-seven</a>

16) If all goes to plan, Riak will be shipping with Fedora 18.

* Latest progress here ---&gt;  <a href="http://stg.fedoraproject.org/wiki/Features/Riak">http://stg.fedoraproject.org/wiki/Features/Riak</a>

17) Kaspar Tidemann wrote up a quick blog post on work coming to Riak-js.

* Read here ---&gt; <a href="http://www.kaspertidemann.com/future-development-of-riak-js/">http://www.kaspertidemann.com/future-development-of-riak-js/</a>

18) Matthew Eernisse added Riak support to his &quot;models&quot; JavaScript ORM.

* Start here ---&gt; <a href="https://twitter.com/mde/status/239454007578468352">https://twitter.com/mde/status/239454007578468352</a>

19) Lei Gu wrote up a Riak HTTP API cheat sheet on his blog.

* Post here ---&gt;
<a href="http://2rdscreenretargeting.blogspot.com/2012/08/riak-http-api-cheat-sheet.html">http://2rdscreenretargeting.blogspot.com/2012/08/riak-http-api-cheat-sheet.html</a>

20) Jean-Michel Lacroix has a proposal out for a Riak talk at ConFoo
happening next year in Montreal.

* He needs your votes ---&gt;
<a href="http://confoo.ca/fr/call-for-papers/speaker/jean-michel-lacroix">http://confoo.ca/fr/call-for-papers/speaker/jean-michel-lacroix</a>

21 ) Some Q &amp; A from Stack Overflow:

* Riak search queries via the java client ---&gt;
<a href="http://stackoverflow.com/questions/12038307/riak-search-queries-via-the-java-client">http://stackoverflow.com/questions/12038307/riak-search-queries-via-the-java-client</a>
