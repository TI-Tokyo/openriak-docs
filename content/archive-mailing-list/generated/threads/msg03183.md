Riak Recap for April 27 - May 1
=======================

1) Kresten Krab Thorup released some code a few weeks back that
enables you to use links to create simple secondary indexes in Riak.
There is now a blog post with some details on how that code works.

* Read here ---&gt;
<a href="http://www.javalimit.com/2011/04/using-to-index-riak-objects.html">http://www.javalimit.com/2011/04/using-to-index-riak-objects.html</a>

Thanks, Kresten.

2) Craig Brown, who runs the @nosqltips twitter account, posted a
video in which he builds a Riak cluster in seven minutes.

* Read and watch here ---&gt;
<a href="http://nosqltips.blogspot.com/2011/04/setting-up-riak-nosql-cluster-in-7.html">http://nosqltips.blogspot.com/2011/04/setting-up-riak-nosql-cluster-in-7.html</a>

Thanks, Craig.

* Details here for anyone interested ---&gt;
<a href="http://twitter.com/#!/hornbeck/status/63751824385130496">http://twitter.com/#!/hornbeck/status/63751824385130496</a>
