</div></div></details></li><li class="mailing-list-reply"><details id="msg00337" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Grant Schofield</span><time datetime="2010-05-12T15:08:41-07:00">May 12, 2010 at 3:08 PM</time><span class="mailing-list-message__subject">Re: Multiple clusters, same box</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">In order to run multiple nodes on a host, and consequently multiple clusters,
you will need to edit the vm.args and app.config for each embedded node  (an
embedded node being a copy of the rel/riak directory you built). For each of
these nodes you will need to change the &quot;-name r...@127.0.0.1&quot; setting in
etc/vm.args to something like &quot;-name no...@127.0.0.1&quot;  where X is the node
number. In the etc/app.config you will need to change all of the port settings
(handoff_port, pb_port, and web_port) so that they are unique to each node.

This will allow you to start multiple nodes. Once a node is running you can use
the &quot;riak-admin join&quot; to have it join another node and form a cluster.
