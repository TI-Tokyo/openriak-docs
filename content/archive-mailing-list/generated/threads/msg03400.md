-module(structs).

-export([
  from_dict/1,
  sort_by_value/2,
  unique/2
]).

...

% Sorts a list of structs by a given value.
sort_by_value(Structs, [Key, &lt;&lt;&quot;asc&quot;&gt;&gt;]) -&gt;
  lists:sort(
    fun({struct, A}, {struct, B}) -&gt;
      proplists:get_value(Key, A) &lt; proplists:get_value(Key, B)
    end,
    Structs
  );
sort_by_value(Structs, [Key, &lt;&lt;&quot;desc&quot;&gt;&gt;]) -&gt;
  lists:sort(
    fun({struct, A}, {struct, B}) -&gt;
      proplists:get_value(Key, A) &gt; proplists:get_value(Key, B)
    end,
    Structs
  );
sort_by_value(Structs, Key) -&gt;
  sort_by_value(Structs, [Key, &lt;&lt;&quot;asc&quot;&gt;&gt;])

--------------------------------------------------------------------

{riak_kv, [
        ...
        {add_paths, [&quot;/etc/riak/erl/&quot;]},
        ...
]}

--------------------------------------------------------------------

$ cd /etc/riak/erl/
$ erlc structs.erl
$ riak attach

Assuming you compiled your Erlang module to an &#x27;ebin&#x27; directory, a portion of
your app.config might look like this:

%% other configs...
{riak_kv, [
  %% ...
  {add_paths, [&quot;/path/to/your/ebin&quot;]},
  %% ...
]},
 %% ...

Alternatively you can use the &#x27;-pz&#x27; switch in vm.args to add a path to the code
loading directories. (See also: <a href="http://www.erlang.org/doc/man/erl.html">http://www.erlang.org/doc/man/erl.html</a>)

Ripple, specifically we are using the output of a Javascript Map to an
Erlang Reduce (If this is not supported, please let us know!)

</blockquote>Dan covered the proper way to do that in Ripple, but I might add that the
output of your JavaScript phase must make sense to the Erlang phase; that bit
is up to you.
