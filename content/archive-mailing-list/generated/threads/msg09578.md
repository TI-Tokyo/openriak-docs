Is there a way to tell the riak-java-client to not store attributes with
a null value into riak? I currently have a json object looking like this:

{&quot;status&quot;:1,
&quot;type&quot;:8,
&quot;content&quot;:&quot;some text&quot;,
&quot;receiver&quot;:17542,
&quot;sender&quot;:317825,
&quot;creationTime&quot;:1290565802000,
&quot;answered&quot;:false,
&quot;contentPath&quot;:null,
&quot;refValue&quot;:null,
&quot;countOrAmountValue&quot;:null,
&quot;subType&quot;:0}

which is derived from a POJO with these attributes. Note three values
are &quot;null&quot; and I would like to not store them into riak to save space.

Anyone?
