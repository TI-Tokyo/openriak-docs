A common cause is the riak user needs
write access to the $PIPE_DIR in order to start properly.  PIPE_DIR is
usually /tmp/riak/, check your riak script to make sure.  If the directory
doesn&#x27;t exist, it will be created with unix perm 755.  Verify that the
riak user owns that directory, and has write permission to the parent
directory.
