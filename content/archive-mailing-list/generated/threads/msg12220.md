We are pleased to announce the availability of Riak CS 1.4.1.   This is a bugfix release based on the 1.4.x series of Riak CS.

Fixes include:
Fix list objects crash when more than the first 1001 keys are in the pending delete stateFix crash in garbage collection daemonFix packaging bug by updating node_package dependency
The full release notes can be found here: <a href="https://github.com/basho/riak_cs/blob/develop/RELEASE-NOTES.org">https://github.com/basho/riak_cs/blob/develop/RELEASE-NOTES.org</a>

The packages can be found on our docs page here: <a href="http://docs.basho.com/riakcs/latest/riakcs-downloads/">http://docs.basho.com/riakcs/latest/riakcs-downloads/</a>

Thanks,
