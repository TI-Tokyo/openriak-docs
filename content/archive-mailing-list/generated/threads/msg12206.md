(develop branch, hash 601560bf9ea0859e598957c13733fbbb0e656e17 of the 6th
september)

The json object looks like this:

{&quot;where&quot;:{&quot;latitude&quot;:7430019,&quot;longitude&quot;:4210023,&quot;geolocation_p&quot;:&quot;7.430019,4.210023&quot;},&quot;timestamp&quot;:&quot;2013-09-08T01:10:07.752Z&quot;}

since there is already a dynamic field for *_p defined.

But the query:
<a href="http://127.0.0.1:8093/solr/my-index/select?q=*:*&amp;fq={!geofilt}&amp;spatial=true&amp;pt=7.430019%2C4.210023&amp;sfield=where_geolocation_p&amp;d=1">http://127.0.0.1:8093/solr/my-index/select?q=*:*&amp;fq={!geofilt}&amp;spatial=true&amp;pt=7.430019%2C4.210023&amp;sfield=where_geolocation_p&amp;d=1</a>

returns the error:
can not use FieldCache on multivalued field:
where_geolocation_p_0_coordinate

Looking at this:
<a href="http://stackoverflow.com/questions/7068605/solr-spatial-search-can-not-use-fieldcache-on-multivalued-field">http://stackoverflow.com/questions/7068605/solr-spatial-search-can-not-use-fieldcache-on-multivalued-field</a>

it seems the problem is the missing parameter and the dynamic field
declaration for *_coordinates in the configuration file.

Is this the cause of the problem?

The _yz_default.xml files in the data directory seems overwritten every
time riak is restarted, is there a way to customize the solr configuration
per bucket?

Thanks in advance,
Vincenzo.
