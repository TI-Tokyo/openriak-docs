Riak Recap for May 02 - 03
====================

1) Version 0.4.1.1 of MailRank&#x27;s Haskell client was just tagged.

Repo here ---&gt;  <a href="https://github.com/mailrank/riak-haskell-client">https://github.com/mailrank/riak-haskell-client</a>

2) Bradley Taylor posted a photo of some hardware he and Webster/Clay
just picked up for their Riak test cluster.

* You&#x27;ll want to look at this ---&gt;
<a href="http://twitter.com/#!/bradleyktaylor/statuses/65490049516572672">http://twitter.com/#!/bradleyktaylor/statuses/65490049516572672</a>

3) Stephan Seidt (@evilhackerdude) released a nifty bit of code
yesterday (while at JSConf) that watches &amp; syncs folders into a riak
bucket.

* Repo here on GitHub ---&gt; <a href="https://github.com/evilhackerdude/teriaki">https://github.com/evilhackerdude/teriaki</a>

Thanks, Stephan!

4) We merged a great chunk of code for riak_core from the team at Evax
that adds a standard OTP-style handle_info callback for vnode modules
to receive arbitrary messages from other processes.

* Initial pull request ---&gt; <a href="https://github.com/basho/riak_core/pull/49/">https://github.com/basho/riak_core/pull/49/</a>
* Actual commit details ---&gt;
<a href="https://github.com/basho/riak_core/commit/9df3f22d75e0022bdf9fcbf2baae937e29c3f6b6">https://github.com/basho/riak_core/commit/9df3f22d75e0022bdf9fcbf2baae937e29c3f6b6</a>

Thanks!

5) Sean Cribbs posted the slides from his talk yesterday at JSConf.

* Check them out here ---&gt; <a href="https://github.com/seancribbs/riak-apps-jsconf2011">https://github.com/seancribbs/riak-apps-jsconf2011</a>
