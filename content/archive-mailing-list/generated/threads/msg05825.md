Riak Recap for November 28 - 30
========================

1) We released some new code that makes it simple for Riak to talk to
Hadoop. Russell Brown wrote a great blog post all about it.

* Post (and code) here ---&gt;
<a href="http://basho.com/blog/technical/2011/11/29/Riak-and-Hadoop/">http://basho.com/blog/technical/2011/11/29/Riak-and-Hadoop/</a>
*** First three people to get the code working and write [to the list
| a blog post] about it will get some Riak swag from me. ***

2) Basho and Riak are going to have a significant presence in
Australia over the next few weeks.

* OJ Reeves, one of the author&#x27;s of Riak&#x27;s .NET Client, will be giving
a talk at Erlang Factory Lite in Brisbin called &quot;Riak: why should you
care?&quot; Details here ---&gt;
<a href="http://www.erlang-factory.com/conference/Brisbane2011/speakers/OliverReeves">http://www.erlang-factory.com/conference/Brisbane2011/speakers/OliverReeves</a>
* Basho Architect Steve Vinoski is also talking at Erlang Lite. His
talk will be all about YAWS. Details here ---&gt;
<a href="http://www.erlang-factory.com/conference/Brisbane2011/speakers/SteveVinoski">http://www.erlang-factory.com/conference/Brisbane2011/speakers/SteveVinoski</a>
* Steve will also be talking at YOW (as part of the track that OJ is
hosting) all about building distributed systems with Riak Core. (This
talk might literally be happening right now). tDetails here ---&gt;
<a href="http://yowaustralia.com.au/YOW2011/general/details.html?speakerId=2287">http://yowaustralia.com.au/YOW2011/general/details.html?speakerId=2287</a>

3) ErlangDC, which is happening this weekend in Washington, DC, is
sold out. However, if you were able to attend you can expect to see
the following talks and faces from the Basho Crew.

* Ryan Zezeski is giving a talk called &quot;From Java to Erlang.&quot; (Zezeski
is an amazing speaker. He is not to be missed.) Details here ---&gt;
<a href="http://erlangdc.com/speakers/ryan_zezeski/">http://erlangdc.com/speakers/ryan_zezeski/</a>
* Rusty Klophaus&#x27; talk is called &quot;Everybody Polyglot.&quot; Details here
---&gt; <a href="http://erlangdc.com/speakers/rusty_klophaus/">http://erlangdc.com/speakers/rusty_klophaus/</a>

4) Resourceful-Riak just hit 0.0.5.

* Code here ---&gt; <a href="http://search.npmjs.org/#/resourceful-riak">http://search.npmjs.org/#/resourceful-riak</a>

5) Basho Developer Reid Draper released chunk of code called
&quot;knockbox&quot;, an eventual consistency for toolbox for Clojure (inspired
by the work the Mochi team with Statebox.)

* Code here ---&gt; <a href="https://github.com/reiddraper/knockbox">https://github.com/reiddraper/knockbox</a>

6) We have a new feature request up features.basho.com.

* Read, comment and vote here ---&gt;
<a href="http://features.basho.com/entries/20721603-efficiently-count-keys-in-a-bucket">http://features.basho.com/entries/20721603-efficiently-count-keys-in-a-bucket</a>

7) For anyone in or around Stockholm tomorrow, there is still time to
be part of the NoSQL Road Show .

* Details and registration here ---&gt;
<a href="https://secure.trifork.com/nosql-stockholm-2011/registration/">https://secure.trifork.com/nosql-stockholm-2011/registration/</a>

8) Francisco Treacy has a new project called &quot;riak-pool.&quot; Ths aims to
provide some connection pooling when used with riakjs, the Riak&#x27;s node
client.

* Code here ---&gt; <a href="https://github.com/frank06/riak-pool">https://github.com/frank06/riak-pool</a>
