</blockquote></div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg11325" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Andrew Thompson</span><time datetime="2013-06-21T21:48:30-07:00">June 21, 2013 at 9:48 PM</time><span class="mailing-list-message__subject">Re: Riak does not work on ec2</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">By default AWS machines use NAT, they provide a temporary external IP
that is NATed through to the internal IP applied to the AWS instance.
You can also permanantly assign an &#x27;elastic IP address&#x27; if you want a
particular instance to always be reachable on a specific IP.

<a href="http://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-instance-addressing.html">http://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-instance-addressing.html</a>

When you put that public IP in the riak config file, it makes no sense
to Riak because that IP isn&#x27;t applied to any interface it knows about.
When you put the private IP in, it works, but you can&#x27;t access it. This
is probably because AWS is dropping inbound traffic by default:

<a href="http://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-network-security.html#default-security-group">http://docs.aws.amazon.com/AWSEC2/latest/UserGuide/using-network-security.html#default-security-group</a>

This is not a Riak problem, it is an issue with configuring AWS.
