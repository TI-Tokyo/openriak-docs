We just tagged Riak 0.10rc1, which is the first release candidate for
the 0.10 official release that should be out later this week.

If you&#x27;re feeling daring, we would encourage you to try it out. Be
sure to let us know if any bugs pop up.

You can get the tarball here:

<a href="http://downloads.basho.com/riak/riak-0.10/riak-0.10rc1.tar.gz">http://downloads.basho.com/riak/riak-0.10/riak-0.10rc1.tar.gz</a>

Full release notes will be out with the 0.10 release, but some
highlights include:

- Protocol Buffers Client (PBC) interface to Riak (info at ---&gt;  at
<a href="http://wiki.basho.com/display/RIAK/PBC+API">http://wiki.basho.com/display/RIAK/PBC+API</a> )
- Pre- and Post- commit hooks  (info at ---&gt;
<a href="http://wiki.basho.com/display/RIAK/Pre-+and+Post-Commit+Hooks">http://wiki.basho.com/display/RIAK/Pre-+and+Post-Commit+Hooks</a> )
- Various performance improvements

Enjoy and let us know what you think -

Mark
