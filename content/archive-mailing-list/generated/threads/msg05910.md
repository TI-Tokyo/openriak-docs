Riak Recap for December 7 - 8
=======================

1) Some new and updated documentation to pass along:

* Basho DA Justin Shoffstall added a page to the wiki with some info
about File System Tuning  ---&gt;
<a href="http://wiki.basho.com/File-System-Tuning.html">http://wiki.basho.com/File-System-Tuning.html</a>
* Elias Levy updated the MR/Search Docs. Updated content here ---&gt;
<a href="http://wiki.basho.com/Riak-Search---Querying.html#Querying-Integrated-with-Map-Reduce">http://wiki.basho.com/Riak-Search---Querying.html#Querying-Integrated-with-Map-Reduce</a>

2) The riak-entity code that the team at Circuit Hub is working on
just hit 0.1.4

* Latest here ---&gt; <a href="http://search.npmjs.org/#/riak-entity">http://search.npmjs.org/#/riak-entity</a>

3) Mathias Meyer wrote a great blog post about Consistent Hashing.

* Brew yourself a cup of coffee and go read this ---&gt;
<a href="http://www.paperplanes.de/2011/12/9/the-magic-of-consistent-hashing.html">http://www.paperplanes.de/2011/12/9/the-magic-of-consistent-hashing.html</a>

4) tddium, a hosted testing environment for Ruby Apps, launched today
with support for Riak.

* Blog post about it here ---&gt;
<a href="http://blog.tddium.com/2011/12/07/tddium-launches-with-riak-and-spinach-support/">http://blog.tddium.com/2011/12/07/tddium-launches-with-riak-and-spinach-support/</a>
* If anyone is interested in how well this integration works, I would
ping Chris Meikeljohn. (twitter.com/cmeik). He&#x27;s making use of it
already and apparently it&#x27;s quite nice.

5) Another video of Kresten Krab Thorup talking about Riak on Drugs
has surfaced. This one was recorded at Strange Loop.

* Watch here ---&gt;
<a href="http://www.infoq.com/presentations/Bringing-Riak-to-the-Mobile-Platform">http://www.infoq.com/presentations/Bringing-Riak-to-the-Mobile-Platform</a>

6) Sean Cribbs is handing out Basho/Riak gear.

* Details here ---&gt; <a href="http://twitter.com/#!/seancribbs/status/145254629972779008">http://twitter.com/#!/seancribbs/status/145254629972779008</a>

7) For anyone in the San Francisco area -  we started up a new meetup
called &quot;BashoChats&quot; that is aimed a discussing distributed systems and
large-scale computing trends.

* First meetup is happening this Wednesday. Details here ---&gt;
<a href="http://www.meetup.com/BashoChats/events/43849732/">http://www.meetup.com/BashoChats/events/43849732/</a>
