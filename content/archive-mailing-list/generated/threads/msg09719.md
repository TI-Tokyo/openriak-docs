Riak Recap for December 16 - Jan 1
==========================

1) Brian Roach is getting ready to tag the 1.0.7 release of the Riak
Java Client.

* The latest commits are here ---&gt;
<a href="https://github.com/basho/riak-java-client/commits/master">https://github.com/basho/riak-java-client/commits/master</a>

2) Riakasaurus, the Riak Twisted Client that Colin Alston and the
Praekelt team use and maintain, just added basic Protocol Buffers
Support.

* Latest here ---&gt; <a href="https://github.com/calston/riakasaurus">https://github.com/calston/riakasaurus</a>

3) Mark Steele released a Riak plugin for collectd.

* Code here ---&gt; <a href="https://github.com/marksteele/collectd-plugins">https://github.com/marksteele/collectd-plugins</a>

4) Basho is sponsoring SyncConf happening in Norwich, UK this February.

* Details here ---&gt;  <a href="https://twitter.com/SyncNorwich/status/280699800117202944">https://twitter.com/SyncNorwich/status/280699800117202944</a>

5) Christopher Biscardi started work on a Riak -&gt; Elastic Search River
a few weeks back.

* Code here ---&gt; <a href="https://github.com/ChristopherBiscardi/mau5">https://github.com/ChristopherBiscardi/mau5</a>

6) We released a new white paper that some of you might find useful.
This one is all about making the transition from a relation DB to
Riak.

* Details here ---&gt;
<a href="http://basho.com/blog/technical/2012/12/19/From-Relational-to-Riak/">http://basho.com/blog/technical/2012/12/19/From-Relational-to-Riak/</a>
* We&#x27;re also doing a live Webcast tomorrow all about this ---&gt;
<a href="http://info.basho.com/RelationalToRiakJan3.html">http://info.basho.com/RelationalToRiakJan3.html</a>

7) Jakob Sievers&#x27; &quot;MeshUp and other Riak hacks&quot; talk from London
Erlang Factory Lite was just released.

* Watch here ---&gt; <a href="http://www.youtube.com/watch?v=grbQujKcjro">http://www.youtube.com/watch?v=grbQujKcjro</a>

8) Yurii Rashkovskii announced that he and his team are working on a
&quot;concurrency-oriented k/v database&quot; based on Riak Core.

* Teaser here ---&gt; <a href="http://genomu.com/">http://genomu.com/</a>

9) InfoQ finally got around to posting Jesse Newland&#x27;s Erlang Factory
San Francisco talk from last year on Riak Core, Webmachine, and GitHub
Pages.

* Watch here ---&gt;
<a href="http://www.infoq.com/presentations/GitHub-Pages-Riak-Webmachine">http://www.infoq.com/presentations/GitHub-Pages-Riak-Webmachine</a>

10) Matthew Revell is giving a &quot;Intro to Riak&quot; talk at Erlang Factor
Lite in Munich next month.

* Details here ---&gt;
<a href="https://www.erlang-factory.com/conference/Munich2013/speakers/MatthewRevell">https://www.erlang-factory.com/conference/Munich2013/speakers/MatthewRevell</a>

11) Dave Parfitt has been getting all sorts of ambitious on his Riak
OCaml client development.

* Latest here ---&gt; <a href="https://twitter.com/metadave/status/286188589577035778">https://twitter.com/metadave/status/286188589577035778</a>

12) Last reminder about the Riak Meetup in Dublin on January 8th.

* RSVP here ---&gt; <a href="http://www.meetup.com/Dublin-Riak/events/91521922/">http://www.meetup.com/Dublin-Riak/events/91521922/</a>

13) There&#x27;s a new Riak Perl Client in town.

* On GitHub ---&gt; <a href="https://github.com/myfinder/p5-data-riak-fast">https://github.com/myfinder/p5-data-riak-fast</a>
* On CPAN ---&gt; <a href="http://search.cpan.org/~myfinder/Data-Riak-Fast-0.03/">http://search.cpan.org/~myfinder/Data-Riak-Fast-0.03/</a>

14) Eric Redmond&#x27;s &quot;Little Riak Book&quot; is looking better by the day.

* Latest here ---&gt; <a href="https://twitter.com/coderoshi/status/286483152925499392">https://twitter.com/coderoshi/status/286483152925499392</a>

15) Von Stark released a Ruby event machine client for Riak along with
a blog post about it.

* Code here ---&gt; <a href="http://tech.vonstark.co/post/38952977628/emriak">http://tech.vonstark.co/post/38952977628/emriak</a>
* Blog post <a href="http://tech.vonstark.co/post/38952977628/emriak">http://tech.vonstark.co/post/38952977628/emriak</a>

16) Casey Rosenthal took some time to hook Redis up to Riak (by
wrapping the Redis C client in an NIF)

* Code here ---&gt; <a href="https://github.com/clr/riak_kv_redis_backend">https://github.com/clr/riak_kv_redis_backend</a>
