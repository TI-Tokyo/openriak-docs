Riak Recap for June 25 - 28
=====================

1) We just announced the next Riak Meetup in LA. This one will feature the
OpenX team talking about using Riak in production and it&#x27;s happening on
July 18th. (Also, I&#x27;ll be in LA for the meetup, so if anyone in the area
wants to get together and talk Riak, let me know.)

* Details here ---&gt;
<a href="http://www.meetup.com/Los-Angeles-Riak-Meetup/events/71281742/">http://www.meetup.com/Los-Angeles-Riak-Meetup/events/71281742/</a>

2) John Vincent put together some code that adds Riak output support to
logstash. (Rumor has it that John wrote this on a plane, so from now any
Riak-related code written on a plane that I know about will get some
special swag. This is your incentive to keep me informed.)

* Details here ---&gt; <a href="https://twitter.com/lusis/status/217463225657204736">https://twitter.com/lusis/status/217463225657204736</a>

3) There&#x27;s a question on Quora about LevelDB vs. Bitcask

* Read and respond here ---&gt;
<a href="http://www.quora.com/Riak/Which-is-better-bitcask-or-leveldb">http://www.quora.com/Riak/Which-is-better-bitcask-or-leveldb</a>

4) Emily Rose has apparently been hacking on a new Node.js client for Riak,
though, for some reason, she was hiding it from us :)

* Code here ---&gt; <a href="https://github.com/nexxy/riakstar">https://github.com/nexxy/riakstar</a>

5) Mathias Meyer wrote a blog post about Riak and CRDTs. His posts are
always a worthwhile read.

* Blog here ---&gt;
<a href="http://www.paperplanes.de//2012/6/27/playing-with-riak-and-crdts.html">http://www.paperplanes.de//2012/6/27/playing-with-riak-and-crdts.html</a>

in London and want to swing by, shoot a message to ro...@basho.com.)

* Details here --&gt;
<a href="http://www.streetinsider.com/Press+Releases/Basho+Opens+U.K.+Office+to+Anchor+European+Operations/7547187.html">http://www.streetinsider.com/Press+Releases/Basho+Opens+U.K.+Office+to+Anchor+European+Operations/7547187.html</a>

* Code here ---&gt;  <a href="https://github.com/booo/riak_kv/tree/sqlite">https://github.com/booo/riak_kv/tree/sqlite</a>

yesterday in Boston. He shared some details on how he is using it in Riak
Control.
