Riak Recap for Dec. 13 - 14

1) Q ---  &quot;In terms of mime types beyond plain text, do you have plans
to integrate Tika or... In terms of mime types beyond plain text, do
you have plans to integrate Tika or similar to be able to index and
parse into plain text richer files like pdf&#x27;s, Word documents, etc?&quot;
(from Amit via The Riak Wiki)

    A  --&gt;
<a href="http://wiki.basho.com/display/RIAK/Riak+Search+-+Indexing?focusedCommentId=2687151#comment-2687151">http://wiki.basho.com/display/RIAK/Riak+Search+-+Indexing?focusedCommentId=2687151#comment-2687151</a>

2)  I stumbled onto a short but worthwhile post on a blog called
&quot;Venalis&quot; that talked a bit about Riak and riak-js (riakjs.org).

Post here ---&gt; <a href="http://blog.venalis.net/2010/12/duck-tape.html">http://blog.venalis.net/2010/12/duck-tape.html</a>

data bags&quot; that examined using Riak (and a few other solutions) for a
data encryption problem.

Post here ---&gt;
<a href="http://lusislog.blogspot.com/2010/12/chef-and-encrypted-data-bags.html">http://lusislog.blogspot.com/2010/12/chef-and-encrypted-data-bags.html</a>

Office in Boulder, CO a few weeks ago.

His slides are here ---&gt; <a href="http://www.slideshare.net/jonmeredith/riak-intro">http://www.slideshare.net/jonmeredith/riak-intro</a>

6) aphyr, seancribbs, and Tv had a convo about incrementing counters
using Riak.

Gist here --&gt; <a href="https://gist.github.com/742887">https://gist.github.com/742887</a>

7) Sean Cribbs pushed some code to support nascent key filters in Ripple.

Details here ---&gt; <a href="http://ow.ly/3pn21">http://ow.ly/3pn21</a>

and truly-excellent chunk of documentation for the Python client that
we just merged into the Basho repo.

Details here---&gt; <a href="https://github.com/basho/riak-python-client/">https://github.com/basho/riak-python-client/</a>

Generated and hosted docs here ---&gt;
<a href="http://basho.github.com/riak-python-client/">http://basho.github.com/riak-python-client/</a>

Thanks, Daniel!

be handed off to be spread around the ring.
