1. I would recommend checking out the master branch of the Java and
Ruby clients. I know there has been considerable work done already to
get them working with 2.0. The Erlang protocol buffers client is
currently 2.0 feature-complete.

2. <a href="https://github.com/basho/yokozuna/tree/develop/docs">https://github.com/basho/yokozuna/tree/develop/docs</a> - I hope you
will be pleasantly surprised at how easy it is to use Yokozuna.
Basically, you install a Java VM (I&#x27;ve tested it with OpenJDK 7 on
FreeBSD 9), and set &quot;yokozuna = on&quot; in your riak.conf file.

3. I don&#x27;t believe &quot;official&quot; migration plans have been outlined yet.
Let me check on this.
