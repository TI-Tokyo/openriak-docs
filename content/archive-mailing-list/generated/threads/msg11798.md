Yokozuna is killed off it takes more than 5 seconds to start. There are
several items in yokozuna HEAD that should fix this [1][2].

I think the best option is to build YZ from github:
<a href="https://github.com/basho/yokozuna/blob/master/docs/INSTALL.md#install-from-github">https://github.com/basho/yokozuna/blob/master/docs/INSTALL.md#install-from-github</a>

I recently rebuilt using `make stagedevrel` and this worked for me.

[2]: <a href="https://github.com/basho/yokozuna/pull/136">https://github.com/basho/yokozuna/pull/136</a>

{solr_startup_wait, 2500}

Dave
