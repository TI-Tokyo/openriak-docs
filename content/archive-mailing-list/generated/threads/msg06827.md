MapReduce bugs found in 1.1.0.

Current release notes for 1.1.1:
<a href="https://github.com/basho/riak/blob/1.1/RELEASE-NOTES.org">https://github.com/basho/riak/blob/1.1/RELEASE-NOTES.org</a>

this a try and give us feedback!
