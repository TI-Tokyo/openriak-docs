I&#x27;m creating Puppet configs for a Riak/Riak-CS/Stanchion stack.  Ideally I want
the stack to come up with some predefined users and buckets already created.
This is all predicated on having an admin user created in Riak-CS which is
problematic in the Puppet automation realm given this value has to be generate
via a POST to a running Riak-CS application and then set in the app.config file.

Is it possible to bootstrap Riak-CS with an admin user some other way than
POST&#x27;ing to a running app?

Thanks,
Dan

It is a bit tricky to automate.

While this isn&#x27;t a solution for Puppet, I created a Chef cookbook [0] that creates a CS admin user, populates the proper configuration files, and restarts services. We make use of this cookbook in our Vagrant Riak CS cluster project [1] [2].

Hopefully this is useful in trying to produce a solution for Puppet.

Hector
