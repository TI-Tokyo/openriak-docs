Riak Recap for March 28 - 31
=====================

1) Joseph Blomstedt&#x27;s Erlang Factory Slides are online. His talk was
called, &quot;Test First Construction of Distributed Systems&quot; and is a great
look at some of the approaches he and others at Basho take to writing and
testing the code that make up Riak&#x27;s internals.

* Slides here ---&gt;
<a href="http://speakerdeck.com/u/jtuple/p/test-first-construction-of-distributed-systems">http://speakerdeck.com/u/jtuple/p/test-first-construction-of-distributed-systems</a>

2) More from Erlang Factory: Jesse Newland gave an exceptional talk about
how he and a few others are rewriting GitHub Pages using Riak and
Webmachine.

* Slides here ---&gt;
<a href="http://speakerdeck.com/u/jnewland/p/github-pages-on-riak-and-webmachine">http://speakerdeck.com/u/jnewland/p/github-pages-on-riak-and-webmachine</a>

3) Some new code: Alice Kaerast just released a proof of concept of a Riak
plugin for Moodle 2.

* Code here on GitHub ---&gt; <a href="https://github.com/kaerast/repository_riak">https://github.com/kaerast/repository_riak</a>

4) New Stack Overflow Content:

* Issues building a three node Riak Cluster from Homewbrew install ---&gt;
<a href="http://stackoverflow.com/questions/9906386/running-a-three-node-riak-cluster-using-a-homebrew-installation">http://stackoverflow.com/questions/9906386/running-a-three-node-riak-cluster-using-a-homebrew-installation</a>
* Is there any way to use JS libraries in Riak? ---&gt;
<a href="http://stackoverflow.com/questions/9937416/is-there-anyway-to-use-js-libraries-in-riak">http://stackoverflow.com/questions/9937416/is-there-anyway-to-use-js-libraries-in-riak</a>

5) Colin Austin has picked up work on txriak, a library that the
AuricSystems crew released last year.

* Code here ---&gt; <a href="https://bitbucket.org/calston/txriak">https://bitbucket.org/calston/txriak</a>
