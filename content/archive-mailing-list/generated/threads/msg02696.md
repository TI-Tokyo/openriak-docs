Riak Recap for March 18 - 20

1) Ryan Zezeski took a break from patching Luwak to write a fantastic
blog post about what he&#x27;s doing with Riak at his day job.

* Read here ---&gt; <a href="http://www.progski.net/blog/2011/aol_meet_riak.html">http://www.progski.net/blog/2011/aol_meet_riak.html</a>

Thanks, Ryan.

2) Version 0.3.2.0 of MailRank&#x27;s Haskell Client made it into HackageDB.

* Latest package here ---&gt; <a href="http://hackage.haskell.org/package/riak-0.3.2.0">http://hackage.haskell.org/package/riak-0.3.2.0</a>
* Repo on Github ---&gt; <a href="https://github.com/mailrank/riak-haskell-client">https://github.com/mailrank/riak-haskell-client</a>

3) Q --- What is the cleanest way to completely shut down a cluster?
(from deinspanjer via #riak)

    A ---Run  &quot;riak stop&quot; on each individual node in the cluster.

4) We added a full wiki page all about Bitcask Configurations.

* Read up on your favorite merge settings here ---&gt;
<a href="http://wiki.basho.com/Bitcask-Configuration.html">http://wiki.basho.com/Bitcask-Configuration.html</a>

if one exists? (from halorgium via #riak)

one a while ago -&gt;
<a href="http://hg.mozilla.org/users/ibicking_mozilla.com/test-pilot-riak-frontend/">http://hg.mozilla.org/users/ibicking_mozilla.com/test-pilot-riak-frontend/</a>
Daniel has also recorded a few screencasts to show how it works. This
