One of my fellow coworkers found an issue in the Riak 1.3.2 RPM&#x27;s.  There
is a typo in the init script that causes `service riak status` to fail.
 This will cause those of you who use Chef, Puppet, Ansible some pain
because they expect status to work properly (as they should).

The issue is described in full here:
<a href="https://github.com/basho/riak/issues/343">https://github.com/basho/riak/issues/343</a>

I have built a new set of packages for RHEL 5, 6, and Fedora 17.  They
still have the version of 1.3.2, but now with a package revision of &#x27;2&#x27;.

If you have already installed a 1.3.2 package with RPM or Yum, you can use
the simple patch found here to patch your init script:
<a href="https://github.com/basho/riak/commit/c315dc9b68497a61fe18ebca7984b165cee8f32f.patch">https://github.com/basho/riak/commit/c315dc9b68497a61fe18ebca7984b165cee8f32f.patch</a>

The downloads page has been updated with the new packages
<a href="http://docs.basho.com/riak/1.3.2/downloads/">http://docs.basho.com/riak/1.3.2/downloads/</a>
For all RPM&#x27;s, the package version should be &quot;1.3.2-2&quot;.  If you see &quot;-1&quot;
then try hitting refresh on your browser.

Sorry for the mistake on my part and the hassle this might have caused
anyone.

Thanks,
