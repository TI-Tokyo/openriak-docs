This does look like a bug in riak_search&#x27;s PB implementation. For some
reason we extract the sort field from the query but never pass it to
anything to perform the sorting. I&#x27;ve opened an issue for this bug and
have started working on it:
<a href="https://github.com/basho/riak_search/issues/136">https://github.com/basho/riak_search/issues/136</a>.
