Riak Recap for September 26 - October 25
====================

Basho released Riak CS 1.4.2
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013639.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013639.html</a>

The UK&#x27;s National Health Service will be replacing an Oracle solution with Riak
- <a href="http://www.theregister.co.uk/2013/10/10/nhs_drops_oracle_for_riak/">http://www.theregister.co.uk/2013/10/10/nhs_drops_oracle_for_riak/</a>
- <a href="http://basho.com/nhs-implements-riak-to-improve-performance-and-patient-care/">http://basho.com/nhs-implements-riak-to-improve-performance-and-patient-care/</a>
-
<a href="http://basho.com/nhs-to-deploy-riak-for-new-it-backbone-with-quality-of-care-improvements-in-sight/">http://basho.com/nhs-to-deploy-riak-for-new-it-backbone-with-quality-of-care-improvements-in-sight/</a>

Seagate released their Kinetic Open Storage platform with help from Basho and
Riak
-
<a href="http://basho.com/basho-releases-ekinetic-driver-and-integrated-riak-backend-with-seagate-partnership/">http://basho.com/basho-releases-ekinetic-driver-and-integrated-riak-backend-with-seagate-partnership/</a>

Kivra talked in Dublin about switching to Riak for scale
- <a href="http://basho.com/kivra-built-their-secure-mailbox-service-on-riak/">http://basho.com/kivra-built-their-secure-mailbox-service-on-riak/</a>

Rovio, Basho, Angry Birds, and Riak caught the attention of Computer Weekly and
won the Best Technology Innovation award
-
<a href="http://basho.com/basho-is-the-winner-of-the-computer-weekly-european-user-awards-for-storage/">http://basho.com/basho-is-the-winner-of-the-computer-weekly-european-user-awards-for-storage/</a>

Basho CTO Justin Sheehy gave an interview to TechWeekEurope
- <a href="http://www.techweekeurope.co.uk/interview/it-life-basho-riak-130350">http://www.techweekeurope.co.uk/interview/it-life-basho-riak-130350</a>

Kresten Krab Thorup released a web hook for Riak that POSTs newly written
objects to a remote HTTP server
- <a href="https://github.com/krestenkrab/riak_webhook">https://github.com/krestenkrab/riak_webhook</a>

Ryan Zezeski has announced Yokozuna 0.10.0
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013566.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013566.html</a>

Hector Castro created a Cloud Foundry service broker for Riak
- <a href="https://github.com/hectcastro/cf-riak-service-broker">https://github.com/hectcastro/cf-riak-service-broker</a>

Bryce Kerley clarified the future (or lack thereof) for Ripple
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013589.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013589.html</a>

Alexey Kachayev has published a sample project leveraging Riak Pipe
- <a href="https://github.com/kachayev/riak-pipe-workshop">https://github.com/kachayev/riak-pipe-workshop</a>

Akash Manohar wrote a post on how to interact with Riak from Elixir
- <a href="http://akash.im/2013/09/30/using-riak-with-elixir.html">http://akash.im/2013/09/30/using-riak-with-elixir.html</a>

Sebastien Goasguen of Citrix created a walkthrough for setting up a Riak CS
cluster
- <a href="http://buildacloud.org/blog/290-a-look-at-riakcs-from-basho.html">http://buildacloud.org/blog/290-a-look-at-riakcs-from-basho.html</a>

A few members of the Salt Stack released a video of them spinning up a 100 node
Riak cluster with Salt SSH
- <a href="http://www.youtube.com/watch?v=uWGDC1PdySQ">http://www.youtube.com/watch?v=uWGDC1PdySQ</a>
- <a href="http://docs.saltstack.com/index.html">http://docs.saltstack.com/index.html</a> (for those of you who haven&#x27;t seen Salt
Stack yet)

Basho now has a dedicated conference page on Lanyrd, if you&#x27;re curious where
you can find us next
- <a href="http://lanyrd.com/basho/">http://lanyrd.com/basho/</a>

While we&#x27;re talking about 2.0 and CRDTs at RICON West, Joel Jacobson will be
talking about them in London
-
<a href="http://jaxlondon.com/sessions/conflict-free-replicated-data-types-eventually-consistent-systems">http://jaxlondon.com/sessions/conflict-free-replicated-data-types-eventually-consistent-systems</a>

Alex Rice published Azure benchmarks for Riak that started an interesting
discussion of benchmarking and points of concern for various cloud hosting
solutions
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013475.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-October/013475.html</a>

Drew Searcy posted a blog on troubleshooting Riak daemon startup problems
- <a href="http://drewsearcy.com/troubleshooting-riak-startup/">http://drewsearcy.com/troubleshooting-riak-startup/</a>

John Daily captured some of the differences between Riak and Riak CS
- <a href="http://basho.com/riak-cs-vs-riak/">http://basho.com/riak-cs-vs-riak/</a>
