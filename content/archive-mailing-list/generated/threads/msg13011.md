Riak Recap for November 11 - 17
=========================

Basho TE and resident Strunk and White enforcer John Daily wrote a superb
blog post about the perils of using clocks in a distributed system. (h/t to
David Greenstein for accidentally inspiring this post.)
- <a href="http://basho.com/clocks-are-bad-or-welcome-to-distributed-systems/">http://basho.com/clocks-are-bad-or-welcome-to-distributed-systems/</a>

Kaspar Bach Pedersen shipped a Riak plugin for the Laravel PHP Framework.
- <a href="http://www.packalyst.com/packages/package/bach-pedersen/laravel-riak">http://www.packalyst.com/packages/package/bach-pedersen/laravel-riak</a>

Kaspar&#x27;s PHP Client also hit 1.0. Nice work. :)
- <a href="https://github.com/TriKaspar/php_riak">https://github.com/TriKaspar/php_riak</a>

The 2nd RC Hangout was held last Friday. This one featured Tom Santero,
Jordan West, and Joe Devivo and was all about the bucket types and config
changes coming in 2.0.
- <a href="http://www.youtube.com/watch?v=lZk8cD-qFHM">http://www.youtube.com/watch?v=lZk8cD-qFHM</a>

Basho Hacker Reid Draper was did a podcast with the Cognitect crew about
all sorts of programming language nerdery (and Riak). Fans of testing
should be especially thrilled with this.
-
<a href="http://thinkrelevance.com/blog/2013/11/11/reid-draper-cognicast-episode-045">http://thinkrelevance.com/blog/2013/11/11/reid-draper-cognicast-episode-045</a>

Michael Klishin announced that Welle, his Clojure client, just hit
2.0.0-beta1 and supports Riak&#x27;s 1.4 counters.
- <a href="https://twitter.com/michaelklishin/status/402153188767571968">https://twitter.com/michaelklishin/status/402153188767571968</a>

Roger Diller and the team at Flex Rental Solutions are starting to use Riak
in production. He wrote a quick blog post introducing Riak and how they are
planning to use it.
- <a href="http://blog.flexrentalsolutions.com/2013/11/introducing-riak.html">http://blog.flexrentalsolutions.com/2013/11/introducing-riak.html</a>

Computer Weekly wrote a piece on Rovio&#x27;s usage of Riak.
-
<a href="http://www.computerweekly.com/news/2240209201/Angry-Birds-firm-handles-massive-growth-with-Riak-NoSQL-database">http://www.computerweekly.com/news/2240209201/Angry-Birds-firm-handles-massive-growth-with-Riak-NoSQL-database</a>

Basho&#x27;s News site got a facelift.
- <a href="http://basho.com/news/">http://basho.com/news/</a>

Basho Hacker Sam Elliott wrote a blog post about his experience as Basho&#x27;s
first Engineering Intern.
- <a href="https://plus.google.com/103355872742999660465/posts/YHyE9A7kGGN">https://plus.google.com/103355872742999660465/posts/YHyE9A7kGGN</a>

Brian Bickerton of OmniTI wrote a great blog on doing a live migration of a
Riak cluster.
- <a href="http://omniti.com/seeds/migrating-riak-do-it-live">http://omniti.com/seeds/migrating-riak-do-it-live</a>

We&#x27;ve got a bunch of meetups happening over the coming weeks:
- Riak New York City happening November 20th:
<a href="http://www.meetup.com/NYC-Riak-Meetup/events/149562832/">http://www.meetup.com/NYC-Riak-Meetup/events/149562832/</a>
- Riak at the Portland Big Data Group happening November 21st:
<a href="http://calagator.org/events/1250465215">http://calagator.org/events/1250465215</a>
- Riak Office Hours in San Francisco happening November 22nd:
<a href="http://www.meetup.com/San-Francisco-Riak-Meetup/events/151525382/">http://www.meetup.com/San-Francisco-Riak-Meetup/events/151525382/</a>
- BashoChats in San Francisco happening December 3rd:
<a href="http://www.meetup.com/BashoChats/events/150371752/">http://www.meetup.com/BashoChats/events/150371752/</a>
- Riak Chicago on December 11th:
<a href="http://www.meetup.com/Chicago-Riak-Meetup/events/151516252/">http://www.meetup.com/Chicago-Riak-Meetup/events/151516252/</a>

MVM&#x27;s work on dynamic cache sizing for LevelDB just landed in master.
- <a href="https://github.com/basho/leveldb/wiki/mv-flexcache">https://github.com/basho/leveldb/wiki/mv-flexcache</a>

Alexey Kachayev from attendify.com posted a slide deck all about the app
they built. They&#x27;ve got riak_core, riak_pipe, riak_test, and rebar (among
other interesting libraries) doing cool things.
- <a href="https://speakerdeck.com/kachayev/erlang-in-production-lessons-learned">https://speakerdeck.com/kachayev/erlang-in-production-lessons-learned</a>

GoGrid is now offering a &quot;Riak 1-Button Deploy™.&quot;
- <a href="http://www.gogrid.com/solutions/riak">http://www.gogrid.com/solutions/riak</a>
