Riak Recap for December 6 - 15
========================

1) Jason Coene is working on data types for Riak implemented in Ruby.

* Code here ---&gt; <a href="https://github.com/jcoene/rico">https://github.com/jcoene/rico</a>

2) Rémi started work on a PHP bundle for Riak (that looks like it&#x27;s
built with Symphony in mind).

* Code here ---&gt; <a href="https://github.com/remialvado/RiakBundle">https://github.com/remialvado/RiakBundle</a>

3) Riak 0.9.2 was just released.

* Details here ---&gt; <a href="https://github.com/mostlyserious/riak-js#092">https://github.com/mostlyserious/riak-js#092</a>

4) The next Portland Riak Meetup is happening on January 28th.

* Details here ---&gt; <a href="http://www.meetup.com/Portland-Riak/events/95049492/">http://www.meetup.com/Portland-Riak/events/95049492/</a>

5) The London Basho crew is doing Riak office hours on January 8th.

* Details here ---&gt; <a href="http://www.meetup.com/riak-london/events/94472242/">http://www.meetup.com/riak-london/events/94472242/</a>

6) Netherlands-based Gideon de Kok is hiring people who want to work
with Riak, Scala and Akka.

* Details here ---&gt; <a href="https://twitter.com/gideondk/status/279692550846160897">https://twitter.com/gideondk/status/279692550846160897</a>

7) Tim Freeman and his team at enStratus are looking for people to
hack Riak, RabbitMQ, Java, and more.

* Details here ---&gt; <a href="https://twitter.com/peakscale/status/279631781332938755">https://twitter.com/peakscale/status/279631781332938755</a>

8) Basho Hacker Matthew Von-Maszewski has been doing a lot of the
LevelDB work over the last few months. He was recently spotted on the
streets of Cambridge, running a 5k.

* Evidence here ---&gt;
<a href="http://www.flickr.com/photos/88357173@N08/8259960700/in/set-72157632211671190">http://www.flickr.com/photos/88357173@N08/8259960700/in/set-72157632211671190</a>

sharing again.

* Riak now has an official AWS AMI ---&gt;
<a href="http://basho.com/blog/technical/2012/12/14/Riak-on-Amazon-Marketplace-AMI">http://basho.com/blog/technical/2012/12/14/Riak-on-Amazon-Marketplace-AMI</a>

10) The Yokozuna work continues to come along at a fast pace. Basho
Hacker Eric Redmond just added sibling indexing.

* Code here ---&gt;
<a href="https://github.com/rzezeski/yokozuna/commit/12ea4bbf99f8667a6f4282081a0d2c05f9512984">https://github.com/rzezeski/yokozuna/commit/12ea4bbf99f8667a6f4282081a0d2c05f9512984</a>
