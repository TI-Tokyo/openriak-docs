My initial understanding of the riak_host variable in the Stanchion config
was that it needed to point at a proxy that load balances to the different
riak nodes. I think now I&#x27;m under the impression that it just needs to
point to a node in the riak cluster and that should be sufficient.

FYI, stanchion works only when you request to create user or bucket. So if you
don&#x27;t have much activity about it, stanchion can simply be pointed directly to
a riak node. You can used load balancer to avoid single point of failure on
riak node. Moreover, for your consideration, make sure you run only a stanchion
on a cluster to avoid race condition when creating user / bucket.
