Riak CS 2 moved to a new Ubuntu/Debian repository, at packagecloud.io.
However attempts to use it as per the documentation result in the message
&quot;Incorrect username or token&quot; and an HTTP status of 401.

This is because the docs give the URL as similar to:
deb <a href="https://packagecloud.io/basho/riak_cs/ubuntu/">https://packagecloud.io/basho/riak_cs/ubuntu/</a> precise main

However they are supposed to be?:

deb <a href="https://packagecloud.io/basho/riak-cs/ubuntu/">https://packagecloud.io/basho/riak-cs/ubuntu/</a> precise main

Note the dash instead of an underscore.
