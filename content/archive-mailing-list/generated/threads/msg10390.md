Riak Recap for March 6 - 12
===========================

1) A new release of the Perl library Net::Riak has been released. It
now supports SSL and secondary indexes

* ---&gt; <a href="http://search.cpan.org/~rge/Net-Riak-0.1701/">http://search.cpan.org/~rge/Net-Riak-0.1701/</a>

2) RICON update on the Basho Blog

* Hoodies! ---&gt;
<a href="http://basho.com/update-on-ricon-east-cfp-early-bird-and-talk-announcements/">http://basho.com/update-on-ricon-east-cfp-early-bird-and-talk-announcements/</a>

3) Will Laurance just released version 0.0.4 of Fuji CLI

* Package ---&gt; <a href="https://npmjs.org/package/fuji">https://npmjs.org/package/fuji</a>
* Github ---&gt; <a href="https://github.com/wlaurance/fuji">https://github.com/wlaurance/fuji</a>

4) Mark Phillips gave the inaugural presentation at the Twin Cities Riak Meetup

* Slides ---&gt;
<a href="https://speakerdeck.com/pharkmillups/riak-your-next-or-current-favorite-database">https://speakerdeck.com/pharkmillups/riak-your-next-or-current-favorite-database</a>

5) Cloud Talk in Bellevue, WA got a Riak Basics talk with Adron Hall +
surprise impromptu Windows Azure talk from Glenn Block + combo how it
all works together w/ VM Depot

* Adron&#x27;s slides ---&gt;
<a href="http://compositecode.com/coding-community/speaking-presentations-workshops/riak-windows-azure/">http://compositecode.com/coding-community/speaking-presentations-workshops/riak-windows-azure/</a>

6) Gideon de Kok wrote a post about how he&#x27;s using Riak, what hurdles
he had to overcome in development, and why he thinks it&#x27;s worth
it. Also, a breakdown of his Akka based Riak client, Raiku

* ---&gt;
<a href="http://lab050.com/blog/2013/3/7/how-we-use-riak-to-model-complexer-data-types">http://lab050.com/blog/2013/3/7/how-we-use-riak-to-model-complexer-data-types</a>

7) Andy Gross will be talking about building cloud services on Riak at
the next Silicon Valley Cloud Computing meetup

* ---&gt; <a href="http://www.meetup.com/cloudcomputing/events/101130082/">http://www.meetup.com/cloudcomputing/events/101130082/</a>

8) Simon Vans Collina stood in for Chris Molozian at TakeOff 2013 to

* Meetup details ---&gt;
