simple example, when I add &#x27;/bucket2/object2&#x27; I want to add a link to
the object in &#x27;/bucket1/object1&#x27; that points to the new object. I
would like to do this in javascript and would appreciate if someone
could help me get started. I could not find a single working example,
and have had difficulties in even getting the basics up and running.

What I have done so far is:

- Changed the js_source_dir directory to &#x27;./js_source&#x27;
- In js_source, I added a file &#x27;validate.js&#x27;:

var validateFunctions = {
  validate: function(v) {
     return v;
  }
};

module.exports = {&#x27;name&#x27;: validateFunctions }

- I created a new bucket as such:

curl -v -X PUT -H &quot;Content-Type: application/json&quot; -d &#x27;{&quot;props&quot;:
{&quot;precommit&quot;: [{&quot;name&quot;: &quot;validate&quot;}]}}&#x27;
<a href="http://127.0.0.1:8098/buckets/javascript/props">http://127.0.0.1:8098/buckets/javascript/props</a>

- I added a new key to this bucket:

curl -v -X PUT -d &#x27;{&quot;bar&quot;:&quot;baz&quot;}&#x27; -H &quot;Content-Type: application/json&quot;
 -H &quot;X-Riak-Vclock: a85hYGBgzGDKBVIszMk55zKYEhnzWBlKIniO8mUBAA==&quot;
<a href="http://127.0.0.1:8098/riak/javascript/doc?returnbody=true">http://127.0.0.1:8098/riak/javascript/doc?returnbody=true</a>

This results in a 403 &quot;PUT aborted by pre-commit hook&quot; failure.

Aside from the obvious &quot;how do I get it to work?&quot; question, I would like to know
1) if there is a working example on the web or a tutorial that shows

2) if I need to do anything when I change my Javascript files (restart

3) if there is a naming convention that I need to follow for my *.js files

So far, I have a a great experience getting to know Riak, but the

</blockquote>Riak&#x27;s JS engine doesn&#x27;t use CommonJS modules, so whatever you define in
the global namespace will be visible. module.exports will probably cause an
evaluation error.

<blockquote>- I created a new bucket as such:

curl -v -X PUT -H &quot;Content-Type: application/json&quot; -d &#x27;{&quot;props&quot;:
{&quot;precommit&quot;: [{&quot;name&quot;: &quot;validate&quot;}]}}&#x27;
<a href="http://127.0.0.1:8098/buckets/javascript/props">http://127.0.0.1:8098/buckets/javascript/props</a>

</blockquote>Because it&#x27;s in the global namespace, you should refer to it like so:
{&quot;name&quot;:&quot;validationFunctions.validate&quot;,&quot;language&quot;:&quot;javascript&quot;}

<blockquote>- I added a new key to this bucket:

curl -v -X PUT -d &#x27;{&quot;bar&quot;:&quot;baz&quot;}&#x27; -H &quot;Content-Type: application/json&quot;
-H &quot;X-Riak-Vclock: a85hYGBgzGDKBVIszMk55zKYEhnzWBlKIniO8mUBAA==&quot;
<a href="http://127.0.0.1:8098/riak/javascript/doc?returnbody=true">http://127.0.0.1:8098/riak/javascript/doc?returnbody=true</a>

This results in a 403 &quot;PUT aborted by pre-commit hook&quot; failure.

</blockquote>Because of the namespacing issue, the error was probably a function
dispatch problem.

<blockquote>Aside from the obvious &quot;how do I get it to work?&quot; question, I would like
to know
1) if there is a working example on the web or a tutorial that shows

</blockquote>Unfortunately, no. That&#x27;s something we should address soon.

<blockquote>2) if I need to do anything when I change my Javascript files (restart
server, re-initialize my buckets, ..)

</blockquote>You can run `riak-admin js_reload` to reload your JS files that are in the
js_source_dir.

<blockquote>3) if there is a naming convention that I need to follow for my *.js files

</blockquote>All *.js files from the js_source_dir (non-recursive) will be read and
evaluated on startup.

<blockquote>4) how to process links in Javascript

</blockquote>The format of the object is the same as in MapReduce, so refer to that
first:

<a href="http://wiki.basho.com/MapReduce.html#Phase-functions">http://wiki.basho.com/MapReduce.html#Phase-functions</a>

Basically, &quot;Links&quot; will be an entry in the metadata sub-object. IIRC each
link is an object with keys &quot;bucket&quot;,&quot;key&quot;,&quot;tag&quot;.
