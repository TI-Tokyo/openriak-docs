I ran into the same problem when following The Riak Fast Track.  My
problem was that the script actually wasn&#x27;t importing anything.  I
changed the script as follows which worked.  Maybe it will work for
you...

#!/usr/bin/env escript
main([Filename]) -&gt;
    {ok, Data} = file:read_file(Filename),
    %%Lines = tl(re:split(Data, &quot;\r?\n&quot;, [{return, binary},trim])),
    Lines = tl(re:split(Data, &quot;\r\n|\n|\r&quot;, [{return, binary},trim])),
    %%lists:foreach(fun(L) -&gt; LS = re:split(L, &quot;,&quot;),
format_and_insert(LS) end, Lines).
    AccOut = lists:foldl(fun(L, AccIn) -&gt; LS = re:split(L, &quot;,&quot;),
format_and_insert(LS, AccIn), AccIn + 1 end, 1, Lines),
    io:format(&quot;Inserted ~w lines~n&quot;, [AccOut]).

format_and_insert(Line, AccIn) -&gt;
    JSON =
io_lib:format(&quot;{\&quot;Date\&quot;:\&quot;~s\&quot;,\&quot;Open\&quot;:~s,\&quot;High\&quot;:~s,\&quot;Low\&quot;:~s,\&quot;Close\&quot;:~s,\&quot;Volume\&quot;:~s,\&quot;Adj
Close\&quot;:~s}&quot;, Line),
    %%Command = io_lib:format(&quot;curl -X PUT
<a href="http://127.0.0.1:8091/riak/goog/~s">http://127.0.0.1:8091/riak/goog/~s</a> -d &#x27;~s&#x27; -H &#x27;content-type:
application/json&#x27;&quot;, [hd(Line),JSON]),
    Command = io_lib:format(&quot;curl -X PUT
<a href="http://127.0.0.1:8091/riak/goog/~w">http://127.0.0.1:8091/riak/goog/~w</a> -d &#x27;~s&#x27; -H &#x27;content-type:
application/json&#x27;&quot;, [AccIn,JSON]),
    io:format(&quot;Inserting line ~w: ~s~n&quot;, [AccIn, hd(Line)]),
    os:cmd(Command).

I had the same issue.  The problem I found was that Riak wasn&#x27;t being
populated from the &quot;load_data&quot; script.  I believe the culprit was that the
slashes in the date field are unacceptable as a Riak key.  Later tutorials
expect the date to be in the format &quot;YYYY-MM-DD&quot; so I wrote a Ruby script to
parse and save as goog2.csv.  The load_data script then worked (which I
verified via curl <a href="http://127.0.0.1:8091/riak/goog">http://127.0.0.1:8091/riak/goog</a>).

Here&#x27;s the Ruby script in case it&#x27;s useful:

require &#x27;rubygems&#x27;
require &#x27;fastercsv&#x27;

cout = FasterCSV.open(&#x27;goog2.csv&#x27;,&#x27;w&#x27;)
FasterCSV.foreach(&#x27;goog.csv&#x27;) do |row|
        date_parts = row[0].split(&#x27;/&#x27;)
        org_date = Date.new((&quot;20&quot; + date_parts[2]).to_i, date_parts[0].to_i,
date_parts[1].to_i)
        mod_date = org_date.strftime(&quot;%Y-%m-%d&quot;)

        row2 = [mod_date]
        (1..6).each { |x| row2 &lt;&lt; row[x] }
        cout &lt;&lt; row2
end
