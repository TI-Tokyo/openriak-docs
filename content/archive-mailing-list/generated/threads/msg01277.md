Yes, you can search using the HTTP interface. For instance, the &quot;search&quot;
feature in the Python client just defines a map/reduce search input. The
map/reduce search interface is part of the standard REST API in Riak Search.
The wiki discusses search integration with map reduce here:
<a href="http://wiki.basho.com/display/RIAK/Riak+Search+-+Querying#RiakSearch-Querying-QueryingIntegratedwithMap%2FReduce">http://wiki.basho.com/display/RIAK/Riak+Search+-+Querying#RiakSearch-Querying-QueryingIntegratedwithMap%2FReduce</a>
