<a href="https://github.com/ramensen/riak_core/blob/rdb/rs-claim-tail-violations/docs/claim-fixes.md">https://github.com/ramensen/riak_core/blob/rdb/rs-claim-tail-violations/docs/claim-fixes.md</a>

discovery of these issues and some potential fixes
<a href="https://github.com/infinityworks/riak_core/blob/mas-claimv2issues/docs/ring_claim.md">https://github.com/infinityworks/riak_core/blob/mas-claimv2issues/docs/ring_claim.md</a>

TL:DR :-
Claim no longer generates rings with avoidable tail violations and
unbalanced vnode distributions.

We&#x27;re still figuring out the best way to release these as part of a Riak build.
