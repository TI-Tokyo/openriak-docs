Riak Recap for April 1 - 3
===================

1) kraay and aphyr had a great chat in #riak that started with &quot;I&#x27;m
evaluating using riak as a document store. I&#x27;d like to provide the end
user with ability to use JPath  (a weak form of XPath) as a means of
traversing the JSON doc and returning those related bits. What would
be the best way of doing this?&quot;

* Gist here ---&gt; <a href="https://gist.github.com/902437">https://gist.github.com/902437</a>

2)  Q --- Hi, does anybody play with basho_bench on cassandra or
hbase? (from aph via #riak)

    A --- <a href="https://github.com/basho/casbench">https://github.com/basho/casbench</a> is something that we wrote
to bench Cassndra using basho_bench. As far as HBase goes, we haven&#x27;t
seen any code (yet) that connects it to basho_bench.

For those of you who aren&#x27;t familiar with basho_bench, check out:

* <a href="https://github.com/basho/basho_bench">https://github.com/basho/basho_bench</a>
* <a href="http://wiki.basho.com/Benchmarking-with-Basho-Bench.html">http://wiki.basho.com/Benchmarking-with-Basho-Bench.html</a>
*
<a href="http://www.slideshare.net/BashoTechnologies/using-basho-bench-to-load-test-distributed-applications">http://www.slideshare.net/BashoTechnologies/using-basho-bench-to-load-test-distributed-applications</a>

3) Q --- Is luwak block size configurable in 0.14 (from thegreatape via #riak)

   A ---  It&#x27;s in master. See
<a href="https://github.com/basho/luwak/commit/a516abbe1956e74721c3d0bb8434b1b9d1cf0d8a">https://github.com/basho/luwak/commit/a516abbe1956e74721c3d0bb8434b1b9d1cf0d8a</a>

4) Q --- Anyone have any recommendation as to what client library to
use for scala? (from m-m via #riak)

   A --- Unfortunately Basho isn&#x27;t supporting a Scala lib at the
moment, and as far as I can tell there isn&#x27;t anything available open
source that&#x27;s current. If you don&#x27;t want to roll your own, your best
to start with the several that were released a while ago [a][b] and
see about doing some updating. Unless there is someone out there with
some code to share...

a - <a href="https://github.com/timperrett/riakka">https://github.com/timperrett/riakka</a>
b - <a href="https://github.com/softprops/ryu">https://github.com/softprops/ryu</a>

published a quick post on it.
