<nav class="mailing-list-toc" aria-label="Thread contents"><h2>In this thread</h2><ol><li><a href="#msg07318"><span>Scaliak 0.1.1-SNAPSHOT Available on OSSRH</span><small>Jordan West · Apr 25, 2012</small></a></li></ol></nav><section class="mailing-list-thread" data-thread-root="msg07318"><article id="msg07318" class="mailing-list-message mailing-list-message--root"><header class="mailing-list-message__header"><span class="mailing-list-message__author">Jordan West</span><time datetime="2012-04-25T08:06:34-07:00">April 25, 2012 at 8:06 AM</time></header><div class="mailing-list-message__body">Last week StackMob open-sourced the Riak client library we use in our Scala
applications, Scaliak (<a href="https://github.com/stackmob/scaliak">https://github.com/stackmob/scaliak</a>). 0.1.1-SNAPSHOT
is now published to Sonatype&#x27;s OSSRH (oss.sonatype.org). Only a 2.9.1
artifact is available at this time but we will providing ones for newer
versions of Scala soon (there are some blockers in releasing a 2.10
version, currently but 2.9.1-1/2.9.2 should be pretty straightforward). We
most likely will not provide artifacts for pre-2.9 versions of Scala unless
there are requests for it.

If you are using SBT:

scalaVersion := &quot;2.9.1&quot;
libraryDependencies += &quot;com.stackmob&quot; %% &quot;scaliak&quot; % &quot;0.1.1-SNAPSHOT&quot;

If you are using maven:

&lt;dependency&gt;
  &lt;groupId&gt;com.stackmob&lt;/groupId&gt;
  &lt;artifactId&gt;scaliak_2.9.1&lt;/artifactId&gt;
  &lt;version&gt;0.1.1-SNAPSHOT&lt;/version&gt;
&lt;/dependency&gt;

We&#x27;d love to hear any feedback people have on the library and contributions
are always welcome. We have been using Riak with the features implemented
in Scaliak in production for a little while now and will continue to
develop the library based on our priorities as well as those of the
community.

Cheers,
