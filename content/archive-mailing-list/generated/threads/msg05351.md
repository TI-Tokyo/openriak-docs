In addition to changing the -name setting in vm.args, you must also run the
&#x27;riak-admin reip&#x27; command. This command renames a node, essentially telling
the cluster that any data associated with the old node name should now be
associated with the new node name. The node in question should be offline
when you run the command.

More information is here:

   - <a href="http://wiki.basho.com/Command-Line-Tools.html#search-cmd">http://wiki.basho.com/Command-Line-Tools.html#search-cmd</a>
   - <a href="http://wiki.basho.com/Basic-Cluster-Setup.html#Configure-the-First-Node">http://wiki.basho.com/Basic-Cluster-Setup.html#Configure-the-First-Node</a>

Best,
Rusty
