The consistency mechanisms, Hinted Handoff, Active Anti-Entropy (AAE) and
Read Repair, all occur automatically.  You can get an overview  of the
Hinted Handoff progress using `riak-admin transfers`.  If you need more
detail, you can parse the cluster logs and look for the entries related to
Hinted Handoff and AAE.  As Read Repair is done on a per-request basis, it
is not logged.

Hope that helps,

Best,

</blockquote></div></div></details></li></ol></div></details></li><li class="mailing-list-reply"><details id="msg11426" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Kresten Krab Thorup</span><time datetime="2013-07-09T06:50:19-07:00">July 9, 2013 at 6:50 AM</time><span class="mailing-list-message__subject">Re: Riak consistency state hook</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">I&#x27;ve also been pondering these things.

The mere presence of out-of-sync handling begs the question of wether we should
show some information about that to &quot;end users&quot;, like much like some systems
may attaching a &quot;certainty&quot; to a given data point.

It would indeed make sense for some front-end operations to only be enabled
when the backing system has a high degree of in-sync, or perhaps the front-end
system should display a warning of sorts.

It would be good to know how much we&#x27;re currently &quot;out of date&quot;.  For a single
key, you can force a check by doing a lookup with a high PR value (reads from
primaries), and possibly you can even get that info by getting the details
structure back from a read/write.

For the &quot;system overall&quot;, it would be nice to have some kind of dashboard that
monitors stats for handoffs, read repairs, entropy work, etc.  From these stats
you can probably compute or display something that says &quot;how in sync&quot; the riak
system as a whole (or part) is right now.  Without such a system it is hard to
know &quot;what is normal&quot;.

In general however, it is very difficult to guarantee anything about such an
evaluation since it may change at any time, even before you get your response
back.
