[&quot;bucket1&quot;, &quot;k3&quot;],

of buckets and keys, and
then return them.

on the map reduce call. the strange thing is, if I issue GET on each
key, results are coming back
without any problem.

are there any subtle differences between GET vs map reduce that I&#x27;m
not understanding?
