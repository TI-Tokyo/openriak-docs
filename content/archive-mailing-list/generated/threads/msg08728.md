Riak Recap for September 19 - 26
=========================

1) We announced a few more RICON talks:

* Basho Hacker and Mad Scientist Andrew Thomspon will be talking about
why Multi Data Center Replication is a hard problem ---&gt;
<a href="http://basho.com/community/ricon2012/#andrew-thompson-talk">http://basho.com/community/ricon2012/#andrew-thompson-talk</a>
* Ines Sombra and Michael Brodhead from Engine Yard are giving a
first-hand account of porting a MySQL backed application to Riak in
the Cloud ---&gt; <a href="http://basho.com/community/ricon2012/#engine-yard-talk">http://basho.com/community/ricon2012/#engine-yard-talk</a>

2) It looks like there is a new Griffon plugin for Riak.

* Code here ---&gt; <a href="http://artifacts.griffon-framework.org/plugin/riak">http://artifacts.griffon-framework.org/plugin/riak</a>

3) We posted the slides from the recent webinar about Searching and
Querying Data in Riak.

* Slides here --&gt;
<a href="http://basho.com/blog/technical/2012/09/24/How-To-Search-And-Query-Data-In-Riak/">http://basho.com/blog/technical/2012/09/24/How-To-Search-And-Query-Data-In-Riak/</a>

4) Shantu Roy wrote a great blog post about the work he and a few
others have been doing to get Riak running on the Tier3 platform.

* Read and use here ---&gt; <a href="http://www.shanturoy.com/riak-tier3-blueprints-awesome">http://www.shanturoy.com/riak-tier3-blueprints-awesome</a>

between redundancy and latency in distributed systems (featuring some
Riak production latency data kindly donated by the smart people over
at Yammer).

* Read here ---&gt;
<a href="http://www.bailis.org/blog/doing-redundant-work-to-speed-up-distributed-queries/">http://www.bailis.org/blog/doing-redundant-work-to-speed-up-distributed-queries/</a>

Puppet Module. Congrats to haf! (Anyone using the code in production
yet? We&#x27;re big fans of it here at Basho and have started to contribute
to it.)

* Read here ---&gt;
<a href="http://puppetlabs.com/blog/puppet-module-bounty-winners-riak-graphite-and-logstash/">http://puppetlabs.com/blog/puppet-module-bounty-winners-riak-graphite-and-logstash/</a>
