That message is just a little bit of text that appears as part of the server
description and hence you can ignore it.

In Riak, you can&#x27;t create Buckets. Buckets are not an entity, they are just
used in conjunction with the Key to create a hash that identifies the
document/object you&#x27;re storing.

Just PUT a document to /riak/bucket/key and the bucket will &quot;exist&quot; at that
point. Remember that if you&#x27;re going to PUT or POST you&#x27;ll need to send it
some content (using the -d or --data-binary flags in CURL).

Hope that helps
OJ
