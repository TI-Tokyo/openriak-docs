Since the subject of this email includes &quot;solr&quot; I&#x27;m assuming you&#x27;re
talking about Riak 2.0 and Yokozuna.

You can see the default Solr schema here:
<a href="https://github.com/basho/yokozuna/blob/develop/priv/default_schema.xml">https://github.com/basho/yokozuna/blob/develop/priv/default_schema.xml</a>

It has an example of an &quot;ignored&quot; type as well as date fields and other types.

_rs_schema is the bucket containing Riak Search schemas, not Solr
schemas (like the subject of this email indicates). That being said,
you can run this command to retrieve the default Riak Search schema if
you&#x27;re using Search in Riak 1.4.X or earlier:

search-cmd show-schema default
