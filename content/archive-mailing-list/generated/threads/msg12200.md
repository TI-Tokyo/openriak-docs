I&#x27;ve released riak-ruby-client 1.4.1 moments ago. This version of the gem fixes
a few minor bugs and issues.

Issues:

* Test for object existence using head request, reported and fixed by
  Elias &quot;eliaslevy&quot; Levy in <a href="https://github.com/basho/riak-ruby-client/pull/102">https://github.com/basho/riak-ruby-client/pull/102</a>

Bugfixes:

* License missing from gemspec, reported by Benjamin &quot;bf4&quot; Fleischer
  in <a href="https://github.com/basho/riak-ruby-client/pull/108">https://github.com/basho/riak-ruby-client/pull/108</a>
* Debugger required by Gemfile, reported by Basho Giddyup
  in <a href="https://github.com/basho/riak-ruby-client/pull/114">https://github.com/basho/riak-ruby-client/pull/114</a>
* Issue when reading Git-based version numbers, reported and fixed by
  jacepp in <a href="https://github.com/basho/riak-ruby-client/pull/120">https://github.com/basho/riak-ruby-client/pull/120</a>

The Ruby gem is ready to go at
<a href="https://rubygems.org/gems/riak-client/versions/1.4.1">https://rubygems.org/gems/riak-client/versions/1.4.1</a> , and the source code,
issue tracker, and README are on GitHub at
<a href="https://github.com/basho/riak-ruby-client/tree/v1.4.1">https://github.com/basho/riak-ruby-client/tree/v1.4.1</a> .
