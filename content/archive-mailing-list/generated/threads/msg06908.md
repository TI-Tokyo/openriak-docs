Ubuntu versions 10.10 and 11.10.

I&#x27;m new to Riak, but I have two machines with public IP addresses. I
installed started to install Riak from source but work blocks ports for Git
so I installed via Debian package:
 wget <a href="http://downloads.basho.com/riak/riak-1.1.0/riak_1.1.0-1_i386.deb">http://downloads.basho.com/riak/riak-1.1.0/riak_1.1.0-1_i386.deb</a>

After installing on both machines I was able to do:
riak start
riak-admin status
riak stop

with no issues. I wanted to cluster these two machines machines together so
I found I need to edit vm.args and app.config. In vm.args I changed
-name riak@127.0.0.1
to
-name riak@1.2.3.4 (my public IP)

and in app.config I changed under riak_core
{http, [ {&quot;127.0.0.1&quot;, 8098 } ]},
to
{http, [ {&quot;0.0.0.0&quot;, 8098 } ]},

and under riak_kv
{pb_ip,   &quot;127.0.0.1&quot; },
to
{pb_ip,   &quot;0.0.0.0&quot; },

I think try
riak start
Riak failed to start within 15 seconds,
see the output of &#x27;riak console&#x27; for more information.
If you want to wait longer, set the environment variable
WAIT_FOR_ERLANG to the number of seconds to wait.

I&#x27;ve adjusted WAIT_FOR_ERLANG, but to no avail. Now, an interesting point
is that if I stop riak and change everything back to default, riak will
start successfully but riak-admin tools fail (saying node not running). I
have no idea where I&#x27;m going wrong. I&#x27;m not completely sure on the riak
cookie but it&#x27;s the same on both machines. I&#x27;ve experience the same
behavior on 4 machines. Two on a private network, two on public network.

Any help is appreciated.
Thanks

</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg06909" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Aphyr</span><time datetime="2012-03-06T14:05:18-08:00">March 6, 2012 at 2:05 PM</time><span class="mailing-list-message__subject">Re: Riak problems on Ubuntu (novice user)</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">First, for security reasons, don&#x27;t run Riak on a public IP. Access it
through an application proxy, a VPN, or an SSH tunnel if you need.

Second, when you change the name of a node, you need to run

riak-admin reip r...@my.old.ip r...@my.new.ip

... to update the ring file with the new node name. Only change the name
and reip when the node is not running. You can also just delete
/var/lib/riak/ring if you don&#x27;t care about the data on the node.

--Kyle
