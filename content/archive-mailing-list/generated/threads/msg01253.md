Finished this up the other day:

<a href="http://github.com/jnewland/gmond_python_modules/tree/master/riak/">http://github.com/jnewland/gmond_python_modules/tree/master/riak/</a>

I&#x27;m a python n00b, be gentle :)

Here&#x27;s a list of the metrics they track:

<a href="http://github.com/jnewland/gmond_python_modules/blob/master/riak/riak.conf">http://github.com/jnewland/gmond_python_modules/blob/master/riak/riak.conf</a>

To use python modules in Ganglia, you&#x27;ll need the following snippet in your
`gmond.conf`:

    modules {

      module {
        name = &quot;python_module&quot;
        path = &quot;/usr/lib/ganglia/modpython.so&quot;
        params = &quot;/usr/lib/ganglia/python_modules&quot;
      }

    ...

    }

Then, copy `ganglia.py` to `/usr/lib/ganglia/python_modules/`, and
`ganglia.conf` to `/etc/ganglia/conf.d` and restart gmond.

Please let me know if you have any problems, I&#x27;m happy to help :)
