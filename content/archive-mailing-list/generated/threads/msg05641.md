AMQP:

<a href="https://github.com/jbrisbin/lager_amqp_backend">https://github.com/jbrisbin/lager_amqp_backend</a>

It uses a re-connecting connection pool for sending messages, so it&#x27;s pretty
fast and will automatically recover if RabbitMQ goes down (but it does *not*,
at the moment, internally queue log messages if it can&#x27;t connect to the
broker).

The idea is to aggregate logging from riak_core applications, but you should be
able to use it in Riak/DB as well.
