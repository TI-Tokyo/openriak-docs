Riak Recap for July 15 - 17
====================

1) Ripple now has client-side &quot;Snowflake&quot; IDs, which will help when
you&#x27;re looking to make your keys unique and sortable.

* Details here ---&gt;  <a href="https://twitter.com/#!/seancribbs/status/92347802012762112">https://twitter.com/#!/seancribbs/status/92347802012762112</a>

2) Ryan Zezeski wrote a blog post about using Inline Fields to boost
Riak Search query performance.

* Read here ---&gt;
<a href="http://blog.basho.com/2011/07/18/Boosting-Riak-Search-Query-Performance-With-Inline-Fields/">http://blog.basho.com/2011/07/18/Boosting-Riak-Search-Query-Performance-With-Inline-Fields/</a>

3) Alen Mujezinovic just released a Riak based session backend for Django.

* Repo here ---&gt; <a href="https://github.com/flashingpumpkin/django-riak-sessions">https://github.com/flashingpumpkin/django-riak-sessions</a>
* On PyPI here ---&gt; <a href="http://pypi.python.org/pypi/django-riak-sessions/0.0.1">http://pypi.python.org/pypi/django-riak-sessions/0.0.1</a>

Thanks, Alen!

4) The Riak Chef Cookbook just got an update and now has a new home
unde the Basho GitHub Account.

* Details here ---&gt; <a href="https://twitter.com/#!/seancribbs/status/92954070553346049">https://twitter.com/#!/seancribbs/status/92954070553346049</a>
