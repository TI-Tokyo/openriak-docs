121 get_reduce_bucket_values(Records, {Start, Max}) -&gt;
122     Skip = get_skip_num(Start, Max),
123     io:format(&quot;get_reduce_bucket_values Records=~p Skip= ~p~n&quot;,
[length(Records), Skip]),

124     if length(Records) &gt;= Skip  -&gt;
125             %%NewList = lists:keysort(#pubsub_item.published, Records),
126             F = fun(#pubsub_item{published=Published1, level=Level1},
127                     #pubsub_item{published=Published2, level=Level2}) -&gt;
128                     if Level1 &gt; Level2 -&gt; true;
129                        Level1 == Level2 -&gt;
130                             if  Published1 &gt; Published2 -&gt; true;
131                                 true -&gt; false
132                             end;
133                        true -&gt; false
134                     end
135                 end,
136             NewList = lists:sort(F, Records),
137             R = lists:sublist(NewList, Skip, Max),
138             io:format(&quot;get_reduce_bucket_value R=~p Skip= ~p~n&quot;,
[length(R), skip]),
139             R;
140        true -&gt;
141             []
142             %Records
143     end.

(2i). My keys is ordered by date and so I could ask date period. If you need
results based on not dates but number of keys, you could name your keys like
&quot;00001&quot;, &quot;00002&quot;, etc. But it would be problem with strict number of results
if you sometimes drop some keys.
Example of mapred query with 2i(leveldb backend) and riak protocol buffers
client:

riakc_pb_socket:mapred(
    Conn,
    {index, &lt;&lt;&quot;page_bucket&quot;&gt;&gt;, &lt;&lt;&quot;$key&quot;&gt;&gt;, From = &quot;00001&quot;, To = &quot;00099&quot;},
    [{map, {modfun, riak_kv_mapreduce, map_object_value}, none, true}]
).
