little experiment together so I could well be wrong. It doesn’t actually build
any clusters, and uses the claim code out of context, ymmv

has it grown over time? Have you run the command riak-admin diag ring_preflists
as documented here
<a href="http://docs.basho.com/riak/kv/2.2.3/setup/upgrading/checklist/#confirming-configuration-with-riaknostic">http://docs.basho.com/riak/kv/2.2.3/setup/upgrading/checklist/#confirming-configuration-with-riaknostic</a>?
