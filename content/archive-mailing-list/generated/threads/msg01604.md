it by multi_backend:
<a href="https://issues.basho.com/show_bug.cgi?id=890">https://issues.basho.com/show_bug.cgi?id=890</a>

Rather than modifying the innostore.app file you can configure the default
innostore settings in your Riak app.config file:
[
{riak_core, [...riak_core settings...]},
{riak_kv, [...riak_kv settings...]},
{innostore, [{buffer_pool_size, 8589934592}, ...other settings...]}
]
