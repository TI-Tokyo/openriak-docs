Riak Recap for November 9 - 10
=======================

1) We merged a small contribution to the Erlang Protobuffs code from
Michel Rijnders.

* Commit here ---&gt;
<a href="https://github.com/basho/erlang_protobuffs/commit/9e662bd002b3e3ac3dbc1215b99890c321e8ceab">https://github.com/basho/erlang_protobuffs/commit/9e662bd002b3e3ac3dbc1215b99890c321e8ceab</a>

2) Rick Olson at GitHub wrote a short blog post about git.io, their
Riak-backed URL shortener.

* Read here ---&gt; <a href="https://github.com/blog/985-git-io-github-url-shortener">https://github.com/blog/985-git-io-github-url-shortener</a>
* Also, you can get to the Riak and Basho repos using git.io/riak and
git.io/basho, respectively.

3) Sean Cribbs posted the slides from the &quot;Embracing NoSQL and
Eventual Consistency with Ripple&quot; talk he gave at Ruby Conf Uruguay.

* These are well worth it ---&gt;
<a href="http://www.slideshare.net/seancribbs/embrace-nosql-and-eventual-consistency-with-ripple">http://www.slideshare.net/seancribbs/embrace-nosql-and-eventual-consistency-with-ripple</a>

4) Jon Brisbin has been busy again. :)

* Updated the RabbitMQ/Riak custom exchange to the 2.7 Rabbit release
---&gt; <a href="http://twitter.com/#!/j_brisbin/statuses/134703020725387265">http://twitter.com/#!/j_brisbin/statuses/134703020725387265</a>
* Released a new repo called &quot;rabbitmq-riak-code-vnode-dispatcher&quot;
that should help you use vnodes with RabbitMQ.

5) We added the ability to check your config file via the Riak command
line tools. (This has been around for a while but I&#x27;m not sure we
advertised it well enough.)

* Details here ---&gt;
<a href="http://wiki.basho.com/Command-Line-Tools---riak.html#chkconfig">http://wiki.basho.com/Command-Line-Tools---riak.html#chkconfig</a>

6) Jordan Schatz is working on a Racket API to Riak.

* Code here ---&gt; <a href="https://github.com/shofetim/Racket-Riak">https://github.com/shofetim/Racket-Riak</a>

7) Basho is hiring Developer Advocates.

* Details here ---&gt;  <a href="http://basho.com/careers/developer-advocate/">http://basho.com/careers/developer-advocate/</a>
