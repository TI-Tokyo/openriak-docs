character is being ignored and you&#x27;re getting a query for a range. Both the
original and the range query produce the same result:

# original
$ curl
<a href="http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570\/204004">http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570\/204004</a>
{&quot;keys&quot;:[&quot;art3&quot;,&quot;art1&quot;]}

#range
$ curl <a href="http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570/204004">http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570/204004</a>
{&quot;keys&quot;:[&quot;art3&quot;,&quot;art1&quot;]}

If I URL encode the query I get the right results back:

$ curl
<a href="http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570%2F204004">http://127.0.0.1:10018/buckets/youmag/index/contentid_bin/1570%2F204004</a>
{&quot;keys&quot;:[&quot;art3&quot;]}

Hope that helps
