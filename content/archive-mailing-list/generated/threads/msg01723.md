if you use the following

config.setMaxConnections(50);

</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg01731" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Jan Buchholdt</span><time datetime="2010-12-06T04:22:20-08:00">December 6, 2010 at 4:22 AM</time><span class="mailing-list-message__subject">Re: java client concurrent connection</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body"> The config.setMaxConnections is not connected to the underlying
httpConnectionManager. I guess that is an error in the implementation of
the RiakClient. Try to use something like:

RiakClient riakClient = new com.basho.riak.client.RiakClient(config);
MultiThreadedHttpConnectionManager cm =
(MultiThreadedHttpConnectionManager)
riakClient.getHttpClient().getHttpConnectionManager();

HttpConnectionManagerParams params = cm.getParams();
params.setDefaultMaxConnectionsPerHost(50);
