Although it is possible to interact with Riak and Riak CS on same
cluster, we&#x27;ll generally recommend that you use one Riak cluster to
back CS and another for standard Riak usage.

You can store any application data in Riak CS. Just be aware that
you&#x27;ll lose some of the query mechanisms Riak provides like secondary
indexes, search, and Map/Reduce.

--
Hector
