## Other Community News

1) The Twelfth ACM SIGPLAN Erlang Workshop, chaired by Basho engineer
Steve Vinoski with contributions from Basho engineers Kenji Rikitake
(Program Committee) and Scott Fritchie (Steering Committee), has
issued a call for papers.

* ---&gt; <a href="http://www.erlang.org/workshop/2013/">http://www.erlang.org/workshop/2013/</a>

2) The crew at Nopo Labs assembled a short blog post on getting Riak
1.3 up and running on Ubuntu 12.x

* ---&gt; <a href="http://nopolabs.com/2013/03/riak-1-3-0-dev-cluster-on-ubuntu-12-x/">http://nopolabs.com/2013/03/riak-1-3-0-dev-cluster-on-ubuntu-12-x/</a>

3) The video of Rob Zuber from Copious talking about Riak in production is now
live on the Basho blog

* ---&gt; <a href="http://basho.com/ron-zuber-on-copious-and-riak/">http://basho.com/ron-zuber-on-copious-and-riak/</a>

4) RiakUp is offering a managed Riak solution.

* ---&gt; <a href="http://riakup.com/">http://riakup.com/</a>

5) Gideon de Kok pushed a major update to Raiku, his Riak Scala Client

* Details here ---&gt; <a href="https://twitter.com/gideondk/status/306490438595002369">https://twitter.com/gideondk/status/306490438595002369</a>
* Also worth noting ---&gt; <a href="https://twitter.com/gideondk/status/306476092015919105">https://twitter.com/gideondk/status/306476092015919105</a>
* Github ---&gt; <a href="https://github.com/gideondk/Raiku">https://github.com/gideondk/Raiku</a>

6) Brian Akins released a Lua protocol buffer client driver for nxg_lua

* Project ---&gt; <a href="https://github.com/bakins/lua-resty-riak">https://github.com/bakins/lua-resty-riak</a>

7) Nodiak just hit version 0.2.1

* ---&gt; <a href="https://npmjs.org/package/nodiak">https://npmjs.org/package/nodiak</a>

8) Chad Depue talks frankly about how he and his team at Inaka
approach NoSQL DBs

* Blog post ---&gt;
<a href="http://inaka.net/blog/2013/02/26/dont-under-think-it-part-ii-sql-vs-nosql/">http://inaka.net/blog/2013/02/26/dont-under-think-it-part-ii-sql-vs-nosql/</a>

9) We wrote a few words on the Basho Blog about Multi-Datacenter Replication
for both backups and data locality.

* MDC blog post ---&gt;
<a href="http://basho.com/multi-datacenter-replication-backups-and-data-locality/">http://basho.com/multi-datacenter-replication-backups-and-data-locality/</a>

10) Will Lawrence started work on a Riak CLI called Fuji

* Code here ---&gt; <a href="https://github.com/wlaurance/fuji">https://github.com/wlaurance/fuji</a>

11) Basho Director of Training Casey Rosenthal is speaking at Railsconf Portand
this May

* Talk details ---&gt; <a href="http://www.railsconf.com/2013/talks#talk-17">http://www.railsconf.com/2013/talks#talk-17</a>

12) Ricardo Gonçalves and Paulo Almeida have an improved version of
their Dotted Version Vectors code, a sophisticated consistency tool
with similarities to vector clocks, with a proof of concept that
integrates with Riak

* Github ---&gt; <a href="https://github.com/ricardobcl/Dotted-Version-Vectors">https://github.com/ricardobcl/Dotted-Version-Vectors</a>
* Academic paper ---&gt;
<a href="http://gsd.di.uminho.pt/members/vff/dotted-version-vectors-2012.pdf">http://gsd.di.uminho.pt/members/vff/dotted-version-vectors-2012.pdf</a>

13) Dave Smith (dizzyd) pointed out on Twitter that there is
riak-admin command that blocks until Riak is ready to service requests

* ---&gt; <a href="https://twitter.com/dizzyd/status/308710172136710144">https://twitter.com/dizzyd/status/308710172136710144</a>

14) The Oracle Alchemist writes about Riak and talking to it via PL/SQL

* ---&gt; <a href="http://www.oraclealchemist.com/news/getting-busy-with-riak/">http://www.oraclealchemist.com/news/getting-busy-with-riak/</a>
