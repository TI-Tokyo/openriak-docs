On Fri, Dec 6, 2013 at 1:05 PM, Kartik Thakore &lt;kthak...@scratchd.ca&gt; wrote:

<blockquote>What is AAE?

</blockquote>Active Anti-Entropy. A background process introduced in Riak 1.3 for
repairing divergent and missing data using merkle trees.

<a href="http://docs.basho.com/riak/latest/theory/concepts/glossary/#Active-Anti-Entropy-AAE-">http://docs.basho.com/riak/latest/theory/concepts/glossary/#Active-Anti-Entropy-AAE-</a>

Yokozuna also supports AAE for maintaining object/index integrity. See the
PR for information about how Riak Search -&gt; Yokozuna upgrade paths work:
<a href="https://github.com/basho/yokozuna/pull/238">https://github.com/basho/yokozuna/pull/238</a>
