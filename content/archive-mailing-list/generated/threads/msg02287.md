Riak Recap for Feb. 9 - 10

1) All of the Basho web properties have been redesigned!

* Start here  -&gt; basho.com and click like crazy.

2) GigaOm wrote a piece on Basho, Riak, and the new round of funding.

* Read here ---&gt;
<a href="http://gigaom.com/cloud/nosql-startup-basho-raises-7-5m-for-riak/">http://gigaom.com/cloud/nosql-startup-basho-raises-7-5m-for-riak/</a>

3) ReadWriteWeb also ran a piece on Riak on Wednesday. This one
focused more on users, and highlighted Inagist, Mozilla and Wikia.

* Read here ---&gt;
<a href="http://www.readwriteweb.com/cloud/2011/02/how-3-companies-are-using-nosq.php">http://www.readwriteweb.com/cloud/2011/02/how-3-companies-are-using-nosq.php</a>

3.1) Which reminds me, if you&#x27;re using/planning to use Riak in
production and haven&#x27;t put yourself on the wiki yet, you should do so.
(It&#x27;s good for the soul.)

* Fork and contribute to this page here ---&gt;
<a href="http://wiki.basho.com/Who-is-Using-Riak.html">http://wiki.basho.com/Who-is-Using-Riak.html</a>

4) Francisco Treacy and the Widescript team started a twitter account
to keep people up to date on what&#x27;s happening with Riak-js, Riak&#x27;s
Node.js client. Follow it here ---&gt; <a href="http://twitter.com/riakjs">http://twitter.com/riakjs</a> Also, if
you haven&#x27;t seen <a href="http://riakjs.org/">http://riakjs.org/</a> yet, you&#x27;ll want to do so ASAP.

5) There is as Riak chat room set up on Convore ---&gt; <a href="https://convore.com/riak/">https://convore.com/riak/</a>

* Also, congrats are in order for Eric Florenzano (@ericflo) who
launched Convore this past Wednesday. (He&#x27;s also been know to use a
bit of Riak from time to time.)

6) Steve Gravell wrote a short and sweet piece about indexing data in
Riak Search.

* Read here ---&gt;
<a href="http://mokele.co.uk/2011/02/06/auto-index-by-riak-search-with-a-postcommit-hook.html">http://mokele.co.uk/2011/02/06/auto-index-by-riak-search-with-a-postcommit-hook.html</a>

7) Version 1.0.0.M2 of the Spring Data Key Value project was released.
Arguably the coolest new Riak-specific feature in this release is the
dedicated Groovy DSL for asynchronous Riak access.

* Details here ---&gt; <a href="http://forum.springframework.org/showthread.php?t=103207">http://forum.springframework.org/showthread.php?t=103207</a>

** Just out of curiosity, is anyone using/planning to use Spring +
Riak? Anything interesting to report?
