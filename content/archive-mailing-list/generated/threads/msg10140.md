</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg10142" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Brian Roach</span><time datetime="2013-02-15T23:57:13-08:00">February 15, 2013 at 11:57 PM</time><span class="mailing-list-message__subject">Re: best practices to work with buckets in java-client</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">You only ever need to use client.createBucket() if you want to change
the bucket properties from the defaults.

This is due to the way Riak works; a put or fetch operation that uses
a bucket that doesn&#x27;t exist will create that bucket with the default
bucket properties.

To be clear, if you do:

Bucket b = client.fetchBucket(&quot;Some_bucket&quot;).execute();

That bucket did not have to exist beforehand. It will be created with
the default properties.
