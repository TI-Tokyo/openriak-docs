</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg12131" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Gints</span><time datetime="2013-08-25T08:25:42-07:00">August 25, 2013 at 8:25 AM</time><span class="mailing-list-message__subject">Re: Adding Nodes to a Running Cluster</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">I believe they actually recommend adding all the nodes you want to add in a
single step, instead of one by one - this way the hand-off will happen only
once, and all the objects will go to the right nodes immediately.

If you add nodes one by one, the objects will have to do multiple
transitions, since each added node will cause a redistribution of which
nodes will be responsible for which objects, causing a hand-off process each
time, and you will consume more traffic, time and more resources to get the
same final result.
