Riak Recap for July 25 - 26
====================

1) Sean Cribbs and the Ripple Team just released version 0.9.7 of the
riak-client and riak-sessions gems.

* Details here ---&gt; <a href="http://twitter.com/#!/seancribbs/statuses/95873017992843265">http://twitter.com/#!/seancribbs/statuses/95873017992843265</a>

2) This made the List already but it&#x27;s worth sending them along again:
Rusty&#x27;s slides from the Secondary Indices talk he delivered at OSCON
on Monday are now available.

* Slides here ---&gt;
<a href="http://www.slideshare.net/rklophaus/querying-riak-just-got-easier-introducing-secondary-indices">http://www.slideshare.net/rklophaus/querying-riak-just-got-easier-introducing-secondary-indices</a>

* Comment thread on Hacker News with a lot of great discussion and Q &amp;
A ---&gt; <a href="http://news.ycombinator.com/item?id=2807968">http://news.ycombinator.com/item?id=2807968</a>

3) Denish Patel (@DenishPatel), with the help of Brian Clapper
(@neophenix), wrote a great blog post about how easy it is to
configure and use Circonus to monitor your Riak cluster.

* Read here ---&gt;
<a href="http://slowquery.blogspot.com/2011/07/monitoring-riak-using-circonus.html">http://slowquery.blogspot.com/2011/07/monitoring-riak-using-circonus.html</a>

Thanks, Denish and Brian!

4) Google wrote a quick blog post about their recently-released k/v
storage engine LevelDB. Diligent followers of Riak will recall that we
recently added support for LevelDB to Riak. This post has some
extensive benchmarks and also gives a shout out to...Riak :)

* Read here ---&gt;
<a href="http://google-opensource.blogspot.com/2011/07/leveldb-fast-persistent-key-value-store.html">http://google-opensource.blogspot.com/2011/07/leveldb-fast-persistent-key-value-store.html</a>

5) Russell Brown added some more details and graphs to the Java Client
benchmarking page on the wiki.

* Read up here ---&gt; <a href="http://wiki.basho.com/Java-Client-Benchmark.html">http://wiki.basho.com/Java-Client-Benchmark.html</a>

6) There are still a few seats left for tomorrow&#x27;s &quot;Riak at
Formspring&quot; talk in San Francisco.

Register here ---&gt;
<a href="http://www.meetup.com/San-Francisco-Riak-Meetup/events/24779281/">http://www.meetup.com/San-Francisco-Riak-Meetup/events/24779281/</a>

7) Looks like there&#x27;s a Riak talk happening on August 3rd at the
Austin NoSQL Meetup.

* Details here ---&gt; <a href="http://www.meetup.com/austin-nosql/events/27293601/">http://www.meetup.com/austin-nosql/events/27293601/</a>

8) For anyone at OSCON, Basho COO Tony Falco will be participating in
the &quot;Not Only SQL&quot; panel happening tomorrow morning.

* Details here ---&gt; <a href="http://www.oscon.com/oscon2011/public/schedule/detail/18959">http://www.oscon.com/oscon2011/public/schedule/detail/18959</a>

9) OJ Reeves (@thecolonial) added all the necessary links to the wiki
for the new .NET client, CorrugatedIron.

* Scroll down to &quot;.NET&quot; to get all the details if you haven&#x27;t already
---&gt; <a href="http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html">http://wiki.basho.com/Community-Developed-Libraries-and-Projects.html</a>

Thanks, OJ!

would advise you to take a glance at this if you have a moment :)

* On GitHub here ---&gt; <a href="https://github.com/basho/riak/commits/master">https://github.com/basho/riak/commits/master</a>
