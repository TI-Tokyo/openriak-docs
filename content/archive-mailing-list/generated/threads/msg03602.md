interface in favor of one of the more user-friendly serialization libraries
which support more languages, like Bert (<a href="http://bert-rpc.org/">http://bert-rpc.org/</a>) or
MessagePack (<a href="http://msgpack.org/">http://msgpack.org/</a>).  I would think Bert is a perfect fit for
Riak since it uses native Erlang binary which would make exposing the Erlang
client pretty seamless.  I&#x27;m not sure of the speed difference, but the fact
that Google only provides PB support in three languages seems to me to be a
bit of a hindrance.

Thoughts?
