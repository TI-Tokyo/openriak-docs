</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg17130" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Sargun Dhillon</span><time datetime="2016-03-08T08:40:55-08:00">March 8, 2016 at 8:40 AM</time><span class="mailing-list-message__subject">Re: Riak_ensemble implementation</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">If you want to learn to use riak_ensemble the library, the
documentation that Joe put together (and others)
<a href="https://github.com/basho/riak_ensemble/blob/develop/doc/Readme.md">https://github.com/basho/riak_ensemble/blob/develop/doc/Readme.md</a>

There&#x27;s real world usage of the code here:
-<a href="https://github.com/basho/riak_kv/blob/develop/src/riak_kv_ensembles.erl">https://github.com/basho/riak_kv/blob/develop/src/riak_kv_ensembles.erl</a>

Basically as a user, you have to create the root ensemble, add all
your nodes to it, and then create your individual, &quot;sub-ensembles&quot;.

You need to implement a backend, and this is a rough sketch of one:
<a href="https://github.com/basho/riak_ensemble/blob/develop/src/riak_ensemble_basic_backend.erl">https://github.com/basho/riak_ensemble/blob/develop/src/riak_ensemble_basic_backend.erl</a>

Due the design of Riak ensemble, and the fact that&#x27;s it&#x27;s effectively
a bunch of individual vertical Paxos group in conjunction with its
usage of single decree, over multi-decree paxos it has some
interesting fault-recovery semantics. An example of this is the
adjustable paranoia level -- it has some strong failure-recovery
semantics, so in the highest paranoia mode, if you have 5 nodes, and
one fails. When that node comes back, it will have to sync with 3/5 of
the other nodes to be considered good to go.

Even with this, riak ensemble is a pretty easy, fun library to use.
The fact that it&#x27;s a composition of single decree paxos groups it
makes it much simpler to understand, and you can implement SMR atop
it, like so: <a href="https://github.com/sargun/riak_ensemble/commits/sargun/redis">https://github.com/sargun/riak_ensemble/commits/sargun/redis</a>
(see the few extra commits)
