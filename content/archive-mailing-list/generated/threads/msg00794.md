Riak Recap for 7/26 - 7/27

1) More from the Riak + JavaScript world... Visionmedia added Riak
support to his &quot;Keys&quot; project, which is a unified interface for
node.js and various key/value stores.

Github repo here ---&gt; <a href="http://github.com/visionmedia/keys/commits/master">http://github.com/visionmedia/keys/commits/master</a>

2) Lateef Jackson updated &quot;Goriak,&quot; his Riak client for Google&#x27;s &quot;Go,&quot;
to work with Riak&#x27;s REST API. Go check it out... Thanks, Lateef!

Google Code repo here ---&gt; <a href="https://code.google.com/p/goriak/">https://code.google.com/p/goriak/</a>

3) Those of you who meticulously monitor the Riak Wiki may have
noticed that we added a few new pages as of late. Here are some
standouts.

We added a page all about Command Line Tools ---&gt;

<a href="http://wiki.basho.com/display/RIAK/Command-Line+Tools">http://wiki.basho.com/display/RIAK/Command-Line+Tools</a>

We also added a section called &quot;Community Processes&quot; which covers code
contributions and wiki contributions. Located here ---&gt;
<a href="http://wiki.basho.com/display/RIAK/Community+Processes">http://wiki.basho.com/display/RIAK/Community+Processes</a>

4) Sean Cribbs and Dan Reverri put together a lengthy and informative
blog post as a follow up to the MapReduce webinar from last week. If
you asked a question but there wasn&#x27;t time to answer it, it&#x27;s
mostly-likely covered in this post.

Link here
---&gt;<a href="http://blog.basho.com/2010/07/27/webinar-recap---mapreduce-querying-in-riak/">http://blog.basho.com/2010/07/27/webinar-recap---mapreduce-querying-in-riak/</a>

the pond. There has been a sighting in France! (h/t to @cstar for
posting this!)

Pic here ---&gt; <a href="http://twitter.com/cstar/statuses/19729200836">http://twitter.com/cstar/statuses/19729200836</a>
