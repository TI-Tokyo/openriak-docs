I googled this error message:
*&quot;cannot restore segment prot after reloc: Permission denied&quot;*

Found this trick from here:
<a href="http://www.appistry.com/community/forums/content/cannot-restore-segment-prot-after-reloc-permission-denied">http://www.appistry.com/community/forums/content/cannot-restore-segment-prot-after-reloc-permission-denied</a>

Where it said that CentOS 5 has the SE Linux feature set to &quot;enforcing&quot;

Riak is started successfully after running /usr/sbin/setenforce 0

Thanks again!
