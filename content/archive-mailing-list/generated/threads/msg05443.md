Riak Recap for November 2 - 3
=======================

1) Dave &quot;Dizzy&quot; Smith, Basho&#x27;s Director of Engineering, was named
&quot;Erlang User of the Year.&quot;

* There&#x27;s a tweet here about it ---&gt;
<a href="http://twitter.com/#!/FrancescoC/status/132133925953875969">http://twitter.com/#!/FrancescoC/status/132133925953875969</a> (and I
suspect there will be something more substantial to point to soon)

2) Some updates to the Riak Wiki:

* We added some info about VNode Vector Clocks (which are new in Riak
1.0) ---&gt; <a href="http://wiki.basho.com/Vector-Clocks.html#VNode-Vector-Clocks">http://wiki.basho.com/Vector-Clocks.html#VNode-Vector-Clocks</a>
* Details on Riak&#x27;s Storage Backend API ---&gt;
<a href="http://wiki.basho.com/Backend-API.html">http://wiki.basho.com/Backend-API.html</a>

3) A short piece about Riak (complete with code) appeared on NetKernel.org:

* Read here ---&gt;
<a href="http://wiki.netkernel.org/wink/wiki/NetKernel/News/3/2/November_4th_2011#NoSQL_and_ROC">http://wiki.netkernel.org/wink/wiki/NetKernel/News/3/2/November_4th_2011#NoSQL_and_ROC</a>

4) Jon Brisbin released &quot;jstatebox&quot; which is a JVM implmentation of
Mochi Media&#x27;s &quot;statebox&quot; code.

* Here on GitHub ---&gt; <a href="https://github.com/jbrisbin/jstatebox">https://github.com/jbrisbin/jstatebox</a>

5) Basho is holding a webinar on November 16th all about the admin
improvements in Riak 1.0.

* Details and registration here ---&gt;
<a href="http://basho.com/contact/webinar-registration/">http://basho.com/contact/webinar-registration/</a>

6) For anyone in/around London: we are holding another NoSQL Road Show
Event on November 29th.

* Details here ---&gt;  <a href="http://nosqlroadshow.com/nosql-london-2011">http://nosqlroadshow.com/nosql-london-2011</a>

7) If anyone is going to RubyConf Uruguay next week, Sean Cribbs will
be there talking about his &quot;Webmachine-Ruby&quot; project. I&#x27;m sure he
wouldn&#x27;t mind talking about Riak, either.

* Details here ---&gt; <a href="http://rubyconfuruguay.org/en/agenda#10">http://rubyconfuruguay.org/en/agenda#10</a>

8) And last, but certainly not least, Basho raised another $5M in
funding and (formally) announced that the Danish Government chose Riak
as part of its health infrastructure.

* Press release on basho.com ---&gt;
<a href="http://basho.com/news/danish_government_licenses_riak">http://basho.com/news/danish_government_licenses_riak</a>
* Some slides with more information about the use case ---&gt;
<a href="http://gotocon.com/dl/goto-aarhus-2011/slides/KrestenKrabThorup_CaseStudyRiakOnDrugsandTheOtherWayAround.pdf">http://gotocon.com/dl/goto-aarhus-2011/slides/KrestenKrabThorup_CaseStudyRiakOnDrugsandTheOtherWayAround.pdf</a>
