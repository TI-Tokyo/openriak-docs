require_once(&#x27;riak-php-client/riak.php&#x27;);

# Connect to Riak
$client = new RiakClient(&#x27;127.0.0.1&#x27;, 8098);

# Choose a bucket name
$bucket = $client-&gt;bucket(&#x27;test&#x27;);

# Supply a key under which to store your data
$person = $bucket-&gt;newObject(&#x27;riak_developer_1&#x27;, array(
    &#x27;name&#x27; =&gt; &quot;John Smith&quot;,
    &#x27;age&#x27; =&gt; 28,
    &#x27;company&#x27; =&gt; &quot;Facebook&quot;
));

# Save the object to Riak
$person-&gt;store();

# Fetch the object
$person = $bucket-&gt;get(&#x27;riak_developer_1&#x27;);

# Update the object
$person-&gt;data[&#x27;company&#x27;] = &quot;Google&quot;;
$person-&gt;store();

If you did not import the class in your php file, you need to use the fully
qualified name which is \Basho\Riak\Riak like this:

$client = new \Basho\Riak\Riak(&#x27;127.0.0.1&#x27;, 8098);

The name change form RiakClient to Riak happened recently (probably as part of
the PSR1 and PSR2 refactoring).
