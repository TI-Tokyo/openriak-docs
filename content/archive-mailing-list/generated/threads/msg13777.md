</blockquote>Hi Tim,

An index may not be deleted if it has any buckets associated with
it. The &#x27;search_index&#x27; property (not &#x27;search-index&#x27;) must be changed
to either a different index or the sentinel value &#x27;_dont_index_&#x27;.
