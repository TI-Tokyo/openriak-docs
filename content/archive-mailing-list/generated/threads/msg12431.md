You can do a HEAD request to just get the object&#x27;s metadata. In the PB api,
there&#x27;s a boolean `head` that you can set to do the same. It doesn&#x27;t return the
object&#x27;s value(s) for either interface.

Docs:
PB:
<a href="http://docs.basho.com/riak/latest/dev/references/protocol-buffers/fetch-object/#Request">http://docs.basho.com/riak/latest/dev/references/protocol-buffers/fetch-object/#Request</a>
HTTP: Send the regular request, only using the HEAD method instead of GET
