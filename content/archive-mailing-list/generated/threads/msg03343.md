Riak Recap for May 13 - 15
====================

1) We added Swipely to the list of production deployments on the Riak Wiki.

* Check it out here ---&gt; <a href="http://wiki.basho.com/Who-is-Using-Riak.html#swipely">http://wiki.basho.com/Who-is-Using-Riak.html#swipely</a>

Anyone else out there in production and want to tell the community
about your Riak usage? Get in touch with me to claim your production T
Shirt...

2) Last reminder about the Riak Meetup happening in NYC on Wednesday.
The agenda has been updated to reflect the awesome talk that Basho CTO
Justin Sheehy will be delivering.

* Details here ---&gt; <a href="http://www.meetup.com/NYC-Riak-Meetup/events/17293915/">http://www.meetup.com/NYC-Riak-Meetup/events/17293915/</a>

want to meet up and talk Riak and Rails.

* Details here ---&gt; <a href="https://twitter.com/#!/scottmlikens/status/69891396445806592">https://twitter.com/#!/scottmlikens/status/69891396445806592</a>

<a href="https://github.com/cloudfoundry/vcap/blob/master/docs/erlang-otp.md">https://github.com/cloudfoundry/vcap/blob/master/docs/erlang-otp.md</a>

7) Last reminder for tomorrow night&#x27;s &quot;Getting Started with Riak&quot; talk
happening at the Arlington/DC Erlang User Group.

* Details here ---&gt; <a href="http://www.meetup.com/erlang/events/17550721/">http://www.meetup.com/erlang/events/17550721/</a>

8) Q --- Hi, what is the default read quorum in java api? Can&#x27;t find
it anywhere. (from TB123 via #riak)

    A --- The default is actually called &quot;Quorum&quot;, which is calculated
based on your n_val. With the default n_val of 3, Quorum is going to
be 2 on a read. The code that handles this is here ---&gt;
<a href="https://github.com/basho/riak_kv/blob/master/src/riak_kv_util.erl#L143">https://github.com/basho/riak_kv/blob/master/src/riak_kv_util.erl#L143</a>

9) Max Beutel contributed a small fix to the PHP Client.

* Details here ---&gt; <a href="https://github.com/basho/riak-php-client/pull/13">https://github.com/basho/riak-php-client/pull/13</a>

Thanks, Max!
