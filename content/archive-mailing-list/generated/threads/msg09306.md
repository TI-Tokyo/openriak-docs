ami-46a3272f contains a preview release of riak_dt (
<a href="http://github.com/basho/riak_dt">http://github.com/basho/riak_dt</a>), which brings support for PN-Counters (and
other future work on CRDTs) to Riak. If you hadn&#x27;t had a chance to check it
out I highly suggest watching Russell Brown and Sean Cribbs speak about the
work at RICON (<a href="http://vimeo.com/52414903">http://vimeo.com/52414903</a>) and checking out their slides (
<a href="https://speakerdeck.com/basho/data-structures-in-riak">https://speakerdeck.com/basho/data-structures-in-riak</a>).

To get started you can follow the exact same instruction for setting up the
yokozuna preview (
<a href="https://github.com/rzezeski/yokozuna/blob/master/docs/EC2.md">https://github.com/rzezeski/yokozuna/blob/master/docs/EC2.md</a>) except
use ami-46a3272f instead of the yokozuna ami (ami-9c2d96f5):

  ec2-run-instances ami-46a3272f -k &lt;YOUR_KEY&gt; -n &lt;NUM_NODES&gt;

More information about riak_dt can be found in the README:

<a href="https://github.com/basho/riak_dt/blob/master/README.md">https://github.com/basho/riak_dt/blob/master/README.md</a>

Cheers,
