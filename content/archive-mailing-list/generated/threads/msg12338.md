The riak-ruby-client gem was updated to 1.4.2 in the last few minutes. Release
1.4.2 fixes a couple bugs and a documentation/usability issue.

Issues:

* Secondary index queries against non-2i-enabled buckets/backends now raise a
  useful exception.

Bugfixes:

* 2i Requests over PBC block forever when 0 results match in 1.4.x,
  reported by Sean &quot;graphex&quot; McKibben in
  <a href="https://github.com/basho/riak-ruby-client/pull/121">https://github.com/basho/riak-ruby-client/pull/121</a> and
  <a href="https://github.com/basho/riak-ruby-client/pull/122">https://github.com/basho/riak-ruby-client/pull/122</a>
* RObject#links is an Array when loaded from PBC, reported by Dan Pisarski in
  <a href="https://github.com/basho/riak-ruby-client/pull/123">https://github.com/basho/riak-ruby-client/pull/123</a>
* Bucket listing doesn&#x27;t work with HTTP backend,
  reported and fixed by Wagner Camaro in
  <a href="https://github.com/basho/riak-ruby-client/pull/124">https://github.com/basho/riak-ruby-client/pull/124</a>

The Ruby gem is ready to go at
<a href="https://rubygems.org/gems/riak-client/versions/1.4.2">https://rubygems.org/gems/riak-client/versions/1.4.2</a> , and the source code,
issue tracker, and README are on GitHub at
<a href="https://github.com/basho/riak-ruby-client/tree/v1.4.2">https://github.com/basho/riak-ruby-client/tree/v1.4.2</a> .

Thanks to all the contributors for this version!
