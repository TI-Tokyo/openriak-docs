Riak Recap for Oct 19

1) Riak support hit Akka master a few days ago.

Relevant commits can be found here ---&gt;
<a href="http://github.com/jboner/akka/commits/master">http://github.com/jboner/akka/commits/master</a>

2) For anyone attending Ruby on Rials EU or who happens to be in
Amsterdam tomorrow night, GitHub and Basho are throwing a drink-up.
Riak knowledge will be there in the form of @technoweenie, @roidrage
and @frank06.

Details here ---&gt; <a href="http://github.com/blog/735-github-meetup-in-amsterdam">http://github.com/blog/735-github-meetup-in-amsterdam</a>

3) Anyone looking for a sample app that uses Riak Search should check
out &quot;Wriaki.&quot; Wriaki is a Riak-backed wiki written by Basho Dev Bryan
Fink (@hobbyist).

Source code for Wriaki is here ---&gt; <a href="http://bitbucket.org/basho/wriaki/src">http://bitbucket.org/basho/wriaki/src</a>
A few details on the Search integration here ---&gt;
<a href="http://bitbucket.org/basho/wriaki/src/d2334be214ce/README#cl-74">http://bitbucket.org/basho/wriaki/src/d2334be214ce/README#cl-74</a>

4) Q --- When &quot;put&quot;-ing data, does the vtag / last_mod /
last_mod_usecs matter? I recall that vtag is simply there for vclock
context, in the event of siblings. last_mod&#x27;s I&#x27;m not sure if riak
asserts its own world view on those fields, or if we set those values
then riak will respect it? ( from  acts_as_ via #riak)

    A --- Those do not matter to Riak. It&#x27;ll set its own last modified.

5) seancribbs, traceback0, jdmaturen, dizzyd, jnewland and Tv had a
great conversation in #riak that started with &quot;Any information of
someone using Riak at scale?&quot; This is long but is well worth is as it
touches on various databases and, more importantly, the overall
importance of capacity planning regardless of your DB.

Gist here ---&gt; <a href="http://gist.github.com/637089">http://gist.github.com/637089</a>
