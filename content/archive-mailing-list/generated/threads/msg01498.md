Riak Recap for Nov. 5 - 7

1) For all of our Perl hackers, it looks like Franck Cuny et al bumped
Net-Riak up to 0.11

Latest changes here ---&gt;
<a href="http://cpansearch.perl.org/src/FRANCKC/Net-Riak-0.11/Changes">http://cpansearch.perl.org/src/FRANCKC/Net-Riak-0.11/Changes</a>

Check out his fork on GitHub for the code ---&gt;
<a href="https://github.com/djui/riak_core/commit/aa80a50fa66b9b567d8373b199e994ecf8d756a1">https://github.com/djui/riak_core/commit/aa80a50fa66b9b567d8373b199e994ecf8d756a1</a>

Riak? Then you&#x27;re in luck, because Mochi Media is hiring.

Details here ---&gt;
<a href="http://mochimedia.theresumator.com/apply/kRUm5b/Senior-Web-Engineer-Python-Django.html">http://mochimedia.theresumator.com/apply/kRUm5b/Senior-Web-Engineer-Python-Django.html</a>

and Adam Hunter (@adamachine) as committers to Ripple, the official
Riak Ruby Client.

Announcement (via tweet) here ---&gt;
<a href="http://twitter.com/seancribbs/status/1032166607687680">http://twitter.com/seancribbs/status/1032166607687680</a>

who was slated to attend. We will be rescheduling in the near future.
