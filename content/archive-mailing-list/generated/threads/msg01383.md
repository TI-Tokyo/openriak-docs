This has been addressed a good amount on the mailing list already.

You can read up on it here ---&gt;
<a href="http://riak.markmail.org/search/?q=delete%20bucket">http://riak.markmail.org/search/?q=delete%20bucket</a>

Short answer is that there is no way to delete a bucket. You&#x27;ll need to delete
each key. There is a ticket open for it ---&gt;
<a href="https://issues.basho.com/show_bug.cgi?id=79">https://issues.basho.com/show_bug.cgi?id=79</a>

<blockquote>Is there any command to show me bucket information ie how many document, its
disc size  etc..
</blockquote>
For getting the number of keys in the bucket, check out question
number four here ---&gt;

<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2010-June/001540.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2010-June/001540.html</a>

As far as other stats, Riak exposes stats at &quot;<a href="http://localhost:8098/stats">http://localhost:8098/stats</a>&quot;;

There is also a nifty Ganglia module that Jesse Newland put together a
few weeks ago---&gt;
<a href="http://github.com/jnewland/gmond_python_modules/tree/master/riak">http://github.com/jnewland/gmond_python_modules/tree/master/riak</a>
