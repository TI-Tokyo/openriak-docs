</div><ol class="mailing-list-replies"><li class="mailing-list-reply"><details id="msg17182" class="mailing-list-message"><summary><header class="mailing-list-message__header"><span class="mailing-list-message__author">Vitaly E</span><time datetime="2016-04-01T06:14:42-07:00">April 1, 2016 at 6:14 AM</time><span class="mailing-list-message__subject">Re: Cluster ready status for Riak S2</span></header></summary><div class="mailing-list-message__content"><div class="mailing-list-message__body">Actually, &#x27;riak-admin wait-for-service &lt;service&gt; &lt;nodename&gt;&#x27; can be a good
way of checking if a Riak service has fully started. For example, &#x27;riak-admin
wait-for-service riak_kv riak@127.0.0.1&#x27; (
<a href="http://docs.basho.com/riak/latest/ops/running/tools/riak-admin/#wait-for-service">http://docs.basho.com/riak/latest/ops/running/tools/riak-admin/#wait-for-service</a>,
more details in <a href="http://littleriakbook.com/">http://littleriakbook.com/</a>). This command will exit when
the service is finally up. A list of available services can be printed using
&#x27;riak-admin services&#x27;. I believe it should work with Riak S2 as well as
Riak KV.
