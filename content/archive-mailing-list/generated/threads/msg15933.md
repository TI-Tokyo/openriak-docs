  ... ... ... riak ... ... ... ... ... ...

Do you want to continue? [Y/n/?]

if i select Y i get the following:

Unpacking riak (2.0.5-1) over (2.0.5-1) ...

and everytime I check for updates, &quot;riak&quot; comes as requiring an update
