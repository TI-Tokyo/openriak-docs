Riak package will give you all the erlang bits you need, you shouldn&#x27;t

Python is one of the client libraries we provide and support.  I&#x27;m not an
expert on it, but we do actively support it for new releases.

Installing via dpkg will not do updates for you automatically, but you can
upgrade with it when new releases come out. See the documentation on
Rolling Upgrades here
<a href="http://docs.basho.com/riak/latest/cookbooks/Rolling-Upgrades/">http://docs.basho.com/riak/latest/cookbooks/Rolling-Upgrades/</a>

upset.  Using just &#x27;sudo riak start&#x27; and &#x27;sudo riak stop&#x27; is the preferred
method.  You do not need to create /var/lib/riak, the proper data
directories will be created on the first start.

I&#x27;d highly recommend you follow the Fast Track on the documentation site to
get more familiar with how Riak works before diving too far into it.
<a href="http://docs.basho.com/riak/latest/tutorials/fast-track/">http://docs.basho.com/riak/latest/tutorials/fast-track/</a>

There were several fixes in regards to init scripts and return codes added
to Riak 1.4 which is our next major release.
