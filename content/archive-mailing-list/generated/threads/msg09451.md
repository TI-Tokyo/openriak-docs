function which is written in javascript using the HTTP API to interact with

If  &quot;input&quot; : [&quot;bucket&quot;, &quot;key&quot;] is the map reduce equivalent of &#x27;curl

Additionally is it possible to include the value of your index in the output of

Hi, Barry. That wording is a little confusing … instead of a list, the
&quot;inputs&quot; field should be a JSON object like:

    {&quot;bucket&quot;:&quot;mybucket&quot;,
     &quot;index&quot;:&quot;myindex_bin&quot;,
     &quot;key&quot;:&quot;my exact match&quot;}

or

    {&quot;bucket&quot;:&quot;mybucket&quot;,
     &quot;index&quot;:&quot;myindex_int&quot;,
     &quot;start&quot;:0
     &quot;end&quot;:100}

More complete examples are near the bottom of
<a href="http://docs.basho.com/riak/latest/tutorials/Secondary-Indexes---Examples/">http://docs.basho.com/riak/latest/tutorials/Secondary-Indexes---Examples/</a>
