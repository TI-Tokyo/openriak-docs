When I used the kerl script, building
the Riak worked fine.

curl -O <a href="https://raw.github.com/spawngrid/kerl/master/kerl">https://raw.github.com/spawngrid/kerl/master/kerl</a>; chmod a+x kerl
./kerl build R14B03 r14b03
sudo ./kerl install r14b03 /opt/erlang/r14b03
. /opt/erlang/r14b03/activate

Thanks!
