Riak Recap for November 11 - 13
========================

1) ldapjs-riak v.0.1.15 is available.

* Code and details here ---&gt;
<a href="http://twitter.com/#!/nodenpm/statuses/136125117460774912">http://twitter.com/#!/nodenpm/statuses/136125117460774912</a>

2) Jon Brisbin released another great piece of code. This one aims to
make it easier to user riak_core with Mislultin to power web apps. (It
should go without saying but: thanks, Jon!)

* Code and details here ---&gt;
<a href="http://twitter.com/#!/j_brisbin/statuses/136141175466893312">http://twitter.com/#!/j_brisbin/statuses/136141175466893312</a>

3) Basho and Riak will have a huge presence at this week&#x27;s QCon Event
in San Francisco.

* Details here ---&gt;
<a href="http://basho.com/blog/technical/2011/11/14/Basho-and-Riak-Taking-Over-QConSF/">http://basho.com/blog/technical/2011/11/14/Basho-and-Riak-Taking-Over-QConSF/</a>

(Also, if you&#x27;re planning to attend and want to chat, drop me an email.)

4) Jonathan Siegel wrote a short blog post about how to make the Riak
Java Client create keys for you.

* Read here ---&gt;
<a href="http://www.jsiegel.com/2011/11/workaround-riak-create-object-without.html">http://www.jsiegel.com/2011/11/workaround-riak-create-object-without.html</a>

(It should be noted that there is an existing pull request to add this
functionality - <a href="https://github.com/basho/riak-java-client/pull/24">https://github.com/basho/riak-java-client/pull/24</a> -
and that Russell and his crew are working on integrating it.)
