Riak Recap for September 5 - September 25
====================

Riak CS 1.4.1 was released.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013232.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013232.html</a>

Ryan Zezeski announced Yokozuna 0.9.0, including integration into the Riak
development branch in preparation for Riak 2.0.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013229.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013229.html</a>

Citrix released CloudPlatform 4.2, which adds S3-compatible object storage,
thus making integration with Riak CS possible.
- <a href="http://basho.com/citrix-cloudplatform-4-2-enables-tighter-riak-cs-integration/">http://basho.com/citrix-cloudplatform-4-2-enables-tighter-riak-cs-integration/</a>

Hector Castro wrote instructions on generating Docker images with Riak.
- <a href="http://docs.docker.io/en/latest/examples/running_riak_service/">http://docs.docker.io/en/latest/examples/running_riak_service/</a>
- <a href="https://github.com/hectcastro/docker-riak">https://github.com/hectcastro/docker-riak</a>

Additionally, Hector wrote a blog post on configuring S3 clients to talk to
Riak CS.
- <a href="http://basho.com/riak-cs-proxy-vs-direct-configuration/">http://basho.com/riak-cs-proxy-vs-direct-configuration/</a>

Seth Thomas wrote his first Basho blog post, describing the history and makeup
of our Chef cookbook.
- <a href="http://basho.com/the-evolution-of-bashos-chef-cookbook/">http://basho.com/the-evolution-of-bashos-chef-cookbook/</a>

Drew Kerrigan wrote a sample Sinatra application that talks to Yokozuna.
- <a href="http://www.drewkerrigan.com/?p=84">http://www.drewkerrigan.com/?p=84</a>

Inspired by Drew, Bryce Kerley wrote up a blog about using Yokozuna with the
Ruby client.
- <a href="http://blog.brycekerley.net/post/61080087619/a-nicer-syntax-for-nicer-search">http://blog.brycekerley.net/post/61080087619/a-nicer-syntax-for-nicer-search</a>

Bryce also announced the Riak Ruby Client v1.4.2.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013353.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013353.html</a>

Jeremiah Peschka announced CorrugatedIron v1.4.2.
-
<a href="http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013257.html">http://lists.basho.com/pipermail/riak-users_lists.basho.com/2013-September/013257.html</a>

Brett Langdon wrote a Riak HTTP client that mimics the memcached interface.
- <a href="https://github.com/brettlangdon/riakcached">https://github.com/brettlangdon/riakcached</a>

We published a handful of Riak Use Cases on the Basho Blog over the past week.
You should read them all.
- Rovio -
<a href="http://basho.com/rovio-uses-riak-to-power-angry-birds-toons-and-new-mobile-games/">http://basho.com/rovio-uses-riak-to-power-angry-birds-toons-and-new-mobile-games/</a>
- Praekelt Foundation (h/t to Simon de Haan et al):
<a href="http://basho.com/praekelt-foundation-deploys-riak/">http://basho.com/praekelt-foundation-deploys-riak/</a>
- Superfeedr (h/t to Julien Genestoux)
<a href="http://basho.com/superfeedr-deploys-riak-for-the-cave/">http://basho.com/superfeedr-deploys-riak-for-the-cave/</a>
