# Description

Discovery-only entry for 3.4.0: this setting is read by the newer transitive KV dependency scanned for metadata, but is absent from the release's direct KV dependency. Default inactivity timeout, in seconds, for an HTTP query's result queue. The request can override it with an inactivity timeout, controlling how long unused queued results are retained.
