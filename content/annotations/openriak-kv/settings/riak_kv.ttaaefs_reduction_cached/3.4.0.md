# Description

Discovery-only entry for 3.4.0: this setting is read by the newer transitive KV dependency scanned for metadata, but is absent from the release's direct KV dependency. Nonnegative integer threshold passed to the exchange engine when deciding whether to repeat cached root or branch comparisons. It is a count threshold, unlike the fractional `riak_kv.ttaaefs_reduction` setting for range trees.

# Notes

The metadata includes both [the direct KV revision](https://github.com/OpenRiak/riak_kv/tree/f4ed77e0c17caf14fe70d12a3b3481b0181f8cc5) and [a newer transitive KV revision](https://github.com/OpenRiak/riak_kv/tree/48285d5d7aa72c4167e338b3d28ae9ba434cfcb7). The recorded environment read comes from the newer revision. Do not assume that setting this key changes the behaviour of a standard 3.4.0 node.

# Inferred default

Not applicable to the direct 3.4.0 KV dependency: it does not consume this key. The common type and value constraints describe the newer transitive source included in the metadata scan.
