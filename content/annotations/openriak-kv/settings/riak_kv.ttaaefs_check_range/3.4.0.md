# Description

Current range filter for a Tictac full-sync range check. In the direct 3.4.0 KV dependency it is `none` or `{Bucket, KeyRange, LowTimestamp, HighTimestamp}`, with timestamps in epoch seconds. The manager's range operations maintain this value.

# Constraints

- `none` or `{Bucket, KeyRange, LowTimestamp, HighTimestamp}`. Bucket is a binary or `{TypeBinary, BucketBinary}`, or `all`; KeyRange is `{StartKey, EndKey}` or `all`; timestamps are epoch seconds. This release has no segment-filter element. Use the manager's range API.

# Notes

The 3.4.0 metadata also scans a newer transitive KV dependency with a different range representation that supports segment filtering. Use the range-management functions provided by the running release instead of copying the newer tuple format.
