# Description

Registry of `{Application, VnodeModule}` pairs maintained by application registration. The vnode manager uses it to discover vnode implementations and identify the application that owns a vnode module.

# Datatype

List

# Constraints

- List of `{Application, Module}` atom pairs identifying vnode implementations. Managed through `riak_core:register/2`.

# Inferred default

`[]` when unregistered; applications populate this registry at startup.

# Tags

feature: cluster-management
repository: riak_core
module: riak_core, riak_core_vnode_manager
concept: partition-placement, runtime

# Notes

This is the Erlang application environment key `vnode_modules` in `riak_core`. Its presence in source metadata does not establish a `riak.conf` mapping.
