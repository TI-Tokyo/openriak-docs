# Description

Returns `none` when no range is set, or `{Bucket, KeyRange, StartSeconds, EndSeconds}`. KV 3.4.0 expands the calendar bounds passed to `set_range/4` by one second on each side. For 2026-12-24 00:00:00 through 23:59:59 UTC, the stored bounds are `1798070399` and `1798156800`.
