# Version data adapters

These JSON files are the normalized documents consumed by Hugo and the browser runtime.

- `3.4.0.json` and `3.4.1.json` are generated by `tools/scripts/sync-product-metadata.js` from their matching `metadata/{version}/` directories. Do not edit them by hand.
- A `partial` defaults document is accepted only when every documentation-required value resolves for every supported OS; its status and warnings are retained in the generated adapter.
- Earlier versions remain proof-of-concept fixtures until metadata is available for them.

The architecture build runs the synchronization script before Hugo, so metadata changes are reflected in the generated adapter automatically.
