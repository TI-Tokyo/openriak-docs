*April 10, 2013*

Earlier this year, we announced that hosted Riak is [now available on the Engine Yard platform](http://basho.com/riak-on-engine-yard/). Ines Sombra, Lead Data Engineer at Engine Yard, has put together a talk to help you get started using Riak in cloud environments. This talk introduces Riak’s overall architecture, some common use cases, and goes over some questions to consider when choosing a database. It also discusses what you need to know to run Riak in the cloud and how it differs from traditional hardware installation.
