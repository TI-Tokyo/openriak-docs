*May 9, 2011*

At last month’s [San Francisco Riak Meetup](http://www.meetup.com/San-Francisco-Riak-Meetup/), Basho Developer Advocate [Dan Reverri](http://twitter.com/#!/reverri) gave an extensive and action-packed presentation on Riak Search. This talk goes from a basic overview of what Riak Search is and does, up through running a Riak Search Sample application. If you’re at all interested in what Riak Search can do for your applications, this video is well worth your 35 minutes. You can also get a PDF copy of Dan’s slides [here.](http://media.basho.com/pdf/RiakSearch-April-27.pdf)

When you’re done with the video:

- [Download Riak Search](http://downloads.basho.com/riak-search/CURRENT/)
- [Browse the Code on GitHub](http://downloads.basho.com/riak-search/CURRENT/)
- [Checkout the Riak Search Docs on the Riak Wiki](http://wiki.basho.com/Riak-Search.html)
- [Join the Riak Mailing List](http://lists.basho.com/mailman/listinfo/riak-users_lists.basho.com)

*NOTE: In the presentation Dan states that Riak Search’s standard analyzer supports stemming. This is not entirely true. The standard analyzer currently does not support stemming, but Riak Search allows you to call out to Java Lucene analyzers, which \*do\* support stemming. Sorry for any confusion.*

Enjoy.
