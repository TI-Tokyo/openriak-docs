# Approved OpenRiak KV Docker source files

These generated Dockerfile, Compose and environment files belong in Git.
Their matching approvals and SHA-256 values are retained under
`records/openriak-docker/`. Directory paths distinguish current image groups,
platforms and historical runs.

Change the generator, then use an explicit refresh to approve new files. Do not
edit approved files directly. Published download copies remain under
`content/static/openriak-kv/downloads/docker/`.

OCI archives, build contexts and diagnostics belong in `.work/openriak-docker/`,
which is excluded from Git and documentation Docker build contexts.
